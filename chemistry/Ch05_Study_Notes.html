2 Type I Ionic — Metal Forms Only ONE Cation §5.2

ConceptWhat to understandExamples
When it's Type IMetal + nonmetal, where the metal has a single, fixed charge (Groups 1A, 2A, Al, Zn, Ag).—
The 3 rules(1) Cation first, anion second. (2) Cation = the element's name, unchanged. (3) Anion = element root + "-ide." No Roman numeral, no prefixes.Cl⁻ = chloride, O²⁻ = oxide.
Worked namesCharge is implied, so it's not written.NaCl = sodium chloride; KI = potassium iodide; CaS = calcium sulfide.
⚠️ Exercise 1SrBr₂ → Sr is 2A (fixed), so no "di", no numeral.= strontium bromide (answer d). Not "dibromide."

3 Type II Ionic — Metal Forms MORE Than One Cation §5.2

ConceptWhat to understandExamples
When it's Type IIMetal + nonmetal where the metal can be several charges — nearly all transition metals, plus Sn, Pb.Fe, Cu, Co, Sn, Pb, Cr, Mn…
The key ruleCharge must be specified with a Roman numeral in parentheses right after the metal name.Fe²⁺ = iron(II); Fe³⁺ = iron(III).
How to find the chargeBack-calculate from the anion: total anion charge must be balanced by the metal.CuBr: Br⁻ ⇒ Cu is 1+ ⇒ copper(I) bromide. FeS: S²⁻ ⇒ iron(II) sulfide. PbO₂: 2 O²⁻ = 4− ⇒ lead(IV) oxide.
⚠️ Exercise 2CrO₂: 2 O²⁻ = 4−, so Cr = 4+.= chromium(IV) oxide (answer c).
⚠️ Exercise 3Most stable S ion = S²⁻; metal ion with 24 e⁻ → protons = 24 + 2 = 26 = Fe, so Fe²⁺.= iron(II) sulfide, FeS (answer d).

6 Type III Covalent — Two Nonmetals §5.3

ConceptWhat to understandExamples
When it's Type IIITwo nonmetals bonded (covalent, not ionic). No charges to balance — so we count atoms with prefixes instead.CO₂, SF₆, N₂O₄.
The 4 rules(1) First element = full name. (2) Second element = root + "-ide." (3) Greek prefixes show how many of each atom. (4) Never use "mono-" on the FIRST element.CO = carbon monoxide (mono only on 2nd). CO₂ = carbon dioxide.
Worked namesPrefix both elements (except mono on first).CO₂ = carbon dioxide; SF₆ = sulfur hexafluoride; N₂O₄ = dinitrogen tetroxide.
⚠️ Exercise 4SeO₂ = two nonmetals ⇒ prefixes, no numeral.= selenium dioxide (answer b). Not "selenium(IV)".

8 Polyatomic Ions & Oxyanions §5.5

ConceptWhat to understandExamples
Polyatomic ionA charged group of several atoms that stays together. Names are special and must be memorized (§9).NH₄⁺, OH⁻, NO₃⁻, SO₄²⁻.
Naming compounds with themSame as ionic: cation first, anion second — but use the polyatomic's own name, and no prefixes.NH₄C₂H₃O₂ = ammonium acetate; NaOH = sodium hydroxide.
Oxyanion pattern (-ate / -ite)Same central element, different # of oxygens. More O = "-ate", fewer O = "-ite."NO₃⁻ = nitrate; NO₂⁻ = nitrite. SO₄²⁻ = sulfate; SO₃²⁻ = sulfite.
Four-level pattern (halogens)When 4 oxyanions exist: per…ate > …ate > …ite > hypo…ite (most O → least O).ClO₄⁻ perchlorate · ClO₃⁻ chlorate · ClO₂⁻ chlorite · ClO⁻ hypochlorite.
"Hydrogen" prefixAdd H⁺ to an anion → add "hydrogen" (old: "bi-") and raise charge by +1.CO₃²⁻ carbonate → HCO₃⁻ hydrogen carbonate (bicarbonate).
⚠️ Exercise 5KClO₃: ClO₃⁻ = chlorate.= potassium chlorate (answer b).

10 Naming Acids §5.6

ConceptWhat to understandExamples
What an acid is (here)A molecule that produces H⁺ in water; recognizable because H is written first (H⁺ attached to an anion).HCl, H₂SO₄.
Rule A — anion has NO oxygenhydro- + root + -ic acid.HCl → hydrochloric acid; HCN → hydrocyanic; H₂S → hydrosulfuric.
Rule B — anion HAS oxygenFrom the oxyanion suffix: -ate → "-ic acid"; -ite → "-ous acid" (no "hydro-").H₂SO₄ (sulfate) → sulfuric acid; H₂SO₃ (sulfite) → sulfurous acid; HC₂H₃O₂ → acetic acid; H₃PO₃ → phosphorous acid.
Memory hook"-ate → -ic" and "-ite → -ous." (per-ate→per-ic; hypo-ite→hypo-ous.)ClO₄⁻ → perchloric; ClO⁻ → hypochlorous.

⭐ Highest-Yield — Drill These First

  1. Classify first (§1 tree): metal+nonmetal Type I/II · two nonmetals Type III · polyatomic · acid. Every question starts here.
  2. Type II Roman numerals — back-calculate the metal charge from the anion (CrO₂ → Cr⁴⁺).
  3. Prefixes vs numerals — the classic trap: two nonmetals get prefixes (selenium dioxide), transition metals get numerals (chromium(IV)). Never mix them.
  4. Memorize the polyatomic table (§9) — learn -ate forms, derive -ite/per-/hypo-.
  5. Acid rules (§10): no O → hydro-…-ic; -ate → -ic; -ite → -ous.
  6. Write formulas from names (§12) — crossover/charge-balance with parentheses for polyatomics.
  7. Prefix "mono-" is never on the first element (CO = carbon monoxide, not monocarbon).
