ANSWER KEY — Integration Lesson 34 Test: Volumes I — Disks & Washers

For the grader · full working shown · give credit for a correct setup with small arithmetic slips · setup-only questions earn full credit with no evaluation

1. Region under y = x² on [0, 2] revolved about the x-axis. Volume?
Work: disk radius r(x) = x². Square FIRST: (x²)² = x4 (exponents multiply — not x²). V = π ∫₀² x4 dx = π[x5/5]₀² = π(32/5 − 0). Answer: V = 32π/5. Grader note: squaring after integrating (π(8/3)² ) is the classic error — no credit for that route.
2. Region under y = √(2x) on [0, 3] revolved about the x-axis. Volume?
Work: radius r(x) = √(2x). Squaring kills the root: (√(2x))² = 2x. V = π ∫₀³ 2x dx = π[x²]₀³ = π(9 − 0). Answer: V = 9π. Grader note: (√(2x))² = 2x, not 2x² and not 4x.
3. y = 5 on [2, 6] revolved about the x-axis; check against πr²h.
Work: every disk is identical, radius 5. V = π ∫₂⁶ 5² dx = π ∫₂⁶ 25 dx = 25π(6 − 2) = 100π. Geometry: cylinder of radius r = 5 and height (length along the axis) h = 6 − 2 = 4 → πr²h = π·25·4 = 100π ✓. Answer: V = 100π, with r = 5 and h = 4. Grader note: using h = 6 (forgetting to subtract the lower limit) gives 150π — wrong.
4. y = x on [0, 4] revolved about the x-axis; check against (1/3)πr²h.
Work: radius r(x) = x, so (r)² = x². V = π ∫₀⁴ x² dx = π[x³/3]₀⁴ = π(64/3). Geometry: a cone lying on its side, tip at the origin, height h = 4 along the axis, base radius = height of the line at x = 4, so r = 4: (1/3)πr²h = (1/3)π·16·4 = 64π/3 ✓. Answer: V = 64π/3. Grader note: the 1/3 in the cone formula IS the 3 from x³/3 — say so for full credit on the check.
5. Slab solid on [0, 6] cm with A(x) = 4 + x cm². (a) Volume? (b) Why cubic centimeters?
Work: (a) V = ∫₀⁶ (4 + x) dx = [4x + x²/2]₀⁶ = (24 + 18) − 0 = 42. (b) Each slab contributes (cross-section area) × (thickness) = cm² × cm = cm³, and adding slabs never changes the units. Answer: (a) V = 42 cubic centimeters. (b) A(x) dx carries cm² · cm = cm³. Grader note: no π anywhere here — the slices are not stated to be circles, so A(x) is used as given.
6. Region between y = x + 1 (top) and y = 1 (bottom) on [0, 2], revolved about the x-axis. Volume?
Work: the floor of the region is y = 1, not the axis → washers. Outer R = x + 1, inner r = 1. Square each separately: R² = (x + 1)² = x² + 2x + 1 (keep the middle term!), r² = 1. R² − r² = x² + 2x. V = π ∫₀² (x² + 2x) dx = π[x³/3 + x²]₀² = π(8/3 + 4) = π(8/3 + 12/3) = 20π/3. Answer: V = 20π/3. Check: full solid π∫₀²(x + 1)² dx = π[(x+1)³/3]₀² = π(27/3 − 1/3) = 26π/3, minus the drilled cylinder of radius 1 and length 2 (= 2π = 6π/3) → 26π/3 − 6π/3 = 20π/3 ✓. Grader note: dropping the 2x cross term gives 14π/3 — wrong.
7. Region between y = 3x and y = x on [0, 1] revolved about the x-axis. Student writes V = π∫₀¹(3x − x)² dx. (a) Student's value? (b) Correct value? (c) Why R² − r² ≠ (R − r)²?
Work: (a) Student: (3x − x)² = (2x)² = 4x², so π ∫₀¹ 4x² dx = 4π[x³/3]₀¹ = 4π/3. (b) Correct washer: R = 3x, r = x, so R² − r² = 9x² − x² = 8x². V = π ∫₀¹ 8x² dx = 8π[x³/3]₀¹ = 8π/3. (c) With R = 3, r = 1: R² − r² = 9 − 1 = 8, but (R − r)² = 2² = 4. Algebra agrees: (R − r)² = R² − 2Rr + r², which is never the same as R² − r² unless r = 0. Answer: (a) 4π/3   (b) 8π/3   (c) 8 ≠ 4 — squaring the gap loses exactly half the volume here. Grader note: a ring's area is the big circle MINUS the hole, π(R² − r²); π(R − r)² is the area of a small circle whose radius is only the gap width.
8. Region enclosed by y = √x and y = x² revolved about the x-axis. Find the limits, then the volume.
Work: intersections: √x = x² → square both sides: x = x4 → x4 − x = 0 → x(x³ − 1) = 0 → x = 0 and x = 1. Which is outer? Test x = 1/4: √x = 1/2 versus x² = 1/16, so √x is the outer curve (R = √x, r = x²). Squares: R² = x, r² = (x²)² = x4. V = π ∫₀¹ (x − x4) dx = π[x²/2 − x5/5]₀¹ = π(1/2 − 1/5) = π(5/10 − 2/10). Answer: intersections x = 0 and x = 1; V = 3π/10. Grader note: reversing R and r gives −3π/10 — a negative volume is an instant signal the curves were swapped.
9. Set up (do NOT evaluate) the volume when the region under y = sin x on [0, π] is revolved about the x-axis.
Work: the region runs from the curve down to the x-axis → disk method. Radius r(x) = sin x. Square it: (sin x)² = sin²x. Limits are given: 0 to π. Answer: V = π ∫₀π sin²x dx   — disk method, radius r = sin x. Stop here; no evaluation required. Grader note: sin²x means (sin x)², NOT sin(x²). Evaluating needs a power-reduction identity, so a correct setup earns the full point.
10. Region between y = √(25 − x²) and y = 3 revolved about the x-axis (hole drilled through a sphere). (a) Limits? (b) Volume?
Work: (a) √(25 − x²) = 3 → square both sides: 25 − x² = 9 → x² = 16 → x = −4 and x = 4. (b) Washers with R = √(25 − x²) (outer) and r = 3 (inner). Square first: R² = 25 − x², r² = 9, so R² − r² = 16 − x². V = π ∫₋₄⁴ (16 − x²) dx = 2π ∫₀⁴ (16 − x²) dx (even integrand, symmetry shortcut) = 2π[16x − x³/3]₀⁴ = 2π(64 − 64/3) = 2π(192/3 − 64/3) = 2π(128/3). Answer: (a) x = ±4   (b) V = 256π/3. Check: less than the whole sphere, (4/3)π·125 = 500π/3 ✓ (the drilled-out part accounts for the rest). Grader note: a very common slip is integrating from 0 to 4 only, giving 128π/3 — exactly half the ring. Also (√(25 − x²) − 3)² is the forbidden squared-difference.
