ANSWER KEY — Integration Lesson 26 Test: u-Substitution Mastery

For the grader · full working shown · give credit for correct method with small arithmetic slips · limits plugged into the wrong variable's formula is THE error to watch for

1. Compute ∫₀¹ 2x(x²+2)² dx with changed limits.
Work: u = x²+2, du = 2x dx (already present). Limits: u(0) = 2, u(1) = 3. Integral = ∫₂³ u² du = [u³/3]₂³ = 27/3 − 8/3 = 19/3. Answer: 19/3. (Grader: back-substituting to (x²+2)³/3 with x-limits 0,1 → 27/3 − 8/3 = 19/3 also earns full credit, though the prompt asked for changed limits — take off half if limits were never converted.)
2. Find the new u-limits: (a) u = x³+1, x: 0 to 2. (b) u = cos x, x: 0 to π/2.
Work: plug the x-limits into the u formula. (a) u(0) = 0+1 = 1; u(2) = 8+1 = 9 → u: 1 → 9. (b) u(0) = cos 0 = 1; u(π/2) = 0 → u: 1 → 0. Answer: (a) 1 → 9 (b) 1 → 0. (Grader: (b) running downhill is CORRECT — "reversed" limits are legal; don't accept 0 → 1 unless the student explains they flipped the integral's sign.)
3. Find ∫ x/(x²+9) dx.
Work: derivative of bottom is 2x; top is x — off by constant 2, so borrow it: u = x²+9, x dx = du/2. (1/2)∫du/u = (1/2)ln|u| = (1/2)ln(x²+9) (bottom always positive). Check: derivative = (1/2)·2x/(x²+9) = x/(x²+9) ✓. Answer: (1/2) ln(x²+9) + C. (Grader: arctan-form answer (1/3)arctan(x/3) is wrong — that's for 1/(9+x²) with NO x on top.)
4. Compute ∫₁^(e²) (ln x)/x dx with changed limits.
Work: u = ln x, du = (1/x)dx. Limits: u(1) = ln 1 = 0; u(e²) = ln(e²) = 2. Integral = ∫₀² u du = [u²/2]₀² = 4/2 − 0 = 2. Answer: 2.
5. Find ∫ cos⁴x sin x dx.
Work: u = cos x, du = −sin x dx → sin x dx = −du. Integral = −∫u⁴du = −u⁵/5 = −cos⁵x/5. Check: d/dx[−cos⁵x/5] = −(5cos⁴x)(−sin x)/5 = cos⁴x sin x ✓. Answer: −cos⁵x/5 + C. (Grader: the missing minus sign is the expected slip; +cos⁵x/5 gets no more than half.)
6. Compute ∫₀^(π/2) sin⁴x cos x dx with changed limits.
Work: u = sin x, du = cos x dx. Limits: u(0) = 0, u(π/2) = 1. Integral = ∫₀¹ u⁴ du = [u⁵/5]₀¹ = 1/5. Answer: 1/5.
7. Find ∫ eˣ/(eˣ+5) dx and name the pattern.
Work: derivative of the bottom (eˣ+5) is eˣ = the top, so this is the ∫ f′/f = ln|f| pattern ("derivative-of-bottom-on-top → ln"). u = eˣ+5, du = eˣdx → ∫du/u = ln(eˣ+5) (always positive, no |·|). Answer: ln(eˣ+5) + C; pattern: ∫ f′/f = ln|f|.
8. Compute ∫₀^(π/4) sec²x/(1+tan x) dx exactly.
Work: derivative of the bottom (1+tan x) is sec²x = the top → f′/f pattern. u = 1+tan x, du = sec²x dx. Limits: u(0) = 1+tan 0 = 1; u(π/4) = 1+tan(π/4) = 1+1 = 2. Integral = ∫₁² du/u = [ln u]₁² = ln 2 − ln 1 = ln 2. Answer: ln 2. (Grader: this is an AP classic; full marks require the changed limits 1 → 2 or a correct back-substitution with x-limits.)
9. Student writes ∫₀¹ x(x²+1)² dx = (1/2)∫₀¹ u² du = 1/6. Find the error; give the correct answer.
Work: the error: the student kept the x-limits 0 and 1 on a u-integral — limits belong to the variable next to the d, so they had to be converted: u(0) = 1, u(1) = 2. Correct: (1/2)∫₁² u² du = (1/2)(8/3 − 1/3) = (1/2)(7/3) = 7/6. Answer: forgot to change the limits; correct value 7/6. (Grader: naming the error without recomputing = half; recomputing without naming the error = half.)
10. Compute ∫₀^(π/4) tan³x sec²x dx with changed limits.
Work: u = tan x, du = sec²x dx (sitting right there). Limits: u(0) = tan 0 = 0; u(π/4) = tan(π/4) = 1. Integral = ∫₀¹ u³ du = [u⁴/4]₀¹ = 1/4. Answer: 1/4. (Grader: the u = sec x road also works — sec⁴x/4 − sec²x/2 evaluated... but it's longer; any correct route earning 1/4 gets the point.)
