ANSWER KEY — Integration Lesson 7 Test: The Fundamental Theorem of Calculus

For the grader · full working shown · give credit for correct method with small arithmetic slips · deduct if F(a) is not subtracted

1. Use the Fundamental Theorem to evaluate ∫04 5 dx, then check with a rectangle.
Work: F(x) = 5x (derivative of 5x is 5 ✓). F(4) = 20, F(0) = 0, so 20 − 0 = 20. Rectangle check: width 4 × height 5 = 20 ✓. Answer: 20.
2. Use the Fundamental Theorem to evaluate ∫03 2x dx, then check with a triangle.
Work: F(x) = x² (derivative is 2x ✓). F(3) = 9, F(0) = 0, so 9 − 0 = 9. Triangle check: base 3, height 2 × 3 = 6, area ½ × 3 × 6 = 9 ✓. Answer: 9.
3. Evaluate ∫03 x² dx.
Work: F(x) = x³/3 (derivative: 3x²/3 = x² ✓). F(3) = 27/3 = 9, F(0) = 0, so 9 − 0 = 9. Answer: 9.
4. Evaluate ∫12 x³ dx. Give the exact fraction and a decimal.
Work: F(x) = x⁴/4 (derivative: 4x³/4 = x³ ✓). F(2) = 16/4 = 4, F(1) = 1/4. Then 4 − 1/4 = 16/4 − 1/4 = 15/4. Answer: 15/4 = 3.75. (Watch for the classic error of forgetting F(1) = 1/4 and answering 4.)
5. Evaluate ∫02 (3x² + 4) dx.
Work: term by term: 3x² → x³, 4 → 4x, so F(x) = x³ + 4x (derivative: 3x² + 4 ✓). F(2) = 8 + 8 = 16, F(0) = 0. Answer: 16.
6. Evaluate ∫15 (2x + 1) dx with the FTC, then verify with the trapezoid method.
Work: F(x) = x² + x (derivative: 2x + 1 ✓). F(5) = 25 + 5 = 30, F(1) = 1 + 1 = 2, so 30 − 2 = 28. Trapezoid check: heights 2(1) + 1 = 3 and 2(5) + 1 = 11; width 5 − 1 = 4; area = ½(3 + 11) × 4 = 7 × 4 = 28 ✓. Answer: 28.
7. A student evaluates ∫13 2x dx as "x² at 3 is 9, answer 9." Find and fix the mistake.
Work: the antiderivative and F(3) = 9 are correct, but the student never subtracted F(1) — the FTC is F(b) − F(a), a difference of TWO readings (like an odometer: end reading minus start reading). F(1) = 1, so the correct value is 9 − 1 = 8. Answer: the mistake is forgetting to subtract F(1); correct answer 8.
8. Show with one line of algebra why the +C is harmless in the FTC.
Work: (F(b) + C) − (F(a) + C) = F(b) − F(a) + C − C = F(b) − F(a). The C is added once and subtracted once, so it cancels for every possible value — all antiderivatives in the family give the same definite integral, and we may use the C = 0 one. Answer: the C's cancel in the subtraction, leaving F(b) − F(a).
9. A pump's flow rate is r(t) = 8t liters per hour. Find the total water pumped from t = 1 to t = 2 hours.
Work: total = ∫12 8t dt. F(t) = 4t² (derivative: 8t ✓). F(2) = 16, F(1) = 4, so 16 − 4 = 12. Units: (liters/hour) × hours = liters. Answer: 12 liters.
10. Challenge: evaluate ∫03 (x² − x + 2) dx.
Work: term by term: x² → x³/3, −x → −x²/2, 2 → 2x, so F(x) = x³/3 − x²/2 + 2x (derivative: x² − x + 2 ✓). F(3) = 27/3 − 9/2 + 6 = 9 − 4.5 + 6 = 10.5. F(0) = 0. So 10.5 − 0 = 10.5. Answer: 21/2 = 10.5.
