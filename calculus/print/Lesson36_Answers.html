ANSWER KEY — Integration Lesson 36 Test: Arc Length

For the grader · full working shown · give credit for a correct setup with small arithmetic slips · setup-only questions earn full credit with no evaluation

1. Length of f(x) = (4/3)x on [0, 9], checked with the distance formula.
Work: f′ = 4/3 → (f′)² = 16/9 → 1 + 16/9 = 9/9 + 16/9 = 25/9 → √(25/9) = 5/3 (a constant, because the slope never changes). L = ∫₀⁹ (5/3) dx = (5/3)(9) = 15. Check: endpoints (0, 0) and (9, 12); distance = √(9² + 12²) = √(81 + 144) = √225 = 15 ✓ (a 3-4-5 triangle scaled by 3). Answer: L = 15. Grader note: for a straight line the integrand is constant, so L = (constant) × (width) — no antiderivative work needed.
2. Exact length of f(x) = 2x − 5 on [1, 4].
Work: f′ = 2 (the −5 has derivative 0) → 1 + (f′)² = 1 + 4 = 5 → integrand √5. L = ∫₁⁴ √5 dx = √5(4 − 1) = 3√5. Check: endpoints (1, −3) and (4, 3); distance = √(3² + 6²) = √45 = √9·√5 = 3√5 ✓. Answer: L = 3√5. Grader note: 3√5 ≈ 6.71 is the finished answer — exact form is required, and √45 unsimplified should get the point with a note to simplify.
3. Length of f(x) = (2/3)x3/2 on [0, 15].
Work: f′ = (2/3)(3/2)x1/2 = x1/2 = √x. Then (f′)² = x (the square undoes the root), so 1 + (f′)² = 1 + x and the integrand is √(1 + x). Linear inside with slope 1, so plain power rule on the package: ∫√(1 + x) dx = (2/3)(1 + x)3/2. L = [(2/3)(1 + x)3/2]₀¹⁵ = (2/3)(163/2 − 13/2) = (2/3)(64 − 1) = (2/3)(63) = 42. Answer: L = 42. Check: 163/2 = (√16)³ = 4³ = 64. Sanity: L must be at least the interval width 15 ✓, and at least the chord ≈ 41.5 ✓. Grader note: the interval was chosen so 1 + 15 = 16 is a perfect square — if the student's 163/2 is not 64, that's the slip.
4. Length of f(x) = (2/3)x3/2 + 11 on [0, 24]; what does the +11 do?
Work: f′ = √x again — the +11 dies when differentiated, and the integrand only ever sees f′. So the integrand is still √(1 + x). L = [(2/3)(1 + x)3/2]₀²⁴ = (2/3)(253/2 − 1) = (2/3)(125 − 1) = (2/3)(124) = 248/3. Answer: L = 248/3. The +11 lifts the whole curve 11 units up but does not stretch it — a vertical shift never changes arc length (every tiny hypotenuse keeps its size and tilt). Check: 253/2 = (√25)³ = 5³ = 125; 248/3 ≈ 82.7 ≥ width 24 ✓. Grader note: a student who tries to keep the 11 inside the integrand has misread the formula; full credit requires both the number and the "shifts don't matter" reason.
5. Set up (do not evaluate) the length of y = x² on [1, 3].
Work: f′ = 2x → (f′)² = 4x² (square the whole thing, coefficient included) → 1 + 4x². Answer: L = ∫₁³ √(1 + 4x²) dx — stop here. Grader note: (2x)² = 4x², not 2x². The parabola has no elementary arc-length antiderivative, so any attempted evaluation is a red flag, not a bonus.
6. Set up (do not evaluate) the length of y = sin x on [0, π/2], and say why we stop.
Work: f′ = cos x → (f′)² = cos²x → integrand √(1 + cos²x). Answer: L = ∫₀π/2 √(1 + cos²x) dx. We stop because no function built from powers, roots, trig, exponentials, and logs has √(1 + cos²x) as its derivative — no elementary antiderivative exists, so a calculator must finish it numerically (≈ 1.91). Grader note: cos²x means (cos x)², not cos(x²). Accept any wording of "impossible by hand / elliptic integral / calculator only."
7. Set up (do not evaluate): (a) y = ex on [1, 2]; (b) y = ln x on [1, 4].
Work: (a) ex is its own derivative, so f′ = ex and (f′)² = (ex)² = e2x (multiplying doubles the exponent). (b) f′ = 1/x → (f′)² = 1/x². Answer: (a) L = ∫₁² √(1 + e2x) dx   (b) L = ∫₁⁴ √(1 + 1/x²) dx. Grader note: in (b) the form √((x² + 1)/x²) — or (√(x² + 1))/x, valid since x > 0 — is equally correct. Neither integral needs evaluating.
8. f′(x) = √(4x² + 4x): simplify 1 + (f′)², then find L on [0, 3].
Work: (f′)² = 4x² + 4x (squaring cancels the root), so 1 + (f′)² = 4x² + 4x + 1 = (2x + 1)² — a perfect square. Re-expand to confirm: (2x + 1)² = 4x² + 4x + 1 ✓. Then √((2x + 1)²) = 2x + 1, positive on [0, 3], so no absolute value needed. L = ∫₀³ (2x + 1) dx = [x² + x]₀³ = (9 + 3) − 0 = 12. Answer: 1 + (f′)² = (2x + 1)², L = 12. Check: differentiate x² + x → 2x + 1 ✓. Sanity: 12 ≥ interval width 3 ✓. Grader note: arc length only ever needs f′, so being handed the derivative is normal, not missing information.
9. Student's L = ∫₀¹² √((f′)²) dx = 5 for f(x) = (5/12)x on [0, 12]. Error? What was computed? Why impossible? Correct length?
Work: (a) The student dropped the 1 inside the square root: √(1 + (f′)²) became √((f′)²). (b) √((f′)²) = |f′|, so the student integrated the slope and got the total vertical rise of the path: the line climbs (5/12)(12) = 5 units. True, but it ignores the 12 units of sideways travel. (c) The integrand √(1 + (f′)²) is always ≥ 1, so L must be at least the interval width 12 — an answer of 5 is impossible. (d) Correct: f′ = 5/12 → 1 + 25/144 = 144/144 + 25/144 = 169/144 → √ = 13/12 → L = (13/12)(12) = 13. Answer: (a) the 1 was dropped; (b) only the 5 units of rise; (c) L ≥ 12 always, so 5 is impossible; (d) L = 13. Check: endpoints (0, 0) and (12, 5): √(144 + 25) = √169 = 13 ✓ (the 5-12-13 triangle). Grader note: the 1 is the dx² leg of the tiny triangle — the horizontal travel. Award the point only if the student explains that, not just fixes the arithmetic.
10. Exact length of f(x) = x3/2 on [0, 5], compared with the straight-line endpoint distance.
Work: f′ = (3/2)x1/2 → (f′)² = (9/4)x → 1 + (f′)² = 1 + 9x/4, integrand √(1 + 9x/4). Linear inside with slope 9/4, so divide by 9/4 (i.e. multiply by 4/9): ∫√(1 + 9x/4) dx = (4/9)(2/3)(1 + 9x/4)3/2 = (8/27)(1 + 9x/4)3/2. (Differentiate to check: (8/27)(3/2)(9/4)(1 + 9x/4)1/2 = (8/27)(27/8)√(1 + 9x/4) = √(1 + 9x/4) ✓.) At x = 5: 1 + 45/4 = 49/4, and (49/4)3/2 = 7³/2³ = 343/8. At x = 0: 13/2 = 1. L = (8/27)(343/8 − 1) = (8/27)(343/8 − 8/8) = (8/27)(335/8) = 335/27. Straight line: endpoints (0, 0) and (5, 53/2) = (5, 5√5); distance = √(25 + 125) = √150 = 5√6. Answer: L = 335/27, and 335/27 ≈ 12.41 > 5√6 ≈ 12.25 ✓ — the curve is longer than the chord, exactly as required. Grader note: the interval was designed so 1 + 45/4 = 49/4 is a perfect square; a student who writes 493/2/4 instead of 493/2/43/2 has forgotten to power the denominator too.
