ANSWER KEY — Integration Lesson 24 Test: Tangent, Secant & Friends

For the grader · full working shown · deduct only half for a missing + C · sign errors on the "co" functions lose the point

1. Exact values of tan(π/3) and sec(π/3).
Work: tan(π/3) = sin(π/3)/cos(π/3) = (√3/2)/(1/2) = √3.   sec(π/3) = 1/cos(π/3) = 1/(1/2) = 2. Answer: tan(π/3) = √3, sec(π/3) = 2.
2. tan 0, sec 0, tan(π/4); where is tan x undefined and why?
Work: tan 0 = 0/1 = 0; sec 0 = 1/1 = 1; tan(π/4) = (√2/2)/(√2/2) = 1. Undefined where the bottom is zero: cos(π/2) = 0, so tan(π/2) is undefined (any odd multiple of π/2 accepted). Answer: 0, 1, 1; tan is undefined at x = π/2 because cos(π/2) = 0 (division by zero).
3. ∫ sec²x dx with check.
Work: reading (tan x)′ = sec²x backward: ∫ sec²x dx = tan x + C. Check: (tan x)′ = sec²x ✓. Answer: tan x + C. (The check must appear — it was asked for. Common wrong answer: sec³x/3 + C, the power-rule-on-trig trap, gets 0.)
4. ∫ csc x cot x dx.
Work: (csc x)′ = −csc x cot x, so we need the minus out front: ∫ csc x cot x dx = −csc x + C. Check: (−csc x)′ = +csc x cot x ✓. Answer: −csc x + C. (+csc x + C is the expected sign slip — no credit, the sign IS the content here.)
5. ∫ (2sec²x + cos x) dx.
Work: split and use the library: ∫ 2sec²x dx = 2 tan x; ∫ cos x dx = sin x. Check: (2 tan x + sin x)′ = 2 sec²x + cos x ✓. Answer: 2 tan x + sin x + C.
6. ∫₀^π/4 sec²x dx.
Work: FTC: tan x |₀^π/4 = tan(π/4) − tan 0 = 1 − 0 = 1. Answer: 1.
7. ∫₀^π/3 sec x tan x dx.
Work: antiderivative is sec x. FTC: sec(π/3) − sec 0 = 2 − 1 = 1. Answer: 1. (sec(π/3) = 1/cos(π/3) = 1/(1/2) = 2; sec 0 = 1.)
8. ∫ sec²(3x) dx with check.
Work: linear-inside rule: base antiderivative tan x, inside 3x, so divide by 3: tan(3x)/3 + C. Check: derivative of tan(3x)/3 = (1/3)·sec²(3x)·3 = sec²(3x) ✓. Answer: tan(3x)/3 + C. (tan(3x) + C without the 1/3 is the standard chain-rule miss — no credit; the check was required and would have caught it.)
9. Student claims ∫ csc²x dx = cot x + C. Right or wrong?
Work: differentiate the claim: (cot x)′ = −csc²x ≠ +csc²x — wrong by a sign. Correct: ∫ csc²x dx = −cot x + C, since (−cot x)′ = csc²x ✓. Answer: wrong; the correct antiderivative is −cot x + C. (Full credit needs the differentiation check shown, the verdict, and the fix.)
10. ∫ tan x dx by u-substitution, every step.
Work: ∫ tan x dx = ∫ (sin x/cos x) dx. Let u = cos x → du = −sin x dx → sin x dx = −du. Integral becomes ∫ (−du)/u = −∫(1/u) du = −ln|u| + C = −ln|cos x| + C. Check: derivative = −(1/cos x)(−sin x) = tan x ✓. Answer: −ln|cos x| + C (equivalently ln|sec x| + C — either form earns full credit). (Missing absolute-value bars: half credit; missing the back-substitution to x: half credit.)
