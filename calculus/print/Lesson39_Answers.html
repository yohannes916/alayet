ANSWER KEY — Integration Lesson 39 Test: Parametric & Polar

1. x = 2t, y = t − 3, t in [0, 4]. (a) Points at t = 0, 2, 4. (b) Eliminate the parameter; name the curve.
Work: (a) t = 0 → (0, −3); t = 2 → (4, −1); t = 4 → (8, 1). (b) From x = 2t, t = x/2; substitute: y = x/2 − 3. All three points satisfy it (e.g. 8/2 − 3 = 1 ✓). Answer: (a) (0, −3), (4, −1), (8, 1)   (b) y = x/2 − 3 — a straight line of slope ½, traced from (0, −3) to (8, 1).
2. x = t², y = 8t. (a) dx/dt and dy/dt. (b) Speed at t = 3.
Work: (a) dx/dt = 2t, dy/dt = 8. (b) At t = 3: dx/dt = 2(3) = 6, dy/dt = 8. Speed = √(6² + 8²) = √(36 + 64) = √100 = 10. (A 3-4-5 triangle doubled: 6-8-10.) Answer: (a) dx/dt = 2t, dy/dt = 8   (b) speed = 10. Grader note: the components must be evaluated at t = 3 BEFORE applying Pythagoras; √((2t)² + 8²) left in terms of t earns partial credit only.
3. x = 5t + 2, y = 12t − 1. (a) Show the speed is constant and find it. (b) Distance travelled from t = 1 to t = 4.
Work: (a) dx/dt = 5 and dy/dt = 12 — both constants, no t appears, so the speed cannot change: speed = √(5² + 12²) = √(25 + 144) = √169 = 13 at every time. (The +2 and −1 only shift the starting point; they vanish when differentiated.)
(b) L = ∫14 13 dt = 13·(4 − 1) = 39. Check with straight-line geometry: at t = 1 the point is (7, 11); at t = 4 it is (22, 47); Δx = 15, Δy = 36, distance = √(225 + 1296) = √1521 = 39 ✓. Answer: (a) speed = 13 always   (b) distance = 39. Grader note: in (b) the elapsed time is 4 − 1 = 3, not 4 (the classic "wrong width" slip).
4. x = 3cos t, y = 3sin t, t in [0, 2π]. (a) Speed. (b) Distance. (c) Circumference check.
Work: (a) dx/dt = −3 sin t, dy/dt = 3 cos t. Speed = √(9sin²t + 9cos²t) = √(9(sin²t + cos²t)) = √(9·1) = 3, constant (using the Pythagorean identity sin²t + cos²t = 1).
(b) L = ∫02π 3 dt = 3·2π = 6π.
(c) The path is the circle of radius 3 (x² + y² = 9cos²t + 9sin²t = 9), whose circumference is 2πr = 2π·3 = 6π ✓ — one lap exactly. Answer: (a) speed = 3   (b) 6π   (c) matches the circumference 2π(3) = 6π.
5. x = 4cos 2t, y = 4sin 2t, t in [0, 2π]. (a) Speed. (b) Distance. (c) Why is it more than 8π? (d) When is the first lap finished?
Work: (a) chain rule: dx/dt = −8 sin 2t, dy/dt = 8 cos 2t. Speed = √(64sin²2t + 64cos²2t) = √(64·1) = 8, constant.
(b) L = ∫02π 8 dt = 8·2π = 16π.
(c) The point stays on the radius-4 circle (x² + y² = 16cos²2t + 16sin²2t = 16), circumference 8π. Since 16π = 2 × 8π, the point goes around TWICE: the inner "2t" makes the angle sweep at double rate, and ∫ speed dt counts every bit of motion, including re-traced ground.
(d) A lap is finished when the angle 2t reaches 2π → t = π. Check: from t = 0 to π the distance is 8π = one circumference ✓. Answer: (a) 8   (b) 16π   (c) it laps the circle twice (16π = 2 · 8π)   (d) at t = π. Grader note: forgetting the chain-rule factor 2 gives speed 4 and distance 8π — method credit only.
6. x = 3t², y = 2t³, t in [0, √3]. Exact distance travelled.
Work: dx/dt = 6t, dy/dt = 6t². Speed² = 36t² + 36t⁴ = 36t²(1 + t²), so speed = √(36t²(1+t²)) = 6t√(1 + t²) (valid since t ≥ 0, so √(36t²) = 6t).
L = ∫0√3 6t√(1 + t²) dt. Let u = 1 + t², du = 2t dt → 6t dt = 3 du. New limits: t = 0 → u = 1; t = √3 → u = 1 + 3 = 4.
L = 3∫14 √u du = 3·[ (2/3)u3/2 ]14 = 2[ u3/2 ]14 = 2(43/2 − 13/2) = 2(8 − 1) = 14.
Checks: 43/2 = (√4)³ = 2³ = 8 ✓; d/dt[2(1 + t²)3/2] = 2·(3/2)(1+t²)1/2·2t = 6t√(1+t²) ✓ (the original speed). Answer: distance = 14. Grader note: limits must be converted to u (or the antiderivative converted back to t); using u-limits 0 and √3 gives a wrong answer.
7. (a) r = 4. (b) θ = π/6. (c) (x, y) of the polar point (4, π/6). (d) Table of r = 2 + 2cos θ; name the curve.
Work: (a) All points at distance 4 from the origin, any angle: a circle of radius 4 centred at the origin.
(b) All points at angle π/6 (30°) from due east, any distance: a ray from the origin heading up-and-right.
(c) x = r cos θ = 4cos(π/6) = 4·(√3/2) = 2√3; y = r sin θ = 4sin(π/6) = 4·(1/2) = 2. Check: x² + y² = 12 + 4 = 16 = 4² ✓ (distance 4, as it must be).
(d) θ = 0 → r = 2 + 2(1) = 4; θ = π/2 → r = 2 + 2(0) = 2; θ = π → r = 2 + 2(−1) = 0; θ = 3π/2 → r = 2 + 2(0) = 2. Fat side (r = 4) due east, pinching to the origin at due west: a cardioid (heart curve) pointing east. Answer: (a) circle of radius 4   (b) ray at angle π/6   (c) (2√3, 2)   (d) r = 4, 2, 0, 2 — a cardioid opening east.
8. (a) Area inside r = 6 for θ from 0 to 2π, checked against πr². (b) Area swept for θ from 0 to π/2.
Work: (a) A = ½∫02π 6² dθ = ½∫02π 36 dθ = ½·36·2π = 36π. Geometry: πr² = π·6² = 36π ✓ — the pizza-wedge machine agrees with elementary geometry.
(b) A = ½∫0π/2 36 dθ = ½·36·(π/2) = 9π. Expected fraction: sweeping π/2 out of 2π is one quarter of the circle, and 36π/4 = 9π ✓. Answer: (a) 36π   (b) 9π, exactly one quarter of 36π. Grader note: the limits in polar area are ANGLES, and they control what fraction of the shape is measured.
9. Exact area inside r = 2cos θ, sweeping −π/2 to π/2; justify the limits and show every half-angle step.
Work — why these limits: r = 2cos θ equals 0 at θ = −π/2 and again at θ = π/2, and it is positive in between; the whole circle is drawn exactly once over [−π/2, π/2]. Continuing on to 2π would re-trace the same circle and double-count every wedge.
Set up: A = ½∫−π/2π/2 (2cos θ)² dθ = ½∫−π/2π/2 4cos²θ dθ = 2∫−π/2π/2 cos²θ dθ.
Half-angle identity: cos²θ = (1 + cos 2θ)/2. Verify: at θ = 0, left = 1 and right = (1 + cos 0)/2 = (1+1)/2 = 1 ✓; at θ = π/2, left = 0 and right = (1 + cos π)/2 = (1 − 1)/2 = 0 ✓.
Substitute: 2∫−π/2π/2 (1 + cos 2θ)/2 dθ = ∫−π/2π/2 (1 + cos 2θ) dθ.
Antiderivative: θ + (sin 2θ)/2 (linear-inside rule: ∫cos 2θ dθ = (sin 2θ)/2). Check: d/dθ[θ + (sin 2θ)/2] = 1 + cos 2θ ✓.
Evaluate: at θ = π/2: π/2 + (sin π)/2 = π/2 + 0 = π/2. At θ = −π/2: −π/2 + (sin(−π))/2 = −π/2 + 0 = −π/2. Difference = π/2 − (−π/2) = π.
Geometry check: r = 2cos θ is the circle of radius 1 centred at (1, 0), so its area is π·1² = π ✓. Answer: A = π. Grader note: sweeping 0 to 2π gives 2π — exactly double, the fingerprint of double-counting.
10. (a) Student writes A = ∫02π 5 dθ = 10π for r = 5. (b) Student gets 9π/2 for r = 3cos θ instead of 9π/4.
Work: (a) Error: the student integrated r dθ instead of ½r² dθ — the polar slice is a pizza WEDGE, not a rectangle. A wedge of angle dθ is the fraction dθ/(2π) of the whole circle, so its area is (dθ/2π)·πr² = ½r² dθ. The quantity r dθ is the LENGTH of the little arc, not an area (note 10π even has units of length, not area).
Correct: A = ½∫02π 5² dθ = ½∫02π 25 dθ = ½·25·2π = 25π, matching π·5² = 25π ✓.
(b) Error: here the formula is right but the LIMITS are wrong. r = 3cos θ traces its entire circle as θ runs from −π/2 to π/2; over [0, 2π] the curve is traced twice, so every wedge is counted twice — which is why the student's answer is exactly double the truth.
Correct: A = ½∫−π/2π/2 (3cos θ)² dθ = (9/2)∫−π/2π/2 cos²θ dθ. Half-angle: cos²θ = (1 + cos 2θ)/2, so this is (9/2)∫−π/2π/2 (1 + cos 2θ)/2 dθ = (9/4)[ θ + (sin 2θ)/2 ]−π/2π/2 = (9/4)[(π/2 + 0) − (−π/2 + 0)] = (9/4)·π = 9π/4.
Geometry check: r = 3cos θ is the circle of radius 3/2 centred at (3/2, 0), area π(3/2)² = 9π/4 ✓. (And the student's 9π/2 is exactly 2 × 9π/4 ✓.) Answer: (a) used ∫r dθ instead of ½∫r² dθ (that integrand is arc length); correct area 25π.   (b) limits [0, 2π] trace the circle twice; correct area 9π/4 using θ from −π/2 to π/2.
Grader note: full credit needs the ERROR NAMED in each part, not just the corrected number. These are the two classic polar-area mistakes: missing ½r², and limits that re-trace the curve.
