ANSWER KEY — Integration Lesson 23 Test: The Trapezoidal Rule

For the grader · full working shown · give credit for correct method with small arithmetic slips

1. Trapezoid with left side 5, right side 9, width 4. Find its area.
Work: A = ½(y_left + y_right)·Δx = ½(5 + 9)(4) = ½(14)(4) = 28. (Average height 7 × width 4 = 28 ✓.) Answer: 28.
2. f(2) = 6, f(6) = 10. One trapezoid for ∫₂⁶ f(x) dx.
Work: width = 6 − 2 = 4 (end minus start — using 6 as the width is the classic slip). Estimate = ½(6 + 10)(4) = ½(16)(4) = 32. Answer: ≈ 32.
3. Two trapezoids (Δx = 1) for ∫₀² x² dx; bigger or smaller than 8/3?
Work: ½(0 + 1)(1) + ½(1 + 4)(1) = 0.5 + 2.5 = 3. Since 3 > 8/3 ≈ 2.667, it's an overestimate — x² is concave up, so the trapezoid tops (chords) sit above the curve. Answer: 3, an overestimate. (Credit the direction only with the estimate 3 correct.)
4. Left sum 12, right sum 20, equal widths. Trapezoid sum?
Work: trapezoid sum = average of left and right sums: T = (L + R)/2 = (12 + 20)/2 = 16. Condition: all slices must have EQUAL widths. Answer: 16, using T = (L + R)/2, valid only for equal widths. (Half credit if the 16 appears without the condition when asked.)
5. Three trapezoids (Δx = 1) for ∫₀³ x² dx; true value; error.
Work: heights 0, 1, 4, 9. Trapezoids: ½(0+1)(1) + ½(1+4)(1) + ½(4+9)(1) = 0.5 + 2.5 + 6.5 = 9.5. True value: x³/3 |₀³ = 27/3 = 9. Error = 9.5 − 9 = 0.5. Answer: estimate 9.5, true value 9, off by 0.5 (over).
6. Velocity table t: 0, 2, 6, 9; v: 5, 11, 15, 9. Trapezoidal estimate of ∫₀⁹ v dt.
Work: unequal widths (2, 4, 3) — each trapezoid separately: ½(5 + 11)·2 = 8·2 = 16; ½(11 + 15)·4 = 13·4 = 52; ½(15 + 9)·3 = 12·3 = 36. Total = 16 + 52 + 36 = 104. Units: (m/s)·s = meters. Answer: ≈ 104 meters (approximate distance traveled). (Watch for the averaging-left-and-right shortcut — it is NOT valid here.)
7. Water table t: 0, 5, 8, 12; R: 4, 10, 14, 6. Total water added.
Work: widths 5, 3, 4: ½(4 + 10)·5 = 7·5 = 35; ½(10 + 14)·3 = 12·3 = 36; ½(14 + 6)·4 = 10·4 = 40. Total = 35 + 36 + 40 = 111. Units: (gal/min)·min = gallons. Answer: ≈ 111 gallons.
8. g concave up on [1, 7] — trapezoid sum over- or underestimate? Justify.
Work: each trapezoid's top is a CHORD of the graph. A concave-up curve sags below its chords (cup shape ∪), so every trapezoid top lies above the curve and each trapezoid holds slightly more area than the region under the curve. Answer: overestimate, because for a concave-up function the chords (trapezoid tops) lie above the curve. (Full credit requires the concavity–chord connection, not just the word "overestimate".)
9. ∫₀² x³ dx, two slices: trapezoid vs midpoint vs true value.
Work: Trapezoid: ½(0 + 1)(1) + ½(1 + 8)(1) = 0.5 + 4.5 = 5. Midpoint: (f(0.5) + f(1.5))(1) = (0.125 + 3.375) = 3.5. True: x⁴/4 |₀² = 16/4 = 4. Errors: trapezoid 5 − 4 = 1 (over); midpoint 4 − 3.5 = 0.5 (under). Answer: T = 5, M = 3.5, true = 4; midpoint is closer.
10. Cars table t: 0, 3, 7, 10; R: 40, 60, 50, 30. (a) Trapezoidal estimate. (b) Meaning with units.
Work: (a) widths 3, 4, 3: ½(40 + 60)·3 = 50·3 = 150; ½(60 + 50)·4 = 55·4 = 220; ½(50 + 30)·3 = 40·3 = 120. Total = 150 + 220 + 120 = 490. (b) Units: (cars/hour)·hours = cars. Answer: (a) ≈ 490   (b) approximately 490 cars passed the checkpoint during the 10 hours from t = 0 to t = 10. (Meaning sentence must mention the quantity, the units, and the time interval for the point.)
