ANSWER KEY — Integration Lesson 35 Test: Volumes II — Off-Axis & Cross-Sections

For the grader · full working shown · give credit for a correct setup with small arithmetic slips · setup-only questions earn full credit with no evaluation

1. (a) y = √x revolved about y = −3: radius at x? (b) About y = 6 (curve below): radius?
Work: radius = distance from the spin line to the curve. (a) Line below curve: r = √x − (−3) = √x + 3. (b) Line above curve: r = 6 − √x. Answer: (a) r = √x + 3   (b) r = 6 − √x.
2. Region between y = x and y = −1, 0 ≤ x ≤ 3, revolved about y = −1. Volume?
Work: region touches the spin line → full disks, radius = x + 1. V = π∫₀³ (x + 1)² dx = π[(x + 1)³/3]₀³ = π(64/3 − 1/3) = 63π/3. Answer: V = 21π.
3. Region between y = √x and y = −2, 0 ≤ x ≤ 1, revolved about y = −2. Volume?
Work: radius = √x + 2. Expand: (√x + 2)² = x + 4√x + 4 (don't drop the middle term!). V = π∫₀¹ (x + 4√x + 4) dx = π[x²/2 + (8/3)x3/2 + 4x]₀¹ = π(1/2 + 8/3 + 4) = π(3/6 + 16/6 + 24/6). Answer: V = 43π/6.
4. Region bounded by x = y², the y-axis, and y = 3, revolved about the y-axis. Volume?
Work: horizontal slices: disk radius x(y) = y². V = π∫₀³ (y²)² dy = π∫₀³ y⁴ dy = π[y⁵/5]₀³ = π·243/5. Answer: V = 243π/5.
5. Base between y = x and the x-axis on [0, 3]; square cross-sections. Volume?
Work: footprint w(x) = x, slice area A = w² = x² (NO π — squares aren't circles). V = ∫₀³ x² dx = [x³/3]₀³ = 27/3. Answer: V = 9. (Writing 9π loses the point.)
6. Base between y = √x and the x-axis on [0, 2]; semicircle cross-sections (diameter on base). Volume?
Work: diameter w = √x → radius w/2 → A = ½π(w/2)² = (π/8)w² = (π/8)x. V = (π/8)∫₀² x dx = (π/8)[x²/2]₀² = (π/8)(2). Answer: V = π/4.
7. Region bounded by y = x, y = 3, and the y-axis, revolved about y = 3. Volume + cone check.
Work: spin line above the region: radius = 3 − x, from x = 0 to 3. V = π∫₀³ (3 − x)² dx = π[−(3 − x)³/3]₀³ = π(0 − (−27/3)) = 9π. Cone check: radius 3, height 3 → ⅓π(3²)(3) = 9π ✓. Answer: V = 9π.
8. Region between y = √x and the x-axis on [0, 4], revolved about y = −2. Set up only.
Work: the region floats 2 units above the spin line → washers. Outer radius = √x + 2 (curve to line); inner radius = 0 − (−2) = 2 (x-axis to line). Answer: V = π∫₀⁴ [(√x + 2)² − 2²] dx. (No evaluation required. Common error: forgetting the inner radius 2 and writing a disk integral.)
9. Base between y = 3 and y = x on [0, 3]; equilateral-triangle cross-sections. Volume?
Work: footprint w(x) = 3 − x; equilateral area A = (√3/4)w². V = (√3/4)∫₀³ (3 − x)² dx = (√3/4)[−(3 − x)³/3]₀³ = (√3/4)(27/3) = (√3/4)(9). Answer: V = 9√3/4.
10. Same base: Solid A (squares) has V = 10; Solid B has semicircles. (a) Volume of B? (b) Why no π in A?
Work: (a) Both volumes = (shape constant)·∫w² dx over the same base, so ∫w² dx = 10 for squares (constant 1). Semicircles use constant π/8: V_B = (π/8)(10). Answer: (a) V = 5π/4. (b) π only enters a volume through the area of a circular slice (πr²); a square's area w² has no π, so none can appear.
