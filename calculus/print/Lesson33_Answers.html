ANSWER KEY — Integration Lesson 33 Test: Improper Integrals

For the grader · full working shown · full credit needs the limit written out, not ∞ plugged in as a number

1. Find each limit: (a) limb→∞ 1/b²   (b) limb→∞ (4 + 1/b)   (c) limb→∞ ln b
Work: (a) 1/b² shrinks to nothing as b grows (1/100, 1/10000, ...) → 0. (b) the 1/b piece fades to 0, leaving the 4 → 4. (c) ln b climbs slowly but never stops → ∞ (no finite limit). Answer: (a) 0   (b) 4   (c) ∞.
2. Evaluate ∫₁^∞ 1/x⁵ dx.
Work: antiderivative of x−5 is x−4/(−4) = −1/(4x⁴). So ∫₁^b = [−1/(4x⁴)]₁^b = −1/(4b⁴) + 1/4. As b → ∞, 1/(4b⁴) → 0, so the limit is 1/4. (p-rule check: p = 5 > 1, value 1/(5−1) = 1/4 ✓.) Answer: converges to 1/4.
3. Evaluate ∫₃^∞ 1/x² dx.
Work: ∫₃^b 1/x² dx = [−1/x]₃^b = −1/b + 1/3. As b → ∞, −1/b → 0, leaving 1/3. (The p-rule value 1/(p−1) = 1 is only for a lower limit of 1 — starting at 3 skips the fattest part of the tail.) Answer: converges to 1/3.
4. Show that ∫₁^∞ 1/x1/3 dx diverges, and explain why.
Work: ∫x−1/3 dx = x2/3/(2/3) = (3/2)x2/3. So ∫₁^b = (3/2)b2/3 − 3/2 → ∞ as b → ∞. Why: shrinking to 0 isn't enough — the tail must shrink FAST ENOUGH, and 1/x1/3 shrinks even more slowly than the borderline 1/x (p = 1/3 ≤ 1). Answer: diverges — the tail is too fat.
5. Evaluate ∫₀^∞ e−3x dx.
Work: antiderivative of e−3x is e−3x/(−3) = −⅓e−3x. So ∫₀^b = [−⅓e−3x]₀^b = −⅓e−3b + ⅓. As b → ∞, e−3b → 0, leaving ⅓. Answer: converges to 1/3.
6. p-rule: (a) ∫₁^∞ 1/x⁶ dx   (b) ∫₁^∞ 1/x0.8 dx
Work: the p-rule: ∫₁^∞ 1/x^p dx converges exactly when p > 1, with value 1/(p−1). (a) p = 6 > 1 → converges to 1/(6−1) = 1/5. (b) p = 0.8 ≤ 1 → diverges. Answer: (a) converges to 1/5   (b) diverges.
7. Evaluate ∫₀⁹ 1/√x dx.
Work: spike at x = 0, so use a wall at a: ∫ₐ⁹ x−1/2 dx = [2√x]ₐ⁹ = 2·3 − 2√a = 6 − 2√a. As a → 0⁺, √a → 0, so the limit is 6. An infinitely tall spike with area exactly 6. Answer: converges to 6.
8. Show that ∫₀¹ 1/x dx diverges.
Work: ∫ₐ¹ 1/x dx = [ln x]ₐ¹ = ln 1 − ln a = −ln a. As a → 0⁺, ln a → −∞, so −ln a → +∞ (check: a = 0.001 gives −ln 0.001 ≈ 6.9; a = 10⁻⁹ gives ≈ 20.7 — it keeps climbing). The area never settles. Answer: diverges — the spike at 0 is too fat.
9. What does CONVERGE mean, and how can an infinitely long region have finite area?
Work (sample answer): converge means: as the wall b slides out to infinity, the areas ∫₁^b head toward one fixed finite number — that number is the area. It's possible because the curve's tail shrinks so fast that each new stretch adds almost nothing: for 1/x², the area up to b is 1 − 1/b (0.9, then 0.99, then 0.999...), settling at exactly 1. Like 1/2 + 1/4 + 1/8 + ... = 1, infinitely many pieces can total a finite amount. Give credit for: "the running area settles toward one number because the added slivers shrink fast enough."
10. Challenge: evaluate ∫₂^∞ 1/(x(x−1)) dx.
Work: partial fractions: 1/(x(x−1)) = A/x + B/(x−1) → 1 = A(x−1) + Bx. At x = 0: A = −1; at x = 1: B = 1. So the integrand is 1/(x−1) − 1/x. Then ∫₂^b = [ln(x−1) − ln x]₂^b = [ln((x−1)/x)]₂^b = ln((b−1)/b) − ln(1/2). As b → ∞, (b−1)/b → 1, so ln((b−1)/b) → ln 1 = 0. Total: 0 − ln(1/2) = ln 2 ≈ 0.693. Answer: converges to ln 2.
