ANSWER KEY — Integration Lesson 37 Test: Differential Equations I

For the grader · full working shown · give credit for correct method with small arithmetic slips · dock a point for two separate constants or a missing ± choice

1. Verify that y = x² + 7 is a solution of dy/dx = 2x.
Work: left side: (x² + 7)′ = 2x. Right side: 2x. The sides are equal for every x. Answer: verified — both sides equal 2x, so y = x² + 7 is a solution.
2. Verify that y = e^(5x) is a solution of dy/dx = 5y.
Work: left side: (e^(5x))′ = 5e^(5x) (chain rule). Right side: 5y = 5·e^(5x) = 5e^(5x). Equal for all x. Answer: verified — both sides equal 5e^(5x).
3. Show that y = x² is NOT a solution of dy/dx = 2y.
Work: left side: (x²)′ = 2x. Right side: 2y = 2x². Is 2x = 2x² for all x? Test x = 2: left = 4, right = 8 — unequal. (Agreement at the special points x = 0 and x = 1 is not enough; a solution must work at EVERY x.) Answer: not a solution — 2x ≠ 2x² in general (e.g. at x = 2).
4. Solve dy/dx = 3y (general solution).
Work: separate: dy/y = 3 dx. Integrate: ln|y| = 3x + C. Exponentiate: |y| = e^C·e^(3x); absorb ±e^C into a single constant C. Check: (Ce^(3x))′ = 3Ce^(3x) = 3y ✓. Answer: y = Ce^(3x).
5. Solve dy/dx = 3x²/y in the form y² = ...
Work: separate: y dy = 3x² dx. Integrate: y²/2 = x³ + C. Multiply by 2 (C eats the 2): y² = 2x³ + C. Check implicitly: 2y·dy/dx = 6x² → dy/dx = 3x²/y ✓. Answer: y² = 2x³ + C. (Accept y²/2 = x³ + C; dock for two constants.)
6. Solve dy/dx = x/y with y(0) = 6.
Work: y dy = x dx → y²/2 = x²/2 + C → y² = x² + C. Plug in (0, 6): 36 = 0 + C → y² = x² + 36. Then y = ±√(x² + 36); since y(0) = 6 > 0, take the + root. Check: dy/dx = x/√(x² + 36) = x/y ✓, y(0) = √36 = 6 ✓; defined for all x. Answer: y = √(x² + 36), the positive root because y(0) = 6 > 0.
7. Solve dy/dx = 4xy with y(0) = 2.
Work: separate: dy/y = 4x dx. Integrate: ln|y| = 2x² + C. Exponentiate: y = Ce^(2x²). Initial condition: 2 = C·e^0 = C. Check: (2e^(2x²))′ = 2e^(2x²)·4x = 4x·y ✓, y(0) = 2 ✓. Answer: y = 2e^(2x²).
8. Columns identical, flat segments exactly on x = 0 — which DE fits?
Work: identical columns means moving up/down changes nothing, so the slope depends on x ONLY — the DE has the form dy/dx = f(x). That rules out dy/dx = y and dy/dx = xy (both change along a column; and xy is zero on BOTH axes, not just x = 0). dy/dx = x depends on x alone and is zero exactly when x = 0. Answer: dy/dx = x — slope depends on x only, zero precisely on the line x = 0.
9. For dy/dx = y(x − 1): where is the field flat, and what is the equilibrium solution?
Work: y(x − 1) = 0 when y = 0 (the whole x-axis) or x = 1 (the whole vertical line). Equilibrium: the constant function y = 0. Check: left side (0)′ = 0; right side 0·(x − 1) = 0 ✓ — a solution that starts at height 0 stays there forever. Answer: flat along y = 0 and along x = 1; the equilibrium solution is y = 0.
10. dy/dx = −x/y: (a) zero/undefined slopes, (b) solution with y(0) = −4, (c) domain.
Work: (a) slope −x/y = 0 where x = 0 (with y ≠ 0); undefined where y = 0 (division by zero — vertical tangents on the x-axis). (b) y dy = −x dx → y²/2 = −x²/2 + C → x² + y² = C; through (0, −4): C = 16 → y = ±√(16 − x²); y(0) = −4 < 0 picks the MINUS root: y = −√(16 − x²). Check: dy/dx = x/√(16 − x²) = −x/(−√(16 − x²)) = −x/y ✓, y(0) = −4 ✓. (c) Need 16 − x² > 0. Answer: (a) zero on x = 0, undefined on y = 0; (b) y = −√(16 − x²) (bottom half of the circle of radius 4); (c) −4 < x < 4.
