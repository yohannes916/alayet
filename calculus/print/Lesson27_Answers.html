ANSWER KEY — Integration Lesson 27 Test: FTC Part 2

For the grader · full working shown · give credit for correct method with small arithmetic slips · justification questions need the SIGN reasoning stated, not just the answer

1. Find d/dx ∫₃ˣ t⁴ dt.
Work: FTC Part 2: the derivative of an accumulation function is the inside function with t replaced by x. The lower limit 3 only shifts g by a constant, so it plays no role. Answer: x⁴.
2. Find d/dx ∫₀ˣ √(1 + t²) dt.
Work: straight FTC 2 — no antiderivative needed (and none exists in simple form). Replace t with x. Answer: √(1 + x²). (Deduct if the student tried to "integrate first" and got tangled — the whole point is that you don't.)
3. Let g(x) = ∫₅ˣ cos t dt. Find g(5) and g′(x).
Work: g(5) = ∫₅⁵ cos t dt = 0, because an integral from a number to itself has zero width — nothing has accumulated at the starting line. g′(x) = cos x by FTC 2. Answer: g(5) = 0 and g′(x) = cos x.
4. What is wrong with g(x) = ∫₀ˣ x³ dx? Write it correctly.
Work: the letter x is doing two jobs at once: it is the fixed upper limit (where to stop) AND the sweeping integration variable (which must run from 0 up to the stopping point). One letter cannot both stand still and move, so the expression is ambiguous. Correct: g(x) = ∫₀ˣ t³ dt — t is a dummy variable that sweeps and vanishes (like the index k in sigma notation); x is the real input. Grader note: full credit requires BOTH the "two jobs / dummy variable" explanation and the corrected notation.
5. Find d/dx ∫₀^(x²) cos t dt.
Work: the upper limit is x², a function of x → chain rule. Plug the limit into f: cos(x²); multiply by its derivative: 2x. Answer: 2x·cos(x²). (Common error: cos(x²) alone — that misses the chain-rule factor and earns half credit at most.)
6. Find d/dx ∫₂^(x³) √(1 + t) dt.
Work: plug the upper limit x³ into f: √(1 + x³); multiply by d/dx(x³) = 3x². The lower limit 2 is irrelevant. Answer: 3x²·√(1 + x³).
7. Find d/dx ∫ₓ⁴ (t³ + 1) dt.
Work: the variable is in the LOWER limit. Flip the limits and the sign: ∫ₓ⁴ = −∫₄ˣ. Then FTC 2: derivative = −(x³ + 1). Sense check: as x grows, the interval [x, 4] shrinks, so the total is shrinking (for positive f) — negative derivative is right. Answer: −(x³ + 1) = −x³ − 1. (Common error: forgetting the minus sign.)
8. g(x) = ∫₀ˣ (t² − 9) dt for x ≥ 0: find g(0), g′(x), g′(4), and where g is decreasing (justify).
Work: g(0) = ∫₀⁰ = 0 (zero-width integral). g′(x) = x² − 9 by FTC 2. g′(4) = 16 − 9 = 7. Decreasing: g′(x) = x² − 9 = (x − 3)(x + 3) < 0 for 0 ≤ x < 3. Answer: g(0) = 0; g′(x) = x² − 9; g′(4) = 7; g is decreasing on (0, 3) because g′(x) = x² − 9 is negative there. Grader note: the justification must mention the SIGN of g′ (or of f) — "because the graph goes down" earns nothing on the AP.
9. g(x) = ∫₁ˣ 3t² dt: tangent line to g at x = 2.
Work: Point: by FTC 1 with antiderivative t³, g(2) = 2³ − 1³ = 8 − 1 = 7 → point (2, 7). Slope: g′(x) = 3x² by FTC 2, so g′(2) = 12. Line: y = 7 + 12(x − 2). Answer: y = 7 + 12(x − 2), i.e. y = 12x − 17. (Either form is full credit; point-slope form is fine.)
10. A student wrote d/dx ∫₀^(3x) sin t dt = sin(3x). Find and fix the error.
Work: the upper limit is 3x, not plain x, so the chain rule requires multiplying by d/dx(3x) = 3. The student forgot the chain-rule factor. Correct: sin(3x) · 3. Check the long way: ∫₀^(3x) sin t dt = 1 − cos(3x), whose derivative is 3 sin(3x). ✓ Answer: missing chain-rule factor; correct derivative is 3 sin(3x). Grader note: require the one-sentence explanation naming the chain rule (or "derivative of the upper limit"), not just the fixed answer.
