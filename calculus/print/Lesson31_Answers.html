ANSWER KEY — Integration Lesson 31 Test: Integration by Parts II

For the grader · full working shown · give credit for correct method with small arithmetic slips · "+ C" required on indefinite integrals

1. Find ∫ x e2x dx.
Work: parts with u = x, dv = e2x dx → du = dx, v = e2x/2. So ∫ = x·(e2x/2) − ∫ e2x/2 dx = (x/2)e2x − e2x/4 + C. Check by differentiating: e2x/2 + x e2x − e2x/2 = x e2x ✓. Answer: (x/2)e2x − (1/4)e2x + C.
2. Find ∫ 3x cos x dx.
Work: pull out the 3, then parts with u = x, dv = cos x dx → du = dx, v = sin x: 3[x sin x − ∫ sin x dx] = 3[x sin x + cos x] + C. Check: 3 sin x + 3x cos x − 3 sin x = 3x cos x ✓. Answer: 3x sin x + 3 cos x + C.
3. u-sub or parts? Then solve: ∫ x sin(x²) dx.
Work: u-substitution — the inside function x² has fingerprint 2x dx, and x dx is present. u = x² → du = 2x dx → ∫ = (1/2)∫ sin u du = −(1/2)cos u + C. Check: derivative of −(1/2)cos(x²) is −(1/2)(−sin(x²))(2x) = x sin(x²) ✓. (Parts would make this worse — always check for the fingerprint first.) Answer: u-sub; −(1/2) cos(x²) + C.
4. Find ∫ (x² + 1) eˣ dx.
Work: split: ∫ x²eˣ dx + ∫ eˣ dx. Parts twice on the first: pass 1 (u = x²): x²eˣ − 2∫ x eˣ dx; pass 2: ∫ x eˣ dx = x eˣ − eˣ. So ∫ x²eˣ dx = x²eˣ − 2xeˣ + 2eˣ. Add ∫ eˣ dx = eˣ. Total: x²eˣ − 2xeˣ + 3eˣ + C = eˣ(x² − 2x + 3) + C. Check: derivative = eˣ(x² − 2x + 3) + eˣ(2x − 2) = eˣ(x² + 1) ✓. Answer: eˣ(x² − 2x + 3) + C.
5. Find ∫ ln(2x) dx.
Work: u = ln(2x), dv = dx → du = (1/(2x))·2 dx = (1/x) dx (chain rule), v = x. So ∫ = x ln(2x) − ∫ x·(1/x) dx = x ln(2x) − ∫ 1 dx = x ln(2x) − x + C. Check: ln(2x) + x·(1/x) − 1 = ln(2x) ✓. Answer: x ln(2x) − x + C.
6. Find ∫ x³ ln x dx.
Work: LIATE: Log beats Algebraic, so u = ln x, dv = x³ dx → du = (1/x) dx, v = x⁴/4. ∫ = (x⁴/4) ln x − ∫ (x⁴/4)(1/x) dx = (x⁴/4) ln x − ∫ x³/4 dx = (x⁴/4) ln x − x⁴/16 + C. Check: x³ ln x + (x⁴/4)(1/x) − x³/4 = x³ ln x + x³/4 − x³/4 = x³ ln x ✓. Answer: (x⁴/4) ln x − x⁴/16 + C.
7. Compute ∫1e² ln x dx exactly.
Work: antiderivative of ln x is x ln x − x (parts with dv = dx). Evaluate: at x = e²: e²·ln(e²) − e² = e²·2 − e² = e². At x = 1: 1·ln 1 − 1 = 0 − 1 = −1. Subtract: e² − (−1) = e² + 1 ≈ 8.39. Answer: e² + 1.
8. Compute ∫0π/2 x cos x dx exactly.
Work: antiderivative (parts, u = x): x sin x + cos x. At π/2: (π/2)·sin(π/2) + cos(π/2) = π/2·1 + 0 = π/2. At 0: 0·sin 0 + cos 0 = 0 + 1 = 1. Subtract: π/2 − 1 ≈ 0.571. Answer: π/2 − 1.
9. Compute ∫01 x eˣ dx exactly.
Work: antiderivative: x eˣ − eˣ. At 1: 1·e − e = 0. At 0: 0 − e⁰ = −1. Subtract: 0 − (−1) = 1. The e's cancel completely — the area under y = x eˣ from 0 to 1 is exactly 1. Answer: 1.
10. Challenge: ∫ x³ cos x dx by the tabular method.
Work: D column (differentiate to 0): x³ → 3x² → 6x → 6 → 0. I column (antidifferentiate repeatedly): cos x → sin x → −cos x → −sin x → cos x. Diagonal products (each D entry × the I entry one row lower), signs +, −, +, −:   +x³·sin x,   −3x²·(−cos x) = +3x² cos x,   +6x·(−sin x) = −6x sin x,   −6·(cos x) = −6 cos x. Check by differentiating: (3x² sin x + x³ cos x) + (6x cos x − 3x² sin x) − (6 sin x + 6x cos x) + 6 sin x = x³ cos x ✓. Answer: x³ sin x + 3x² cos x − 6x sin x − 6 cos x + C.
