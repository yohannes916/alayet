ANSWER KEY — Integration Lesson 25 Test: Inverse Trig Antiderivatives

For the grader · full working shown · give credit for correct method with small slips · a missing + C on an indefinite integral costs the point only if it happens repeatedly

1. Evaluate exactly: (a) arctan 1 (b) arcsin(1/2) (c) arctan 0.
Work: read the trig table backward. (a) tan(π/4) = 1 → arctan 1 = π/4. (b) sin(π/6) = 1/2 → arcsin(1/2) = π/6. (c) tan 0 = 0 → arctan 0 = 0. Answer: (a) π/4 (b) π/6 (c) 0. (Grader: answers must be in radians; 45° etc. gets half credit at most.)
2. Find ∫ 1/(1+x²) dx.
Work: this is the boxed arctan fact — power rule can't apply (bottom is a sum), u-sub has no du = 2x dx available. Answer: arctan x + C. (Grader: ln(1+x²) + C is the classic wrong answer — its derivative is 2x/(1+x²), not 1/(1+x²).)
3. Find ∫ 3/√(1−x²) dx.
Work: constant-multiple rule + the arcsin fact: 3 ∫ 1/√(1−x²) dx = 3 arcsin x. Check: (3 arcsin x)′ = 3/√(1−x²) ✓. Answer: 3 arcsin x + C.
4. Compute exactly: ∫₁^√3 1/(1+x²) dx.
Work: [arctan x]₁^√3 = arctan √3 − arctan 1 = π/3 − π/4 = 4π/12 − 3π/12 = π/12. Answer: π/12. (Grader: subtracting in the wrong order gives −π/12 — a negative area for a positive function should have triggered a sanity alarm.)
5. Compute exactly: ∫₀^(√3/2) 1/√(1−x²) dx.
Work: [arcsin x]₀^(√3/2) = arcsin(√3/2) − arcsin 0 = π/3 − 0. Answer: π/3.
6. Find ∫ 1/(16+x²) dx.
Work: a² = 16 → a = 4; a-form gives (1/a) arctan(x/a): (1/4) arctan(x/4) + C. Check: derivative = (1/4)·1/(1+x²/16)·(1/4) = (1/16)·16/(16+x²) = 1/(16+x²) ✓. Answer: (1/4) arctan(x/4) + C. (Grader: forgetting the front 1/4 is the #1 slip — take the point.)
7. Compute exactly: ∫₀^√2 1/√(4−x²) dx.
Work: a = 2, antiderivative arcsin(x/2) (no front factor for arcsin). [arcsin(x/2)]₀^√2 = arcsin(√2/2) − arcsin 0 = π/4 − 0. Answer: π/4.
8. Three lookalikes: (a) ∫ x/(1+x²) dx (b) ∫ 1/(1+x)² dx (c) ∫ 1/(1+x²) dx.
Work: (a) x on top ≈ derivative of bottom → u-sub → ln: u = 1+x², x dx = du/2 → (1/2) ln(1+x²) + C. (b) square on the parenthesis → power rule: u = 1+x, ∫u⁻²du = −1/u → −1/(1+x) + C. (c) plain 1 on top, square on x alone → arctan fact → arctan x + C. Answer: (a) u-sub→ln, (1/2)ln(1+x²)+C; (b) power rule, −1/(1+x)+C; (c) arctan, arctan x + C. (Grader: ask for BOTH tool name and antiderivative; 2 of 3 fully right = half point.)
9. Verify that (1/3) arctan(x/3) is an antiderivative of 1/(9+x²).
Work: d/dx[(1/3)arctan(x/3)] = (1/3) · 1/(1+(x/3)²) · (1/3) [chain rule: inside x/3 has derivative 1/3] = (1/9) · 1/(1+x²/9) = (1/9) · 9/(9+x²) = 1/(9+x²) ✓. Answer: derivative equals 1/(9+x²), verified. (Grader: the chain-rule factor 1/3 must appear explicitly; a "verification" that never multiplies by 1/3 earns no credit.)
10. Show ∫₀¹ 8/(1+x²) dx = 2π and explain the connection to computing digits of π.
Work: 8 ∫₀¹ 1/(1+x²) dx = 8[arctan x]₀¹ = 8(π/4 − 0) = 2π ✓. Explanation: the integral is an area under a concrete curve, so a numerical method (like the trapezoidal rule) can approximate it to any accuracy WITHOUT knowing π — and since the exact value is 2π, halving the estimate manufactures π's digits from areas alone. Answer: 8 · π/4 = 2π; approximating the same area numerically yields digits of π.
