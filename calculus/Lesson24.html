Lesson 24 — Growing the Library: Tangent, Secant & Friends

🎯 Goal of this lesson: meet the other four trig functions — tangent, secant, cosecant, cotangent — all built from sin and cos. Learn their derivative facts, then read those facts backward to add four new antiderivatives to your library. Plus one famous integral, ∫ tan x dx, cracked with u-substitution.

1 Meet the other four trig functions (from scratch)

  • So far you know sin x and cos x. The other four trig functions aren't new mysteries — every one of them is just a fraction built from sin and cos:

cotangentcot xcos x / sin xtangent flipped
  • Why "slope-flavored"? On the unit circle, a ray at angle x rises sin x for every cos x it runs — so sin x / cos x is literally the ray's slope. At x = π/4 the ray points diagonally (45°), slope 1 — and sure enough, tan(π/4) = 1.
  • You can compute values instantly from the sin/cos table you already know (Lesson 18). For example: tan(π/3) = sin(π/3)/cos(π/3) = (√3/2)/(1/2) = √3, and sec(π/3) = 1/cos(π/3) = 1/(1/2) = 2. Also sec(π/4) = 1/(√2/2) = 2/√2 = √2.

  • ⚠️ Danger zones: you can't divide by zero. Since cos(π/2) = 0, both tan x and sec x are undefined at x = π/2 (and at every odd multiple of π/2). Likewise sin 0 = 0, so csc x and cot x are undefined at x = 0, π, 2π, … Near those points the graphs shoot off to infinity.

2 Their derivative facts

  • Here are the four derivative facts — memorize them as a matched set:
FunctionDerivative
tan xsec²x
sec xsec x · tan x
cot x−csc²x
csc x−csc x · cot x
  • Let's verify the first one, so it's not magic. Since tan x = sin x/cos x, we need the rule for differentiating a fraction (the quotient rule, stated informally): (top/bottom)′ = (top′·bottom − top·bottom′) / bottom².
Verifying (tan x)′ = sec²x: top = sin x (derivative cos x), bottom = cos x (derivative −sin x).
(tan x)′ = [cos x · cos x − sin x · (−sin x)] / cos²x = (cos²x + sin²x) / cos²x.
Now the most famous identity in trig — cos²x + sin²x = 1 (the point (cos x, sin x) sits on the unit circle, so its coordinates satisfy x² + y² = 1). So:
(tan x)′ = 1/cos²x = (1/cos x)² = sec²x ✓
  • The other three come from the same kind of computation. Notice the pattern: the two "co" functions (cot, csc) get minus signs — just like cos's derivative −sin x carries the minus.

3 Read them backward: four new antiderivatives

  • Every derivative fact, read right-to-left, is an antiderivative fact (Lesson 6's big move). Reading the table backward gives us four new library entries:
📚 New library entries (box these!):
∫ sec²x dx = tan x + C
∫ sec x tan x dx = sec x + C
∫ csc²x dx = −cot x + C
∫ csc x cot x dx = −csc x + C
  • Pattern to remember: the "co" versions carry minus signs. You've seen this before: ∫ cos x dx = sin x + C is clean, but ∫ sin x dx = −cos x + C needs a minus. Same story here — csc² and csc·cot answers come out negative.
  • Careful reading: ∫ csc²x dx = −cot x + C works because (−cot x)′ = −(−csc²x) = csc²x — the two minus signs cancel.

4 The check habit: differentiate every answer

  • These four are easy to garble (sign slips, swapped pairs), so always differentiate your answer — it takes five seconds and catches everything.
Example check: claim: ∫ csc x cot x dx = −csc x + C. Check: (−csc x)′ = −(−csc x · cot x) = csc x · cot x ✓ — matches what's inside the integral. Claim verified.

5 A worked definite integral

Compute ∫₀^π/4 sec²x dx.
Antiderivative: tan x. Evaluate (FTC, Lesson 8):
∫₀^π/4 sec²x dx = tan(π/4) − tan(0) = 1 − 0 = 1.
Beautifully clean — the area under the sec²x curve from 0 to π/4 is exactly 1.

6 A famous one: ∫ tan x dx (u-substitution to the rescue)

  • Tangent is NOT in the backward-reading table — nothing in our derivative list produces plain tan x. But writing tan x = sin x / cos x reveals a u-substitution setup (Lesson 16): the bottom's derivative is sitting on top!
Every step:
∫ tan x dx = ∫ (sin x / cos x) dx
Let u = cos x. Then du = −sin x dx, so sin x dx = −du.
∫ (sin x dx) / cos x = ∫ (−du)/u = −∫ (1/u) du
From Lesson 21: ∫ (1/u) du = ln|u| + C. So we get −ln|u| + C.
Substitute back: ∫ tan x dx = −ln|cos x| + C
Check: derivative of −ln|cos x| is −(1/cos x)·(−sin x) = sin x/cos x = tan x ✓

The |…| bars matter (Lesson 21): cos x is negative on part of its domain, and ln only eats positive numbers — the absolute value keeps the formula legal everywhere cos x ≠ 0.
  • Same answer, different outfit: using log rules, −ln|cos x| = ln(1/|cos x|) = ln|sec x| + C. Books write it both ways — they're identical.
  • What about ∫ sec x dx? Honest answer: it exists, but no pattern we own yet produces it — it needs a sneaky trick (coming in a later lesson). For now, sec x stays on the "wanted" poster.
✏️ Exercises — 20 problems (write your answer on paper, then reveal)
1.values
Using the definitions, find: (a) tan 0   (b) tan(π/4)   (c) sec 0.

Worked solution

Background: tan x = sin x/cos x and sec x = 1/cos x. Table values you know: sin 0 = 0, cos 0 = 1, sin(π/4) = cos(π/4) = √2/2.
(a) tan 0 = sin 0 / cos 0 = 0/1 = 0.
(b) tan(π/4) = (√2/2)/(√2/2) = 1 — sin and cos are equal there, so the ratio is 1.
(c) sec 0 = 1/cos 0 = 1/1 = 1.
(a) 0   (b) 1   (c) 1
2.values
Using the definitions, find: (a) tan(π/3)   (b) sec(π/3)   (c) sec(π/4).

Worked solution

Background: table values: sin(π/3) = √3/2, cos(π/3) = 1/2, cos(π/4) = √2/2. Dividing by a fraction = multiplying by its flip.
(a) tan(π/3) = (√3/2)/(1/2) = (√3/2)·(2/1) = √3.
(b) sec(π/3) = 1/(1/2) = 2.
(c) sec(π/4) = 1/(√2/2) = 2/√2 = √2 (multiply top and bottom by √2: 2√2/2 = √2).
(a) √3   (b) 2   (c) √2
3.danger zones
Explain why tan x and sec x are both undefined at x = π/2, and name one value of x where csc x is undefined.

Worked solution

Background: every one of the four new functions is a fraction, and a fraction breaks exactly where its bottom is zero. tan and sec have cos on the bottom; csc and cot have sin on the bottom.
cos(π/2) = 0, so tan(π/2) = sin(π/2)/cos(π/2) = 1/0 and sec(π/2) = 1/0 — division by zero, undefined.
csc x = 1/sin x breaks where sin x = 0: at x = 0 (also π, 2π, −π, …).
Both have cos x on the bottom and cos(π/2) = 0; csc is undefined at x = 0 (or any multiple of π)
4.library
Find ∫ sec²x dx.

Worked solution

Background: reading (tan x)′ = sec²x backward: the antiderivative of sec²x is tan x. Never forget the + C — every vertical shift of tan x has the same derivative.
∫ sec²x dx = tan x + C.
Check: (tan x)′ = sec²x ✓.
tan x + C
5.library
Find ∫ sec x tan x dx.

Worked solution

Background: (sec x)′ = sec x · tan x, so the product sec x tan x is exactly a derivative we recognize — read it backward.
∫ sec x tan x dx = sec x + C.
Check: (sec x)′ = sec x tan x ✓.
sec x + C
6.library · minus!
Find ∫ csc²x dx.

Worked solution

Background: the "co" pattern: (cot x)′ = −csc²x has a minus, so to land on +csc²x you must start from −cot x. Same idea as ∫ sin x dx = −cos x + C.
∫ csc²x dx = −cot x + C.
Check: (−cot x)′ = −(−csc²x) = csc²x ✓ — the two minuses cancel.
−cot x + C
7.library · minus!
Find ∫ csc x cot x dx.

Worked solution

Background: (csc x)′ = −csc x · cot x. To get rid of the unwanted minus, start from −csc x — its derivative flips the sign back to positive.
∫ csc x cot x dx = −csc x + C.
Check: (−csc x)′ = −(−csc x cot x) = csc x cot x ✓.
−csc x + C
8.mix
Find ∫ (3sec²x + sin x) dx.

Worked solution

Background: integrals split over + and constants slide out front (Lesson 7). Handle each piece with its own library entry: ∫ sec²x dx = tan x + C and ∫ sin x dx = −cos x + C (Lesson 18).
∫ 3sec²x dx = 3 tan x.   ∫ sin x dx = −cos x.
Total: 3 tan x − cos x + C.
Check: (3 tan x − cos x)′ = 3 sec²x − (−sin x) = 3 sec²x + sin x ✓.
3 tan x − cos x + C
9.mix
Find ∫ (sec²x − 2) dx.

Worked solution

Background: the constant −2 integrates to −2x (a constant rate accumulates linearly, Lesson 6). The sec²x piece comes from the library.
∫ sec²x dx = tan x, and ∫ (−2) dx = −2x.
Total: tan x − 2x + C.
Check: (tan x − 2x)′ = sec²x − 2 ✓.
tan x − 2x + C
10.check by differentiating
A student claims ∫ csc²x dx = cot x + C. Check the claim by differentiating, and fix it if it's wrong.

Worked solution

Background: the differentiate-to-check habit in action. An antiderivative claim is right exactly when its derivative equals the function inside the integral — no exceptions, no debate.
Check: (cot x)′ = −csc²x. But the integrand is +csc²x. Off by a sign — the claim is wrong.
Fix: start from −cot x instead: (−cot x)′ = csc²x ✓.
Wrong — (cot x)′ = −csc²x. Correct answer: −cot x + C

14.famous integral
Reproduce the derivation of ∫ tan x dx using u-substitution, showing every step. Then differentiate your answer to check it.

Worked solution

Background: the u-substitution signal (Lesson 16): when a fraction's bottom has its own derivative sitting on top, substitute u = the bottom. Here tan x = sin x/cos x, and the top (sin x) is one minus sign away from the bottom's derivative (−sin x).
∫ tan x dx = ∫ (sin x / cos x) dx.
Let u = cos x → du = −sin x dx → sin x dx = −du.
Substitute: ∫ (−du)/u = −∫ (1/u) du = −ln|u| + C (Lesson 21).
Back-substitute: −ln|cos x| + C. (Equivalent form: ln|sec x| + C, since −ln a = ln(1/a).)
Check: derivative of −ln|cos x| = −(1/cos x)·(−sin x) = sin x/cos x = tan x ✓.
∫ tan x dx = −ln|cos x| + C  (= ln|sec x| + C)
15.linear inside
Find ∫ sec²(2x) dx.

Worked solution

Background: the "linear inside" rule (Lesson 17): if ∫ f(x) dx = F(x) + C, then ∫ f(ax) dx = F(ax)/a + C — the chain rule would multiply by a when differentiating, so we pre-divide by a to cancel it.
Base fact: ∫ sec²x dx = tan x + C. Inside is 2x, so divide by 2:
∫ sec²(2x) dx = tan(2x)/2 + C.
Check: derivative of tan(2x)/2 = (1/2)·sec²(2x)·2 = sec²(2x) ✓.
tan(2x)/2 + C
16.linear inside
Find ∫ sec(4x) tan(4x) dx, and check your answer by differentiating.

Worked solution

Background: same linear-inside move on a different library entry: ∫ sec x tan x dx = sec x + C, so with 4x inside, divide by 4.
∫ sec(4x) tan(4x) dx = sec(4x)/4 + C.
Check: derivative of sec(4x)/4 = (1/4)·sec(4x)tan(4x)·4 = sec(4x)tan(4x) ✓ — the chain rule's 4 cancels our 1/4 exactly.
sec(4x)/4 + C
17.spot the error
A student writes ∫ sec²x dx = sec³x/3 + C, reasoning "power rule: raise the exponent, divide by it." Find the error, prove the answer wrong by differentiating it, and give the correct answer.

Worked solution

Background: the power rule ∫ xⁿ dx = xⁿ⁺¹/(n+1) + C is for powers of x itself. sec²x is a power of sec x, a whole function of x — differentiating sec³x triggers the chain rule and spits out an extra factor the student never planned for.
Test the claim: derivative of sec³x/3 = (1/3)·3sec²x·(sec x)′ = sec²x · sec x tan x = sec³x tan x.
That's sec³x tan x, nowhere near sec²x — the claim fails the check badly.
Correct answer, from the library: ∫ sec²x dx = tan x + C (check: (tan x)′ = sec²x ✓).
The power rule doesn't apply to powers of functions; correct answer: tan x + C
18.definite · exact
Compute ∫₀^π/4 2 sec x tan x dx, exact value first, then as a decimal.

Worked solution

Background: constant 2 slides out front. Antiderivative of sec x tan x is sec x. Values: sec(π/4) = 1/cos(π/4) = 1/(√2/2) = √2 ≈ 1.414, and sec 0 = 1.
2 ∫₀^π/4 sec x tan x dx = 2 [sec x]₀^π/4 = 2(sec(π/4) − sec 0) = 2(√2 − 1).
Decimal: 2(1.414 − 1) = 2(0.414) ≈ 0.828.
2√2 − 2 ≈ 0.828
19.conceptual · honesty
Your friend asks: "We have ∫ sec²x dx and ∫ sec x tan x dx — so what's plain ∫ sec x dx?" Explain why our current backward-reading method can't produce it, and what an honest mathematician says about it.

Worked solution

Background: our whole library is built by reading known derivatives backward. That method only finds antiderivatives for functions that happen to BE somebody's derivative in our table. Plain sec x isn't on the right-hand side of any derivative fact we own — and no obvious u-substitution works either (there's no du partner in sight).
Scan the table: derivatives give sec²x (from tan) and sec x·tan x (from sec) — but never plain sec x. And sec x = 1/cos x offers no inner function whose derivative is also present, so u-substitution stalls.
The honest answer: ∫ sec x dx DOES exist — it turns out to be ln|sec x + tan x| + C — but finding it requires a genuinely sneaky trick (multiplying by a cleverly chosen "disguised 1"). We'll earn that trick in a later lesson. For now: "not with today's tools" ≠ "impossible."
No derivative fact we own outputs plain sec x, and no u-sub fits; the antiderivative exists (ln|sec x + tan x| + C) but needs a trick we haven't learned yet
20.challenge
Compute ∫₀^π/4 (sec²x + cos x) dx — exact value first, then a decimal approximation (use √2 ≈ 1.414).

Worked solution

Background: a two-library problem — one new entry (sec² → tan) plus one old friend (cos → sin, Lesson 18). Split the integral, antidifferentiate each piece, then FTC with the table values tan(π/4) = 1 and sin(π/4) = √2/2.
Antiderivative: tan x + sin x. (Check: (tan x + sin x)′ = sec²x + cos x ✓.)
Top limit: tan(π/4) + sin(π/4) = 1 + √2/2.
Bottom limit: tan 0 + sin 0 = 0 + 0 = 0.
Value = (1 + √2/2) − 0 = 1 + √2/2.
Decimal: √2/2 ≈ 1.414/2 = 0.707, so the value ≈ 1 + 0.707 = 1.707 ≈ 1.71.
1 + √2/2 ≈ 1.71
