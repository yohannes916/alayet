Lesson 26 — u-Substitution Mastery: Changing Limits & Classic Patterns

The Definite-Integral Upgrade and a Pattern Gallery · Intuitive Calculus for a Curious Student · Lesson 26 of 40

📚 All lessons← Prev: Lesson 25Next: Lesson 27 →
🎯 Goal of this lesson: level up u-substitution in two ways. First, the definite-integral upgrade: change the limits along with the variable and never go back to x. Second, a gallery of classic patterns — ∫ f′/f = ln|f|, the (ln x)/x fingerprint, and the sinⁿx·cos x family — that AP exams recycle year after year. Spot the pattern, and the integral falls in three lines.

1 The ritual, plus the definite-integral upgrade

  • Recap of Lesson 18's u-substitution ritual: ① pick u = the inside function, ② compute du, ③ swap everything into u-language (borrowing a constant if needed), ④ integrate in u, ⑤ back-substitute to x. That ritual still runs the show.
  • Here's the upgrade for definite integrals: when you change the variable, change the LIMITS too. The old limits say "x runs from 0 to 2." But once we're living in u-language, we should say where u runs. Just feed the x-limits into the u formula.
  • If u = x²+1 and x runs from 0 to 2, then u runs from u(0) = 0²+1 = 1 up to u(2) = 2²+1 = 5. New limits: 1 to 5. And then — this is the beautiful part — you NEVER go back to x. Finish the whole problem in u.
Worked example (the limits-changing way): compute ∫₀² x(x²+1)³ dx.
u = x²+1, du = 2x dx → x dx = du/2. Limits: u(0) = 1, u(2) = 5.
∫₀² x(x²+1)³ dx = (1/2)∫₁⁵ u³ du = (1/2)[u⁴/4]₁⁵ = (5⁴ − 1⁴)/8 = (625 − 1)/8 = 624/8 = 78.
Same problem, old way (back-substitute): ∫ x(x²+1)³ dx = (1/2)·u⁴/4 = (x²+1)⁴/8. Then plug in the ORIGINAL x-limits: at x = 2: (4+1)⁴/8 = 625/8; at x = 0: 1/8. Difference: 624/8 = 78. Same answer — two roads, one truth ✓.

2 Why changing limits is safer AND faster

  • Faster: the back-substitution step (rewriting u⁴/4 as (x²+1)⁴/8) disappears entirely. You integrate in u, plug in u-numbers, done.
  • Safer: the #1 exam disaster with definite u-subs is a mismatch — plugging x-limits into a u-antiderivative (or u-limits into an x-antiderivative). If you convert the limits the moment you convert the variable, the whole problem lives consistently in u-world and the mismatch becomes impossible.
  • The one rule to burn in: limits always belong to the variable next to the d. Writing ∫₁⁵ u³ du means "u runs 1 → 5". Writing ∫₀² next to u³ du would be a lie — u never goes near 0 or 2 in our example.
  • Both roads stay legal. But from now on, changed limits is our default for definite integrals; back-substituting is the road for indefinite ones (where there are no limits, so you must return to x for the final answer).

3 The classic pattern gallery

  • Certain u-subs appear so often that AP graders can recite them in their sleep. Learn these four as patterns — each one fully worked, then boxed.
Pattern 1 — tangent (recap from Lesson 24): ∫ tan x dx = ∫ sin x/cos x dx. Let u = cos x, du = −sin x dx → sin x dx = −du. Integral becomes −∫ du/u = −ln|u|.
Box: ∫ tan x dx = −ln|cos x| + C
Pattern 2 — (ln x)/x: the fingerprint is ln x and its derivative 1/x both present. Let u = ln x, du = (1/x) dx — and the (1/x) dx is sitting right there. ∫ (ln x)/x dx = ∫ u du = u²/2.
Box: ∫ (ln x)/x dx = (ln x)²/2 + C
Pattern 3 — derivative-of-bottom-on-top → ln: try ∫ eˣ/(1+eˣ) dx. Let u = the bottom = 1+eˣ; then du = eˣ dx = exactly the top. Integral becomes ∫ du/u = ln|u| = ln(1+eˣ).
This works EVERY time the top is the derivative of the bottom. State it as a general rule and box it:
Box: ∫ f′(x)/f(x) dx = ln|f(x)| + C   (so ∫ eˣ/(1+eˣ) dx = ln(1+eˣ) + C — no |·| needed since 1+eˣ > 0)
Pattern 4 — sinⁿx · cos x: a power of sine, times cosine standing guard. Let u = sin x, du = cos x dx — the cosine IS the du. ∫ sinⁿx cos x dx = ∫ uⁿ du = uⁿ⁺¹/(n+1).
Box: ∫ sinⁿx cos x dx = sinⁿ⁺¹x/(n+1) + C   (mirror version: ∫ cosⁿx sin x dx = −cosⁿ⁺¹x/(n+1) + C — the minus comes from du = −sin x dx!)

4 The fingerprint checklist, upgraded

  • Before integrating anything, run this scan:
Question to askIf yes...
Is there an inside function whose derivative appears elsewhere (up to a constant)?u = the inside; borrow a constant for du if needed
Top-and-bottom check: is the TOP (about) the derivative of the BOTTOM?u = bottom → the ln pattern: ∫ f′/f = ln|f|
Is it a power of sin (or cos) with the OTHER one standing next to dx?u = the powered one; watch the minus for cos
Do I see ln x together with 1/x?u = ln x
Definite integral?convert the limits immediately; never return to x
  • The phrase "up to a constant" matters: for ∫ x²/(x³+1) dx the derivative of the bottom is 3x², and we only have x² — off by the constant 3. That's fine: borrow it, answer (1/3)ln|x³+1| + C. What you can NOT borrow is an x — only constants slide through integrals.

5 A definite integral with trig, start to finish

Worked example: compute ∫₀^(π/2) sin²x cos x dx.
Pattern 4: u = sin x, du = cos x dx. Convert the limits: u(0) = sin 0 = 0, u(π/2) = sin(π/2) = 1.
∫₀^(π/2) sin²x cos x dx = ∫₀¹ u² du = [u³/3]₀¹ = 1/3 − 0 = 1/3.
Notice how civilized that was: trig limits (0 and π/2) became plain numbers (0 and 1), and the finish line was a one-step power rule. That's the changed-limits upgrade earning its keep.
x-world u-world 1 | sin²x·cosx 1 | u² _/ | _/\_ | _/ | _/ \ u=sin x | ___/ | _/ \ =======> |__—— 0 +—————————————→ x 0 +————————————→ u 0 π/2 0 1 same area, easier shape

6 Honesty corner — when u-sub simply fails

  • u-substitution is powerful, not almighty. It needs a du in the picture. Look at ∫ x eˣ dx: try u = x (then du = dx, but eˣ won't translate into u-language) or u = eˣ (then du = eˣ dx, but there's a leftover lone x). No choice of u makes the du appear. Same story for ∫ ln x dx and ∫ x cos x dx.
  • These aren't broken integrals — they need a genuinely new tool: integration by parts, the product rule read backward. That's Lesson 30. For now, the honest skill is recognizing "no du in sight → u-sub is the wrong key for this lock," and saying so instead of forcing it.

1.change the limits
Compute ∫₀¹ 2x(x²+1)² dx by u-substitution with changed limits. Do not back-substitute.

Worked solution

Background: the full upgraded ritual: pick u, compute du, AND feed the x-limits through the u formula to get u-limits. From then on the problem lives entirely in u-world.
u = x²+1, du = 2x dx — and 2x dx sits right there, no borrowing needed.
Limits: u(0) = 0+1 = 1; u(1) = 1+1 = 2.
∫₀¹ 2x(x²+1)² dx = ∫₁² u² du = [u³/3]₁² = 8/3 − 1/3 = 7/3.
7/3
2.limits drill
Just find the new u-limits (no integrating!): (a) u = x²+4, x from 0 to 2   (b) u = sin x, x from 0 to π/2   (c) u = ln x, x from 1 to e   (d) u = cos x, x from 0 to π/2.

Worked solution

Background: converting limits is pure plug-in: feed each x-limit into the u formula. One surprise to notice in (d): u-limits are allowed to run DOWNHILL (start bigger than they end) — that's fine, just keep them in order: bottom limit from the bottom x, top limit from the top x.
(a) u(0) = 4, u(2) = 8 → u: 4 → 8.
(b) u(0) = sin 0 = 0, u(π/2) = 1 → u: 0 → 1.
(c) u(1) = ln 1 = 0, u(e) = ln e = 1 → u: 0 → 1.
(d) u(0) = cos 0 = 1, u(π/2) = 0 → u: 1 → 0 (downhill — perfectly legal).
(a) 4→8   (b) 0→1   (c) 0→1   (d) 1→0
3.ln x pattern
Find ∫ (ln x)/x dx.

Worked solution

Background: the fingerprint: ln x AND its derivative 1/x both present. Whenever a function and its derivative show up together, u-sub is knocking. Here u = ln x makes du = (1/x) dx, which is exactly the rest of the integrand.
u = ln x, du = (1/x) dx.
∫ (ln x)/x dx = ∫ u du = u²/2 + C.
Back-substitute (indefinite integral, so we must return to x): (ln x)²/2 + C.
Check: d/dx[(ln x)²/2] = (1/2)·2(ln x)·(1/x) = (ln x)/x ✓.
(ln x)²/2 + C
4.f′/f → ln
Find ∫ eˣ/(eˣ+3) dx.

Worked solution

Background: the top-and-bottom check: the derivative of the bottom (eˣ+3) is eˣ — exactly the top. That's the ∫ f′/f = ln|f| pattern. Since eˣ+3 is always positive (eˣ > 0), we can drop the absolute value.
u = eˣ+3, du = eˣ dx = the top.
∫ eˣ/(eˣ+3) dx = ∫ du/u = ln|u| + C = ln(eˣ+3) + C.
Check: d/dx[ln(eˣ+3)] = eˣ/(eˣ+3) ✓.
ln(eˣ+3) + C
5.sinⁿ · cos
Find ∫ sin⁴x cos x dx.

Worked solution

Background: Pattern 4: a power of sine with cosine standing next to dx. The cosine IS the du for u = sin x, so the whole thing collapses to the power rule on u⁴.
u = sin x, du = cos x dx.
∫ sin⁴x cos x dx = ∫ u⁴ du = u⁵/5 + C = sin⁵x/5 + C.
Check: d/dx[sin⁵x/5] = (5 sin⁴x · cos x)/5 = sin⁴x cos x ✓.
sin⁵x/5 + C
6.tan recap
Find ∫ tan x dx, showing the u-substitution that produces the answer.

Worked solution

Background: tan x = sin x/cos x, and the top is (almost) the derivative of the bottom: (cos x)′ = −sin x, off only by a minus sign. So this is secretly the f′/f → ln pattern with one minus to manage.
u = cos x, du = −sin x dx → sin x dx = −du.
∫ tan x dx = ∫ sin x/cos x dx = ∫ (−du)/u = −ln|u| + C.
Back-substitute: −ln|cos x| + C.
Check: d/dx[−ln|cos x|] = −(1/cos x)(−sin x) = tan x ✓.
−ln|cos x| + C
7.change the limits
Compute ∫₀² x(x²+4)³ dx with changed limits.

Worked solution

Background: same recipe as the notes' showcase problem, but now the du needs the constant-borrow trick: du = 2x dx while we only have x dx, so x dx = du/2 and a 1/2 pops out front.
u = x²+4, du = 2x dx → x dx = du/2. Limits: u(0) = 4, u(2) = 8.
∫₀² x(x²+4)³ dx = (1/2)∫₄⁸ u³ du = (1/2)[u⁴/4]₄⁸ = (8⁴ − 4⁴)/8.
8⁴ = 4096 and 4⁴ = 256, so (4096 − 256)/8 = 3840/8 = 480.
480
8.f′/f · borrow
Find ∫ x²/(x³+1) dx.

Worked solution

Background: top-and-bottom check: derivative of the bottom is 3x², and the top is x² — a match up to the constant 3. Constants can be borrowed (only constants!), so this is the ln pattern with a 1/3 out front.
u = x³+1, du = 3x² dx → x² dx = du/3.
∫ x²/(x³+1) dx = (1/3)∫ du/u = (1/3) ln|u| + C = (1/3) ln|x³+1| + C.
Check: d/dx[(1/3)ln|x³+1|] = (1/3)·3x²/(x³+1) = x²/(x³+1) ✓.
(1/3) ln|x³+1| + C
9.f′/f · trig
Find ∫ cos x/sin x dx for x between 0 and π (where sin x > 0).

Worked solution

Background: this is cot x, tangent's upside-down cousin from Lesson 24. Top-and-bottom check: derivative of sin x is cos x = the top, exactly — no borrowing, no minus sign this time. On (0, π), sin x is positive, so ln|sin x| = ln(sin x).
u = sin x, du = cos x dx = the top.
∫ cos x/sin x dx = ∫ du/u = ln|u| + C = ln(sin x) + C on this interval.
Check: d/dx[ln(sin x)] = cos x/sin x ✓. (Compare tan: THAT one got a minus because (cos x)′ = −sin x. Here (sin x)′ = +cos x, so no minus.)
ln(sin x) + C
10.definite · ln x pattern
Compute ∫₁^e (ln x)/x dx with changed limits.

Worked solution

Background: e ≈ 2.718 is the natural base from Lesson 16, and ln e = 1 (ln asks "e to WHAT power?"). Watch the limits transform: the awkward pair (1, e) becomes the friendly pair (0, 1).
u = ln x, du = (1/x) dx. Limits: u(1) = ln 1 = 0; u(e) = ln e = 1.
∫₁^e (ln x)/x dx = ∫₀¹ u du = [u²/2]₀¹ = 1/2 − 0 = 1/2.
1/2
11.cosⁿ · sin — the minus!
Find ∫ cos³x sin x dx. (Careful: there's a minus sign hiding in this one.)

Worked solution

Background: the mirror of Pattern 4: a power of COSINE with sine standing guard. u = cos x — but now du = −sin x dx, so sin x dx = −du and a minus sign rides along to the final answer. Forgetting it is the single most common slip in this family.
u = cos x, du = −sin x dx → sin x dx = −du.
∫ cos³x sin x dx = ∫ u³(−du) = −u⁴/4 + C = −cos⁴x/4 + C.
Check: d/dx[−cos⁴x/4] = −(4cos³x)(−sin x)/4 = cos³x sin x ✓ — the two minuses cancel, confirming ours was needed.
−cos⁴x/4 + C
12.definite · downhill limits
Compute ∫₀^(π/2) cos²x sin x dx with changed limits.

Worked solution

Background: two twists at once: the cosⁿ·sin minus sign AND downhill u-limits (u = cos x runs from 1 down to 0). Handle each mechanically and they cooperate — in fact a handy flip rule saves the day: ∫ from a to b = −∫ from b to a.
u = cos x, du = −sin x dx → sin x dx = −du. Limits: u(0) = 1, u(π/2) = 0.
∫₀^(π/2) cos²x sin x dx = −∫₁⁰ u² du = +∫₀¹ u² du (flipping the limits eats the minus).
= [u³/3]₀¹ = 1/3.
Sanity: the integrand is positive on (0, π/2), so a positive answer is right ✓.
1/3
13.both ways
Compute ∫₀¹ x(x²+3)² dx BOTH ways — (a) back-substitute and use x-limits, (b) change the limits — and confirm they agree.

Worked solution

Background: both roads are legal; this exercise is your proof-by-experience. Setup shared by both: u = x²+3, du = 2x dx → x dx = du/2.
(a) Back-substitute: ∫ x(x²+3)² dx = (1/2)·u³/3 = (x²+3)³/6. Evaluate at x-limits: at x = 1: 4³/6 = 64/6; at x = 0: 3³/6 = 27/6. Difference: 37/6.
(b) Changed limits: u(0) = 3, u(1) = 4. (1/2)∫₃⁴ u² du = (1/2)[u³/3]₃⁴ = (64 − 27)/6 = 37/6.
Same answer, 37/6 ✓ — but count the steps: road (b) never needed to rebuild (x²+3)³/6.
37/6 both ways
14.which pattern?
Name the pattern (f′/f → ln, sinⁿ·cos, or ln x pattern) and give the antiderivative: (a) ∫ 2x/(x²+7) dx   (b) ∫ sin⁵x cos x dx   (c) ∫ (ln x)³/x dx

Worked solution

Background: pattern recognition is the real exam skill — the computing is easy once the pattern is named. Run the checklist: top ≈ derivative of bottom? Power of sine with a cos·dx? ln x with a 1/x?
(a) Derivative of bottom (x²+7) is 2x = the top → f′/f → ln: ln(x²+7) + C (bottom always positive, no |·| needed).
(b) Power of sine, cosine on guard → sinⁿ·cos: sin⁶x/6 + C.
(c) ln x (cubed) with its derivative 1/x present → ln x pattern, u = ln x: ∫u³du = u⁴/4 → (ln x)⁴/4 + C.

15.definite · tan
Compute ∫₀^(π/4) tan x dx exactly, using changed limits. Simplify your answer to a single ln.

Worked solution

Background: definite version of the tan pattern. You'll need cos(π/4) = √2/2 and two ln rules from Lesson 17: ln 1 = 0, and −ln(a/b) = ln(b/a). Also handy: √2/2 = 1/√2.
u = cos x, sin x dx = −du. Limits: u(0) = cos 0 = 1; u(π/4) = √2/2.
∫₀^(π/4) tan x dx = −∫₁^(√2/2) du/u = −[ln u]₁^(√2/2) = −(ln(√2/2) − ln 1) = −ln(√2/2).
Simplify: −ln(1/√2) = ln √2 = (1/2) ln 2 ≈ 0.347.
Sanity: tan is small and positive on (0, π/4), so a small positive area is right ✓.
(1/2) ln 2   (= ln √2)
16.definite · f′/f
Compute ∫₀¹ eˣ/(1+eˣ) dx exactly, using changed limits. Write the answer as a single ln.

Worked solution

Background: the f′/f pattern, definite edition. Remember e⁰ = 1, so the bottom limit converts to 1+1 = 2. And ln a − ln b = ln(a/b) collapses the answer into one logarithm — AP exams love that final compression.
u = 1+eˣ, du = eˣ dx. Limits: u(0) = 1+e⁰ = 2; u(1) = 1+e.
∫₀¹ eˣ/(1+eˣ) dx = ∫₂^(1+e) du/u = [ln u]₂^(1+e) = ln(1+e) − ln 2.
Compress: ln((1+e)/2) ≈ ln(1.859) ≈ 0.620.
ln((1+e)/2)
17.spot the error
A student computes ∫₀² x(x²+1)³ dx like this: "u = x²+1, x dx = du/2, and u goes from 1 to 5. So I get (1/2)∫₁⁵ u³ du. Integrating: (1/2)·u⁴/4 = (x²+1)⁴/8. Now I plug my limits 1 and 5 into that: (1+1)⁴/8... wait, no — ((5²+1)⁴ − (1²+1)⁴)/8 = (26⁴ − 2⁴)/8." Find the error and give the correct answer.

Worked solution

Background: this is the dreaded DOUBLE conversion: the student changed the limits to u-values (1 and 5) AND back-substituted to an x-formula — then fed the u-limits into the x-formula as if they were x-values. Limits belong to the variable next to the d; the two roads must never be mixed.
The error: after writing (x²+1)⁴/8 (an x-world formula), the student plugged in 1 and 5 — which are u-limits, not x-limits. Numbers converted once must not be converted again.
Fix, road A (stay in u): (1/2)[u⁴/4]₁⁵ = (625 − 1)/8 = 78.
Fix, road B (back to x, use ORIGINAL x-limits 0 and 2): [(x²+1)⁴/8]₀² = (625 − 1)/8 = 78.
Either lane works — the crash comes only from switching lanes mid-problem.
Error: u-limits plugged into an x-formula. Correct answer: 78
18.definite · tan again
Compute ∫₀^(π/3) tan x dx exactly. (Answer is a famous single ln.)

Worked solution

Background: same routine as exercise 15 but ending at π/3, where cos(π/3) = 1/2. One more ln rule pays off: −ln(1/2) = ln 2.
Antiderivative (Pattern 1): −ln|cos x|. So the integral = [−ln(cos x)]₀^(π/3).
Top: −ln(cos(π/3)) = −ln(1/2). Bottom: −ln(cos 0) = −ln 1 = 0.
Answer: −ln(1/2) − 0 = ln 2 ≈ 0.693.
Compare exercise 15: doubling the arc from π/4 to π/3 doubled the area from (1/2)ln 2 to ln 2 — a pretty coincidence of the cosine values (√2/2)² = 1/2.
ln 2

Worked solution

Background: the ln x pattern scales to any power: u = ln x turns (ln x)²/x dx into u² du. Compare exercise 10 — same limits (0 to 1 in u-world), one power higher.
u = ln x, du = (1/x) dx. Limits: u(1) = 0, u(e) = 1.
∫₁^e (ln x)²/x dx = ∫₀¹ u² du = [u³/3]₀¹ = 1/3.
(Pattern preview: with (ln x)ⁿ the answer is 1/(n+1). Exercise 10 was n = 1 → 1/2 ✓.)

20.challenge · two roads
Compute ∫₀^(π/4) tan x sec²x dx TWO ways: (a) u = tan x, (b) u = sec x. (Recall from Lesson 24: (tan x)′ = sec²x and (sec x)′ = sec x tan x.) You'll get identical answers from different-looking antiderivatives — explain how that's possible.

Worked solution

Background: a single integrand can contain TWO valid patterns at once. The resolution of the puzzle uses the trig identity sec²x = 1 + tan²x: the two antiderivatives differ by a constant — and "+ C" was invented for exactly this. Values needed: tan(π/4) = 1, sec(π/4) = √2, sec 0 = 1.
(a) u = tan x, du = sec²x dx. Limits: u(0) = 0, u(π/4) = 1. Integral = ∫₀¹ u du = [u²/2]₀¹ = 1/2.
(b) u = sec x, du = sec x tan x dx. Regroup the integrand: tan x sec²x dx = sec x · (sec x tan x dx) = u du. Limits: u(0) = 1, u(π/4) = √2. Integral = ∫₁^√2 u du = [u²/2]₁^√2 = (2 − 1)/2 = 1/2.
Same answer, 1/2 ✓ — yet the antiderivatives look different: tan²x/2 vs sec²x/2. How? sec²x = 1 + tan²x, so sec²x/2 = tan²x/2 + 1/2 — they differ by the constant 1/2, i.e., by a choice of C. In a DEFINITE integral the constant cancels in the subtraction, so both roads must agree.
1/2 by both roads; the antiderivatives differ by the constant 1/2 (sec² = 1 + tan²), which cancels in any definite integral
