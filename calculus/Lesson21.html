Lesson 21 — Completing the Power Rule

🎯 Goal of this lesson: unlock the FULL power rule. The same formula you've used since Lesson 4 — raise the power by one, divide by the new power — actually works for negative powers like 1/x² and fractional powers like √x. One rewrite step, and a huge new family of functions opens up.

1 Welcome to Part 2 of the course!

  • Congratulations — you've finished the first half. You can slice areas, run the Fundamental Theorem, substitute, and solve initial-value problems. That's a genuinely big deal.
  • Lessons 21–40 take everything you know and polish it up to AP Calculus BC level — the class strong high-school seniors take. You're ready for it, because here's the secret: Part 2 contains very few brand-new ideas. Mostly it's your existing tools, made sharper and more flexible.
  • Today is the perfect example. You will learn zero new formulas. The power rule you already own is simply about to handle far more functions than you thought it could — including 1/x², √x, and ∛x.
  • The whole trick is learning to rewrite functions so they LOOK like xn. Rewriting first, integrating second — that habit will carry you through the rest of the course.

2 Rewriting from scratch: what negative and fractional exponents mean

  • Negative exponents mean "1 over." By definition, x−n = 1/xn. So x−2 = 1/x² and 1/x⁵ = x−5. Why this definition? Watch the pattern: x³, x², x¹ — each step down divides by x. Keep going: x⁰ = 1, then x−1 = 1/x, then x−2 = 1/x². The pattern forces it.
  • Fractional exponents mean roots. x1/2 = √x, because the exponent rule says x1/2 · x1/2 = x1/2+1/2 = x¹ — so x1/2 is the thing that multiplies by itself to give x. That's exactly what a square root is! Same idea: x1/3 = ∛x (cube root).
  • Mixed fractions combine both ideas: x3/2 = x¹ · x1/2 = x·√x. The top of the fraction is a power, the bottom is a root.

3 The power rule works for ALL powers (except one)

  • The big announcement: ∫ xn dx = xn+1/(n+1) + C works for every power n except n = −1. Negative, fractional, whatever — raise the power by one, divide by the NEW power.
Worked example (negative power): ∫ 1/x² dx.
Rewrite: 1/x² = x−2. Raise the power by one: −2 + 1 = −1. Divide by the new power:
∫ x−2 dx = x−1/(−1) + C = −x−1 + C = −1/x + C.
Check by differentiating (always!): d/dx[−1/x] = d/dx[−x−1] = (−1)(−1)x−2 = x−2 = 1/x² ✓. Notice the surprise: the answer to a "1 over x squared" integral is "minus 1 over x" — the minus sign appears because the new power is negative.
Worked example (fractional power): ∫ √x dx.
Rewrite: √x = x1/2. Raise the power by one: 1/2 + 1 = 3/2. Divide by the new power:
∫ x1/2 dx = x3/2/(3/2) + C.
Dividing by a fraction, from scratch: "divide by 3/2" means "how many 3/2's fit?" — and the answer is always the same as multiplying by the flipped fraction: ÷ 3/2 = × 2/3. (Why? Dividing by 3 makes things 3× smaller; dividing by 1/2 makes them 2× bigger; dividing by 3/2 does both: × 2/3.) So:
∫ √x dx = (2/3)x3/2 + C.
Check: d/dx[(2/3)x3/2] = (2/3)·(3/2)·x1/2 = x1/2 = √x ✓ — the 2/3 and 3/2 cancel perfectly. That cancellation is WHY the rule says "divide by the new power."

4 The lone exception: n = −1

  • Try the power rule on ∫ 1/x dx = ∫ x−1 dx: raise the power by one → −1 + 1 = 0, divide by the new power → x⁰/0. Division by zero! The machine jams on exactly one input.
  • You already know the rescue from Lesson 15: ∫ 1/x dx = ln|x| + C, because the derivative of ln x is 1/x.
  • New detail — the absolute value. ln only accepts positive inputs (it asks "e to what power gives this?", and e-to-anything is positive). But 1/x exists for negative x too, and areas under it there are perfectly real. Writing |x| feeds ln a positive number no matter the sign of x, so ONE formula covers both sides.
  • Check that it really works for negative x: there, |x| = −x, so we need the derivative of ln(−x). Chain rule (the inside function is −x, its derivative is −1): d/dx[ln(−x)] = 1/(−x) · (−1) = 1/x ✓. The two minus signs cancel — the formula genuinely earns its absolute value.
  • So the full story in one line: ∫ xn dx = xn+1/(n+1) + C for n ≠ −1, and ∫ x−1 dx = ln|x| + C.

  • Golden habit: rewrite as powers of x BEFORE you integrate. Never try to integrate a fraction or a root "as is." Watch four classics:

6 A definite integral, start to finish

Worked example: find ∫14 1/√x dx — the exact area under y = 1/√x from x = 1 to x = 4.
Rewrite: 1/√x = x−1/2. Antiderivative: x1/2/(1/2) = 2x1/2 = 2√x.
FTC: ∫14 x−1/2 dx = [2√x]14 = 2√4 − 2√1 = 4 − 2 = 2.

  • Sanity check: the region is 3 wide with heights between 1 and 1/2, so the area must sit between 3 × ½ = 1.5 and 3 × 1 = 3. Our answer 2 fits. Always sanity-check definite integrals against a rough rectangle.

1.negative power
Rewrite as a power of x, then integrate: ∫ x−3 dx. (Already a power — just apply the rule, then check your answer by differentiating.)

Worked solution

Background: the power rule ∫ xn dx = xn+1/(n+1) + C works for negative powers too. "Raise the power by one" on a negative number moves it TOWARD zero: −3 + 1 = −2 (not −4!). A number line helps: −3 → −2 is one step up.
New power: −3 + 1 = −2. Divide by it: x−2/(−2) = −½ x−2.
Rewrite for humans: −1/(2x²) + C.
Check: d/dx[−½x−2] = −½ · (−2) · x−3 = x−3 ✓.
−1/(2x²) + C
2.fractional power
Rewrite as a power of x, then integrate: ∫ √x dx.

Worked solution

Background: √x = x1/2 because x1/2 · x1/2 = x¹. Once it's a power, the ordinary power rule applies. Dividing by a fraction = multiplying by its flip: ÷ 3/2 = × 2/3.
Rewrite: √x = x1/2. New power: 1/2 + 1 = 3/2.
x3/2/(3/2) = (2/3)x3/2.
Check: (2/3)·(3/2)·x1/2 = √x ✓.
(2/3)x3/2 + C
3.rewrite first
Rewrite as a power of x, then integrate: ∫ 1/x⁴ dx.

Worked solution

Background: "1 over x to a power" is a negative power: 1/x⁴ = x−4. Never integrate a fraction as-is — translate to power form first, THEN raise-and-divide.
Rewrite: 1/x⁴ = x−4. New power: −4 + 1 = −3.
x−3/(−3) = −1/(3x³).
Check: d/dx[−⅓x−3] = −⅓·(−3)·x−4 = x−4 ✓.
−1/(3x³) + C
4.cube root
Rewrite as a power of x, then integrate: ∫ ∛x dx.

Worked solution

Background: the cube root is the 1/3 power: ∛x = x1/3, because x1/3·x1/3·x1/3 = x¹. Adding 1 to a fraction: 1/3 + 1 = 1/3 + 3/3 = 4/3.
Rewrite: ∛x = x1/3. New power: 4/3.
x4/3/(4/3) = (3/4)x4/3 (dividing by 4/3 = multiplying by 3/4).
Check: (3/4)·(4/3)·x1/3 = x1/3 ✓.
(3/4)x4/3 + C
5.big fractional power
Integrate: ∫ x5/2 dx.

Worked solution

Background: x5/2 means x²·√x, but you don't need to unpack it — the power rule eats any exponent (except −1). Fraction addition: 5/2 + 1 = 5/2 + 2/2 = 7/2.
New power: 7/2. x7/2/(7/2) = (2/7)x7/2.
Check: (2/7)·(7/2)·x5/2 = x5/2 ✓.
(2/7)x7/2 + C
6.constant multiple
Integrate: ∫ 6/x² dx.

Worked solution

Background: the constant-multiple rule (Lesson 5) says a constant factor rides along outside the integral: ∫ 6·f = 6·∫ f. So peel off the 6, integrate the power, multiply back.
Rewrite: 6/x² = 6x−2.
6 · x−1/(−1) = −6x−1 = −6/x.
Check: d/dx[−6x−1] = −6·(−1)·x−2 = 6/x² ✓.
−6/x + C
7.constant multiple
Integrate: ∫ 10√x dx.

Worked solution

Background: combine two rules: the constant 10 rides along, and √x = x1/2 integrates to (2/3)x3/2. Then multiply the constants: 10 · 2/3 = 20/3. Leaving 20/3 as a fraction is cleaner (and more exact) than a decimal.
10 · x3/2/(3/2) = 10 · (2/3) x3/2 = (20/3)x3/2.
Check: (20/3)·(3/2)·x1/2 = 10√x ✓.
(20/3)x3/2 + C
8.sum of powers
Integrate: ∫ (x³ + √x) dx.

Worked solution

Background: the sum rule (Lesson 5) lets you integrate term by term — each piece gets its own power-rule treatment. A whole-number power and a fractional power can live in the same problem happily.
∫ x³ dx = x⁴/4.
∫ x1/2 dx = (2/3)x3/2.
Check: d/dx[x⁴/4 + (2/3)x3/2] = x³ + x1/2 ✓.
x⁴/4 + (2/3)x3/2 + C
9.sum · rewrite both
Integrate: ∫ (1/x² + 1/√x) dx.

Worked solution

Background: two rewrites in one problem: 1/x² = x−2 and 1/√x = x−1/2 (a root in the bottom makes a NEGATIVE fractional power). Watch the second one: −1/2 + 1 = +1/2, and dividing by 1/2 doubles: x1/2/(1/2) = 2√x.
∫ x−2 dx = x−1/(−1) = −1/x.
∫ x−1/2 dx = x1/2/(1/2) = 2√x.
Check: d/dx[−x−1 + 2x1/2] = x−2 + x−1/2 ✓.
−1/x + 2√x + C
10.split the fraction
Integrate: ∫ (x³ + 2)/x² dx. (Hint: split the fraction into two pieces first.)

Worked solution

Background: when a SUM sits on top of one denominator, you may split it: (a+b)/c = a/c + b/c — that's just adding fractions read backwards. Then simplify each piece with exponent subtraction: x³/x² = x3−2 = x.
Split: (x³+2)/x² = x³/x² + 2/x² = x + 2x−2.
∫ x dx = x²/2; ∫ 2x−2 dx = 2·x−1/(−1) = −2/x.
Check: d/dx[x²/2 − 2x−1] = x + 2x−2 = (x³+2)/x² ✓.
x²/2 − 2/x + C
11.split the fraction
Integrate: ∫ (x + 1)/√x dx.

Worked solution

Background: splitting works with root denominators too: (x+1)/√x = x/√x + 1/√x. Simplify with exponents: x/√x = x¹/x1/2 = x1−1/2 = x1/2. So the scary fraction is secretly √x + 1/√x.
Split and rewrite: (x+1)/√x = x1/2 + x−1/2.
∫ x1/2 dx = (2/3)x3/2; ∫ x−1/2 dx = 2√x.
Check: d/dx[(2/3)x3/2 + 2x1/2] = x1/2 + x−1/2 ✓.
(2/3)x3/2 + 2√x + C
12.definite integral
Evaluate exactly: ∫12 1/x² dx.

Worked solution

Background: the FTC (Lesson 8): find an antiderivative F, then compute F(b) − F(a). No +C needed for definite integrals — it would cancel in the subtraction. Careful with double negatives when the antiderivative is −1/x!
Antiderivative of x−2 is −1/x.
[−1/x]12 = (−1/2) − (−1/1) = −1/2 + 1 = 1/2.
Sanity check: width 1, heights between 1/4 and 1 → answer must be between 1/4 and 1. ✓

15.check by differentiating
A classmate claims ∫ x3/2 dx = (2/5)x5/2 + C. Check the claim by differentiating. Is it right?

Worked solution

Background: every integration claim can be verified with a derivative: if d/dx[answer] gives back the original function, the answer is right. This check is free and catches nearly every slip — professionals use it constantly.
d/dx[(2/5)x5/2] = (2/5) · (5/2) · x3/2 (bring the power down, lower the power by one).
(2/5)·(5/2) = 1, so the derivative is exactly x3/2 — the original function.
Yes — the claim is correct, because the derivative returns x3/2
16.spot the error
Sam computes ∫ x−5 dx = x−4/(−5) + C. Find the error, fix it, and show (by differentiating) that Sam's version fails the check.

Worked solution

Background: the #1 power-rule slip: dividing by the OLD power instead of the NEW one. The rule is xn+1/(n+1) — the same "n+1" appears in both places. Here n = −5, so the new power is −4, and you divide by −4.
Sam raised the power correctly (−5 → −4) but divided by −5, the old power.
Fix: x−4/(−4) = −1/(4x⁴) + C.
Check Sam's: d/dx[x−4/(−5)] = (−4/−5)x−5 = (4/5)x−5 — off by a factor of 4/5. Check the fix: d/dx[−¼x−4] = −¼·(−4)·x−5 = x−5 ✓.
Correct answer: −1/(4x⁴) + C — divide by the NEW power, −4
17.spot the error · n = −1
Priya tries the power rule on ∫ 1/x dx: "rewrite as x−1, raise the power to 0, divide by 0…" She gets stuck. Explain exactly what breaks, and give the correct integral.

Worked solution

Background: division by zero is not "infinity" or "zero" — it's undefined, full stop. The power rule's recipe produces x0/0 when n = −1, so the recipe simply cannot run. Nature still gives the area under 1/x a value — it just comes from a different function: the natural logarithm (Lesson 15).
What breaks: n + 1 = −1 + 1 = 0, and the rule says divide by n + 1 → divide by 0. Undefined.
The correct integral: ∫ 1/x dx = ln|x| + C, since d/dx[ln x] = 1/x.
Memory hook: the power rule handles every power on the number line EXCEPT −1; ln|x| plugs that one hole.
The rule demands division by zero; instead ∫ 1/x dx = ln|x| + C
18.spot the error · absolute value
Jaden writes ∫ 1/x dx = ln x + C. What small but important thing is missing? Explain why it matters, and show by differentiating ln(−x) that the fixed formula works for negative x.

Worked solution

Background: ln asks "e to what power gives this number?" Since e to any power is positive, ln can't accept negative inputs. But 1/x is a perfectly good function for negative x, so its antiderivative formula must work there too. The absolute value |x| flips negatives positive before ln sees them.
Missing: the absolute value. It should be ln|x| + C. Without it, the formula silently fails for every negative x (ln x doesn't even exist there).
For x < 0, |x| = −x, so the formula claims ln(−x) is an antiderivative of 1/x there. Chain rule check: d/dx[ln(−x)] = 1/(−x) · (−1) = 1/x ✓.
Example use: ∫−3−1 1/x dx = ln|−1| − ln|−3| = 0 − ln 3 = −ln 3 — a real (negative) signed area the fixed formula handles smoothly.
Write ln|x| + C; the check d/dx[ln(−x)] = 1/x confirms it
19.word problem
Water flows into a rain barrel at the rate r(t) = 4/√t liters per minute, for t from 1 to 9 minutes. How many liters flow in during that time?

Worked solution

Background: total accumulated = the definite integral of the rate (the very first idea of the course, now with a fancier rate). A rate like 4/√t is fast at first and slows down — the flow starts at 4 L/min (t = 1) and eases to 4/3 L/min (t = 9).
Total = ∫19 4t−1/2 dt.
Antiderivative: 4 · 2√t = 8√t. (Check: d/dt[8t1/2] = 4t−1/2 ✓.)
[8√t]19 = 8·3 − 8·1 = 24 − 8 = 16. Units: (liters/min)·min = liters.
16 liters
20.challenge · multi-part
Let f(x) = (x² − 3)/x². (a) Rewrite f(x) as a sum of powers of x. (b) Find the general antiderivative, and check it by differentiating. (c) Evaluate ∫14 f(x) dx exactly.

Worked solution

Background: this is the full rewrite-first pipeline on one function: split the fraction, translate to powers, integrate term by term, verify, then run the FTC. AP free-response questions are built exactly like this — several small skills chained together.
(a) Split: (x² − 3)/x² = x²/x² − 3/x² = 1 − 3x−2.
(b) ∫ (1 − 3x−2) dx = x − 3·x−1/(−1) = x + 3/x + C. Check: d/dx[x + 3x−1] = 1 − 3x−2 ✓ — and note the sign flip: integrating −3x−2 gave PLUS 3/x.
(c) [x + 3/x]14 = (4 + 3/4) − (1 + 3) = 19/4 − 4 = 3/4.
(a) 1 − 3x−2   (b) x + 3/x + C   (c) 3/4
