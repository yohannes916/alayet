Lesson 17 — Substitution I: Linear Insides

Guess, Check, and Fix · Intuitive Calculus for a Curious Student · Lesson 17 of 40

📚 All lessons← Prev: Lesson 16Next: Lesson 18 →
🎯 Goal of this lesson: learn to integrate functions with a linear inside — things like (2x+1)³, e^(3x), and cos(2x) — using the guess-and-fix trick: integrate as if the inside were a single letter, then divide by the inside's slope. It's self-checking, so a wrong answer can never survive.

1 The new problem — a function inside a function

  • Here's an integral our current tools don't directly handle: ∫(2x+1)³ dx.
  • The power rule (Lesson 5) covers ∫x³ dx = x⁴/4 + C — but this isn't x cubed, it's (2x+1) cubed. There's a function tucked inside the cube.
  • One escape route: multiply out the cube. (2x+1)³ = 8x³ + 12x² + 6x + 1, then integrate term by term. It works... but it's misery — and for (2x+1)¹⁰ it would be torture, and for e^(2x) or cos(2x) there's nothing to multiply out at all.
  • There must be a smarter way. There is — and it comes from remembering how the chain rule works.

2 Quick recap — the chain rule from derivatives

  • From derivatives: when you differentiate a function with something inside it, the inside's derivative comes out as an extra multiplier. That's the chain rule.
  • Example: differentiate (2x+1)⁴. Treat the inside like a single blob: the outside power rule gives 4(blob)³ — and then the chain rule says multiply by the derivative of the blob. The inside 2x+1 has derivative 2, so:
  • ((2x+1)⁴)′ = 4(2x+1)³ × 2 = 8(2x+1)³ — the "×2" is the inside's slope tagging along.
  • This tag-along factor is the whole story of today's lesson: it appears every time we differentiate, so it must be dealt with every time we anti-differentiate.

3 Guess, check, fix — solving ∫(2x+1)³ dx

  • Guess: pretending the inside is a single letter, the power rule suggests (2x+1)⁴/4.
  • Check by differentiating the guess: ((2x+1)⁴/4)′ = 4(2x+1)³ × 2 / 4 = 2(2x+1)³. We wanted (2x+1)³ but got twice that — the chain rule's ×2 snuck in.
  • Fix: our guess came out exactly 2 times too big, so divide the guess by 2:
  • ∫(2x+1)³ dx = (2x+1)⁴/(4·2) + C = (2x+1)⁴/8 + C
  • Final check: ((2x+1)⁴/8)′ = 4(2x+1)³ × 2 / 8 = (2x+1)³ ✓. Perfect.

4 The general pattern — divide by the inside's slope

  • Whenever the inside is linear — shaped like ax + b (a straight line, slope a) — the tag-along factor is always just the number a. So the recipe is:
  • Integrate as if the inside were a single letter, then divide by a (the inside's slope).
  • This works for every function family we know:

5 Always check by differentiating

  • The best part of guess-and-fix: it's self-correcting. Even if your guess is off, differentiating it TELLS you the exact factor it's off by — then you just divide by that factor.
  • Make the check a reflex: write your answer, differentiate it in your head, confirm you land exactly on the function under the integral sign. If a stray factor shows up, fix and re-check. An unchecked substitution answer is only a rumor.

6 Warning — this shortcut is for LINEAR insides only

⚠️ Read this twice: dividing by the inside's slope works only because a linear inside ax + b has a CONSTANT slope a — the tag-along factor is a plain number, so one division cleans it up completely.

If the inside is curvy — like x² in ∫cos(x²) dx — its slope 2x changes from point to point, and no single number you divide by can fix that. Trying sin(x²)/2x is a classic wrong answer (differentiate it — a mess pops out, not cos(x²)). Curvy insides need the full u-substitution method — that's exactly what Lesson 18 is for.

1.gentle start
Find ∫(x+4)⁵ dx. (The inside x+4 has slope 1 — what does the recipe say about dividing?)

Worked solution

Background: the recipe: integrate as if the inside were a single letter, then divide by the inside's slope. Here the inside is x+4, a line with slope 1 (the number in front of x). Dividing by 1 changes nothing — so this one is as easy as the plain power rule.
Treat (x+4) as a single letter: the power rule gives (x+4)⁶/6, then divide by the slope 1.
Check: ((x+4)⁶/6)′ = 6(x+4)⁵ · 1 / 6 = (x+4)⁵ ✓.
(x+4)⁶/6 + C

Find ∫(2x−1)³ dx, and check by differentiating.

Worked solution

Background: the inside is 2x−1, a line with slope 2 (the −1 doesn't matter — constants have slope 0 and vanish when differentiated; only the number multiplying x counts).
As-if-single-letter: (2x−1)⁴/4. Then divide by the slope 2: (2x−1)⁴/8.
Check: ((2x−1)⁴/8)′ = 4(2x−1)³ · 2 / 8 = (2x−1)³ ✓.

3.exponential
Find ∫e^(2x) dx.

Worked solution

Background: from Lesson 15, e^x is the function that is its own derivative and its own antiderivative. With 2x inside, the chain rule makes (e^(2x))′ = 2e^(2x) — so anti-differentiating must divide that 2 back out.
As-if-single-letter: e^(2x). Divide by the inside's slope 2: e^(2x)/2.
Check: (e^(2x)/2)′ = e^(2x) · 2 / 2 = e^(2x) ✓.
e^(2x)/2 + C
4.cosine
Find ∫cos(3x) dx.

Worked solution

Background: from Lesson 16, ∫cos x dx = sin x + C. Now the inside is 3x (slope 3) — cos(3x) is a cosine wave wobbling three times as fast, so its humps are a third as wide, and the answer shrinks by a factor of 3.
As-if-single-letter: sin(3x). Divide by 3: sin(3x)/3.
Check: (sin(3x)/3)′ = cos(3x) · 3 / 3 = cos(3x) ✓.
sin(3x)/3 + C
5.sine · two things to track
Find ∫sin(2x) dx. (Careful: this needs BOTH Lesson 16's minus sign AND today's divide-by-slope.)

Worked solution

Background: two rules stack here. Lesson 16: ∫sin x dx = −cos x + C (the minus!). Today: inside 2x has slope 2, so divide by 2. Apply both, then let the check-by-differentiating settle any doubt.
As-if-single-letter: −cos(2x). Divide by 2: −cos(2x)/2.
Check: (−cos(2x)/2)′ = −(−sin(2x)) · 2 / 2 = sin(2x) ✓ — the two minus signs cancel and the 2s cancel.
−cos(2x)/2 + C
6.check task
Differentiate (2x+1)⁴/8 step by step, and confirm the result is exactly (2x+1)³. Say where the 8 in the denominator comes from.

Worked solution

Background: differentiating with a linear inside uses the chain rule: power rule on the outside, then multiply by the inside's slope. The point of this exercise: watch the 8 get eaten by the factors the derivative produces.
Power rule on the outside: 4(2x+1)³, so far giving 4(2x+1)³/8.
Chain rule — multiply by the inside's slope 2: 4(2x+1)³ · 2 / 8 = 8(2x+1)³/8 = (2x+1)³ ✓.
Where the 8 came from: 4 (the new power that comes down) × 2 (the inside's slope) = 8. The denominator was built to cancel exactly those two factors.
((2x+1)⁴/8)′ = (2x+1)³ — the 8 is 4 × 2, ready to cancel the chain rule's output
7.two ways · they match
Find ∫(3x+2)² dx TWO ways: (a) expand the square and integrate term by term; (b) use today's shortcut. Then compare the two answers.

Worked solution

Background: when a new method arrives, test it against an old one you trust. Expanding: (3x+2)² = (3x+2)(3x+2) = 9x² + 12x + 4. Two correct antiderivatives are allowed to differ by a constant — that's what + C is for.
(a) Expand: ∫(9x² + 12x + 4) dx = 9·x³/3 + 12·x²/2 + 4x + C = 3x³ + 6x² + 4x + C.
(b) Shortcut: as-if-single-letter (3x+2)³/3, divide by slope 3 → (3x+2)³/9 + C. Check: 3(3x+2)²·3/9 = (3x+2)² ✓.
Compare by expanding (b): (3x+2)³ = 27x³ + 54x² + 36x + 8, so (3x+2)³/9 = 3x³ + 6x² + 4x + 8/9. That's answer (a) plus the constant 8/9 — and constants get absorbed into + C, so the two answers are the SAME family. Both differentiate to (3x+2)². ✓
(a) 3x³ + 6x² + 4x + C   (b) (3x+2)³/9 + C — equal up to a constant, both correct

9.the ½ gotcha
Find ∫cos(x/2) dx. (The inside is x/2 — what is its slope, and what does dividing by it do?)

Worked solution

Background: x/2 is a line with slope ½ (it's ½·x). The recipe says divide by the slope — and dividing by ½ is the same as MULTIPLYING by 2. So slow waves (inside slope less than 1) make the answer BIGGER, which fits the picture: cos(x/2) wobbles at half speed, its humps are twice as wide, twice the area.
As-if-single-letter: sin(x/2). Divide by ½: sin(x/2) ÷ ½ = 2 sin(x/2).
Check: (2 sin(x/2))′ = 2 cos(x/2) · ½ = cos(x/2) ✓.
2 sin(x/2) + C

Worked solution

Check: (−cos(5x)/5)′ = −(−sin(5x)) · 5 / 5 = sin(5x) ✓.

11.spot the error
A student writes: ∫cos(2x) dx = sin(2x) + C. Differentiate their answer to find the mistake, then fix it.

Worked solution

Background: forgetting to divide by the inside's slope is THE classic substitution error. Check-by-differentiating exposes it immediately: the chain rule's tag-along factor shows up uninvited.
Differentiate the claim: (sin(2x))′ = cos(2x) · 2 = 2cos(2x). That's TWICE what the integral asked for.
The answer is 2 times too big → divide by 2. Correct: sin(2x)/2 + C.
Verify the fix: (sin(2x)/2)′ = 2cos(2x)/2 = cos(2x) ✓.
Error: forgot to divide by the inside's slope 2. Correct: sin(2x)/2 + C
12.definite integral
Compute ∫₀¹ (2x+1)³ dx.

Worked solution

Background: a definite integral with the new method: find the antiderivative by guess-and-fix, then FTC — top limit minus bottom limit. Handy move: evaluate the INSIDE first at each limit (at x = 1, 2x+1 = 3; at x = 0, 2x+1 = 1), then apply the power.
Antiderivative: (2x+1)⁴/8 (from problem 6, already verified by differentiating).
Top limit x = 1: (2·1+1)⁴/8 = 3⁴/8 = 81/8. Bottom limit x = 0: (2·0+1)⁴/8 = 1/8.
Subtract: 81/8 − 1/8 = 80/8 = 10.

13.definite · net zero
Compute ∫₀^(π/2) cos(2x) dx, and explain the answer using signed area. (Hint: where does cos(2x) cross the axis between 0 and π/2?)

Worked solution

Background: antiderivative of cos(2x) is sin(2x)/2 (problem 11's corrected answer). Note the neat trick with limits: plug the limit into the INSIDE first — at x = π/2 the inside is 2·(π/2) = π, a value-table angle! cos(2x) wobbles at double speed, so between 0 and π/2 it completes what plain cosine does between 0 and π.
∫₀^(π/2) cos(2x) dx = [sin(2x)/2]₀^(π/2) = sin(π)/2 − sin(0)/2.
= 0/2 − 0/2 = 0.
Signed-area story: cos(2x) is above the axis from 0 to π/4 and below from π/4 to π/2 — two mirror-image regions, one positive, one negative, cancelling exactly (just like ∫₀^π cos x dx = 0 from Lesson 16, squished to half width).
0 — the area above the axis cancels the area below
14.definite · one squished hump
Compute ∫₀^(π/2) sin(2x) dx, tracking every sign.

Worked solution

Background: sin(2x) runs at double speed, so from 0 to π/2 it traces one COMPLETE hump (what sin x does from 0 to π). Antiderivative: −cos(2x)/2 (problem 5). Inside values at the limits: 2·(π/2) = π and 2·0 = 0 — both table angles: cos π = −1, cos 0 = 1.
∫₀^(π/2) sin(2x) dx = [−cos(2x)/2]₀^(π/2) = (−cos π)/2 − (−cos 0)/2.
= (−(−1))/2 − (−1)/2 = 1/2 + 1/2 = 1.
Sense check: a full sine hump has area 2 (Lesson 16); this hump is squished to half width, so half the area — 1 ✓.

15.definite · exponential
Compute ∫₀¹ e^(2x) dx. Give the exact answer and a decimal estimate (use e² ≈ 7.39).

Worked solution

Background: from Lesson 15, e ≈ 2.718 and e^0 = 1. Antiderivative of e^(2x) is e^(2x)/2 (problem 3). Exact answers keep the letter e in them — only convert to a decimal at the very end, for a feel of the size.
∫₀¹ e^(2x) dx = [e^(2x)/2]₀¹ = e²/2 − e⁰/2 = e²/2 − 1/2 = (e² − 1)/2.
Decimal: (7.39 − 1)/2 ≈ 6.39/2 ≈ 3.19.

16.definite · slow wave
Compute ∫₀^π sin(x/2) dx. (Remember the x/2 inside means multiply by 2 — and watch the sine minus sign.)

Worked solution

Background: three things stack: sine's minus (Lesson 16), dividing by the slope ½ (= multiplying by 2), and the FTC. Antiderivative: −cos(x/2) ÷ ½ = −2cos(x/2). Inside values at the limits: π/2 and 0 — table angles: cos(π/2) = 0, cos 0 = 1.
Check the antiderivative first: (−2cos(x/2))′ = −2 · (−sin(x/2)) · ½ = sin(x/2) ✓.
∫₀^π sin(x/2) dx = [−2cos(x/2)]₀^π = (−2cos(π/2)) − (−2cos 0).
= (−2·0) − (−2·1) = 0 + 2 = 2.
Sense check: sin(x/2) at half speed traces only the RISING half of a stretched hump here, staying above the axis the whole way — a positive answer fits.

17.story · faster wave
A playground swing moves with speed v(t) = sin(2t) meters per second — it's a nervous little swing, wobbling twice as fast as a plain sine wave. One complete push forward lasts from t = 0 to t = π/2 (when the speed returns to 0). (a) How far does the swing travel during that push? (b) A lazier swing has speed sin t, and its push lasts from t = 0 to t = π. How far does IT travel? What did doubling the wobble speed do to the distance?

Worked solution

Background: from Lessons 11–12: distance = integral of speed over the time interval. A faster-wobbling wave (2t inside) squeezes each hump into half the time — same top speed, but less time spent moving, so less distance. Let's see the integrals agree.
(a) Distance = ∫₀^(π/2) sin(2t) dt = [−cos(2t)/2]₀^(π/2) = (−cos π)/2 − (−cos 0)/2 = 1/2 + 1/2 = 1 meter.
(b) Lazy swing: ∫₀^π sin t dt = [−cos t]₀^π = 1 + 1 = 2 meters (the famous hump from Lesson 16).
Doubling the wobble speed HALVED the distance per push: same speeds, half the time. That's the divide-by-2 in the antiderivative showing up in real life.
(a) 1 meter   (b) 2 meters — twice the frequency, half the distance per push
18.definite · net zero · slow wave
Compute ∫₀^(2π) cos(x/2) dx, and explain the answer with signed area.

Worked solution

Background: antiderivative of cos(x/2) is 2 sin(x/2) (problem 9). The inside runs at half speed: as x goes 0 → 2π, the inside x/2 goes only 0 → π — so cos(x/2) traces what plain cosine does over [0, π]: down from 1 to −1, crossing the axis midway (at x = π).
∫₀^(2π) cos(x/2) dx = [2 sin(x/2)]₀^(2π) = 2 sin π − 2 sin 0.
= 2·0 − 2·0 = 0.
Signed-area story: cos(x/2) is above the axis on [0, π] (area +2) and below on [π, 2π] (area −2) — mirror pieces that cancel exactly.
0 — the positive half cancels the negative half

20.challenge
Find ∫(e^(2x) + (4x+1)²) dx, then verify your whole answer by differentiating it term by term.

Worked solution

Background: integrals split over plus signs, so handle each term with its own guess-and-fix. Term 1: exponential with inside slope 2. Term 2: power with inside slope 4 — the denominator will be 3 (from the power rule) times 4 (the slope) = 12.
Term 1: ∫e^(2x) dx = e^(2x)/2.
Term 2: ∫(4x+1)² dx = (4x+1)³/3 ÷ 4 = (4x+1)³/12.
Together: e^(2x)/2 + (4x+1)³/12 + C.
Verify: (e^(2x)/2)′ = 2e^(2x)/2 = e^(2x) ✓ and ((4x+1)³/12)′ = 3(4x+1)² · 4 / 12 = (4x+1)² ✓. Sum: e^(2x) + (4x+1)² — exactly the function under the integral sign.
