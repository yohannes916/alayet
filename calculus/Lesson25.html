Lesson 25 — Inverse Trig Antiderivatives: arctan & arcsin

Two New Antiderivatives with π Inside · Intuitive Calculus for a Curious Student · Lesson 25 of 40

📚 All lessons← Prev: Lesson 24Next: Lesson 26 →
🎯 Goal of this lesson: meet the functions arctan and arcsin (they answer "backward" trig questions), trust two astonishing facts about their derivatives, and read those facts backward to unlock two antiderivatives the power rule and u-substitution can NOT reach: ∫ 1/(1+x²) dx = arctan x + C and ∫ 1/√(1−x²) dx = arcsin x + C. By the end you will compute an area under a plain-looking fraction and get π/4.

1 Inverse functions from scratch — asking the question backward

  • You already know inverse pairs: squaring and square-rooting. Squaring asks "what is 5²?" (answer: 25). Square-rooting asks the backward question: "WHAT number, when squared, gives 25?" (answer: 5). Each undoes the other.
  • arctan is the backward question for tangent. arctan x asks: "the tangent of WHAT angle equals x?" Since tan(π/4) = 1, we get arctan 1 = π/4. Since tan 0 = 0, arctan 0 = 0. Since tan(π/3) = √3, arctan √3 = π/3.
  • arcsin is the backward question for sine. arcsin x asks: "the sine of WHAT angle equals x?" Since sin(π/6) = 1/2, we get arcsin(1/2) = π/6. Since sin(π/2) = 1, arcsin 1 = π/2. And arcsin 0 = 0.
  • Notice: the input is a plain number, the output is an ANGLE (in radians, always). arctan and arcsin turn numbers back into angles.

  • One honest fine-print note: many angles share the same tangent, so arctan promises to always answer with the angle between −π/2 and π/2. arcsin makes the same promise (its output lives in [−π/2, π/2], and it only accepts inputs from −1 to 1, since sine never leaves that range). That's how the backward question gets exactly one answer.

2 The surprise — angle functions with NO trig in their derivatives

  • Here is one of the prettiest surprises in calculus. arctan and arcsin are built from trig, so you'd expect their derivatives to be a mess of sines and cosines. Instead:
  • (arctan x)′ = 1/(1+x²)   and   (arcsin x)′ = 1/√(1−x²) — no trig anywhere! Just fractions made of x's. Take these two as facts to trust (the proofs use the chain rule cleverly; you'll see them in a full calculus course).
  • Plausibility check (never trust a formula you haven't poked at): the graph of arctan x climbs quickly near 0 but flattens out for huge x — once tan of an angle is 1,000,000, nudging x higher barely changes the angle. So the slope of arctan should shrink toward 0 as x grows. And indeed 1/(1+x²) → 0 as x gets huge ✓. At x = 0 the formula gives slope 1/(1+0) = 1, a brisk 45° climb — matching the steep middle of the graph ✓.

3 Read it backward — two brand-new antiderivatives

  • Every derivative fact, read backward, is an antiderivative fact. Reading the two surprises backward gives us two new entries for the library:
Box these — new library entries:
∫ 1/(1+x²) dx = arctan x + C
∫ 1/√(1−x²) dx = arcsin x + C
  • Why do we need them? Try the old tools on 1/(1+x²). The power rule needs a plain power of x — but this is 1 over a SUM, not 1 over a power of x, so the power rule doesn't apply. u-substitution with u = 1+x² needs a du = 2x dx somewhere — but there's no x on top, so u-sub stalls too. These integrals genuinely require the new facts.
  • And they appear constantly on AP exams — examiners love them precisely because no old tool works.

4 The showstopper — an area that equals π/4

Worked example: compute ∫₀¹ 1/(1+x²) dx.
Antiderivative: arctan x. By the Fundamental Theorem:
∫₀¹ 1/(1+x²) dx = arctan 1 − arctan 0 = π/4 − 0 = π/4.
Read that again: the exact area under a plain fraction, between 0 and 1, is π/4 — a slice of a circle's number appearing under a curve with no circles in sight! ≈ 0.785, and the region really does fit inside a 1 × 1 square ✓.

5 The a-forms — when the 1 becomes a 4 or a 9

  • The AP exam often swaps the 1 for another perfect square: 1/(4+x²) or 1/√(9−x²). There are gentle upgrades of our two facts. For any positive constant a:
The a-forms:
∫ 1/(a²+x²) dx = (1/a) arctan(x/a) + C
∫ 1/√(a²−x²) dx = arcsin(x/a) + C
Notice: arcsin's form has NO 1/a out front; arctan's form does. Verifying (below) shows exactly why.
  • Let's verify the a = 2 arctan case by differentiating — the ultimate integral-checker. Claim: (1/2) arctan(x/2) is an antiderivative of 1/(4+x²).
  • Differentiate with the chain rule (inside function x/2, whose derivative is 1/2):
    d/dx[(1/2)arctan(x/2)] = (1/2) · 1/(1+(x/2)²) · (1/2) = (1/4) · 1/(1+x²/4).
  • Clean up the little fraction: multiply top and bottom by 4: 1/(1+x²/4) = 4/(4+x²). So the whole thing is (1/4) · 4/(4+x²) = 1/(4+x²) ✓. The chain rule spits out a 1/2, and the 1/2 out front is there to team up with it — that's the job of the (1/a).
  • For arcsin, the chain rule's 1/a gets absorbed when the a comes out of the square root (√(a²−x²) = a·√(1−(x/a)²)), so no front factor is needed. You'll verify the a = 3 case in exercise 16.

Worked solution

(a) tan(π/4) = 1, so arctan 1 = π/4.
(b) tan 0 = 0, so arctan 0 = 0.
(c) tan(π/3) = √3, so arctan √3 = π/3.

3.new library entry
Find ∫ 1/(1+x²) dx.

Worked solution

Background: this is one of today's two boxed facts. The power rule can't help (the bottom is a sum, not a lone power of x), and u = 1+x² has no matching du = 2x dx upstairs. Only the arctan fact fits.
∫ 1/(1+x²) dx = arctan x + C, straight from the library.
Check by differentiating: (arctan x)′ = 1/(1+x²) ✓.
arctan x + C
4.new library entry
Find ∫ 1/√(1−x²) dx.

Worked solution

Background: the second boxed fact. The fingerprint to memorize: a square ROOT downstairs, holding (1 − x²). Compare with arctan's fingerprint: NO root, holding (1 + x²). Root + minus → arcsin; no root + plus → arctan.
∫ 1/√(1−x²) dx = arcsin x + C.
Check: (arcsin x)′ = 1/√(1−x²) ✓.
arcsin x + C
5.constant multiple
Find ∫ 5/(1+x²) dx.

Worked solution

Background: constants slide freely through integrals (the constant-multiple rule from way back): ∫ c·f(x) dx = c·∫ f(x) dx. The new arctan fact combines with all the old rules.
∫ 5/(1+x²) dx = 5 ∫ 1/(1+x²) dx = 5 arctan x + C.
Check: (5 arctan x)′ = 5 · 1/(1+x²) ✓.
5 arctan x + C
6.mixed sum
Find ∫ (1/(1+x²) + eˣ) dx.

Worked solution

Background: the sum rule says integrate term by term. Each term calls a different library entry: the first is today's arctan fact; the second is the old friend ∫ eˣ dx = eˣ + C. One C at the end covers everything.
∫ 1/(1+x²) dx = arctan x, and ∫ eˣ dx = eˣ.
Add them: arctan x + eˣ + C.
Check: derivative is 1/(1+x²) + eˣ ✓.

7.definite · showstopper
Compute ∫₀¹ 1/(1+x²) dx exactly.

Worked solution

Background: the Fundamental Theorem routine: find an antiderivative, plug in the top limit, plug in the bottom limit, subtract. The antiderivative here is arctan x, so the answer will be a difference of ANGLES — even though the problem has no trig in it.
∫₀¹ 1/(1+x²) dx = [arctan x]₀¹ = arctan 1 − arctan 0.
arctan 1 = π/4 and arctan 0 = 0.
Answer: π/4 − 0 = π/4 ≈ 0.785. Sanity check: the region sits inside a 1 × 1 square (height starts at 1, ends at 1/2), so an area a bit above 3/4 is believable ✓.
π/4
8.definite · arcsin
Compute ∫₀^(1/2) 1/√(1−x²) dx exactly.

Worked solution

Background: same Fundamental Theorem routine, arcsin edition. You'll need the exact value arcsin(1/2) — that's the backward sine question: sine of WHAT is 1/2? From the exact-values table: π/6.
∫₀^(1/2) 1/√(1−x²) dx = [arcsin x]₀^(1/2) = arcsin(1/2) − arcsin 0.
= π/6 − 0 = π/6.

9.definite · arctan
Compute ∫₀^√3 1/(1+x²) dx exactly.

Worked solution

Background: a definite integral's limits can be any numbers — including √3. The payoff for knowing the arctan table: √3 is exactly where arctan gives the beautiful answer π/3.
∫₀^√3 1/(1+x²) dx = [arctan x]₀^√3 = arctan √3 − arctan 0.
tan(π/3) = √3, so arctan √3 = π/3.
Answer: π/3 − 0 = π/3.

10.a-form · a = 2
Find ∫ 1/(4+x²) dx.

Worked solution

Background: the bottom is a² + x² with a² = 4, so a = 2. The a-form says ∫ 1/(a²+x²) dx = (1/a) arctan(x/a) + C — and the (1/a) out front is NOT decoration: the chain rule produces a 1/a when differentiating arctan(x/a), and the front factor cancels it.
With a = 2: ∫ 1/(4+x²) dx = (1/2) arctan(x/2) + C.
Check (as in the notes): d/dx[(1/2)arctan(x/2)] = (1/2)·1/(1+x²/4)·(1/2) = (1/4)·4/(4+x²) = 1/(4+x²) ✓.
(1/2) arctan(x/2) + C
11.a-form · a = 3
Find ∫ 1/√(9−x²) dx.

Worked solution

Background: root downstairs holding (a² − x²) → the arcsin a-form: ∫ 1/√(a²−x²) dx = arcsin(x/a) + C. Here a² = 9, so a = 3. Remember: arcsin's a-form has NO front factor — the root absorbs it.
∫ 1/√(9−x²) dx = arcsin(x/3) + C.
Quick check: d/dx[arcsin(x/3)] = 1/√(1−x²/9) · (1/3) = (1/3) · 3/√(9−x²) = 1/√(9−x²) ✓ (the 1/3 from the chain rule cancels the 3 that comes out of the root).
arcsin(x/3) + C
12.definite · a-form
Compute ∫₀¹ 1/√(4−x²) dx exactly.

Worked solution

Background: combine the arcsin a-form (a = 2) with the Fundamental Theorem. The antiderivative will be arcsin(x/2), so the limits get divided by 2 on the way into arcsin.
Antiderivative: arcsin(x/2). So the integral = [arcsin(x/2)]₀¹.
Top: arcsin(1/2) = π/6. Bottom: arcsin(0) = 0.
Answer: π/6 − 0 = π/6.

13.trap trio · ln pattern
Find ∫ x/(1+x²) dx. (Careful — this is NOT arctan!)

Worked solution

Background: the x upstairs changes everything. With u = 1+x², du = 2x dx — and an x dx IS present up top (half of a du). That's the u-substitution fingerprint from Lesson 18, with the constant-borrow trick: x dx = du/2.
Let u = 1+x², du = 2x dx, so x dx = du/2.
∫ x/(1+x²) dx = ∫ (1/u)(du/2) = (1/2)∫ du/u = (1/2) ln|u| + C.
Back-substitute: (1/2) ln(1+x²) + C. (No absolute value needed — 1+x² is always positive.)
Check: derivative = (1/2)·2x/(1+x²) = x/(1+x²) ✓.
(1/2) ln(1+x²) + C
14.trap trio · power rule
Find ∫ 1/(1+x)² dx. (Careful — the square is on the whole parenthesis!)

Worked solution

Background: (1+x)² is a squared PARENTHESIS, totally different from 1+x². Substituting u = 1+x gives du = dx (derivative of 1+x is just 1), so this is the power rule in disguise: ∫ u⁻² du = u⁻¹/(−1) = −1/u.
Let u = 1+x, du = dx.
∫ 1/(1+x)² dx = ∫ u⁻² du = u⁻¹/(−1) + C = −1/u + C.
Back-substitute: −1/(1+x) + C.
Check: d/dx[−(1+x)⁻¹] = (+1)(1+x)⁻² · 1 = 1/(1+x)² ✓.
−1/(1+x) + C
15.recognition drill
Without computing anything yet, classify each integral by naming the right tool (arctan fact / u-sub → ln / power rule), then give each antiderivative: (a) ∫ 1/(1+x)² dx   (b) ∫ 1/(1+x²) dx   (c) ∫ x/(1+x²) dx

Worked solution

Background: this trio is the AP's favorite trap. The 10-second scan: WHERE is the square (on x alone, or on the parenthesis)? Is there an x upstairs that could be a du? Answer those two questions and the tool picks itself.
(a) Square on the parenthesis → power rule with u = 1+x → −1/(1+x) + C.
(b) Square on x alone, plain 1 on top → arctan fact → arctan x + C.
(c) Square on x alone, but x on top ≈ derivative of bottom → u-sub → ln → (1/2) ln(1+x²) + C.
(a) power rule: −1/(1+x) + C   (b) arctan: arctan x + C   (c) u-sub: (1/2)ln(1+x²) + C
16.check by differentiating
Verify by differentiation that arcsin(x/3) really is an antiderivative of 1/√(9−x²). Show every chain-rule step.

Worked solution

Background: differentiating your answer is the universal integral-checker. Two facts combine here: (arcsin x)′ = 1/√(1−x²), and the chain rule (multiply by the derivative of the inside, which for x/3 is 1/3). The interesting part is watching the 1/3 vanish.
d/dx[arcsin(x/3)] = 1/√(1−(x/3)²) · (1/3) = (1/3) · 1/√(1−x²/9).
Clean the root: 1 − x²/9 = (9−x²)/9, so √(1−x²/9) = √(9−x²)/3.
So (1/3) · 1/(√(9−x²)/3) = (1/3) · 3/√(9−x²) = 1/√(9−x²) ✓.
The 3 that climbs out of the square root exactly cancels the chain rule's 1/3 — that's why arcsin's a-form needs no front factor.
Derivative = 1/√(9−x²) ✓ — verified
17.spot the error
A student writes: ∫ 1/(1+x²) dx = ln(1+x²) + C, reasoning "one over something integrates to ln of that thing." Find the error, prove the answer wrong by differentiating it, and give the correct answer.

Worked solution

Background: the ln rule the student half-remembers is ∫ (1/u) du = ln|u| + C — and it only fires when du is genuinely present. For u = 1+x², du = 2x dx, so the ln route needs an x upstairs. There isn't one.
Differentiate the student's answer: d/dx[ln(1+x²)] = 2x/(1+x²) (chain rule: 1/(inside) × derivative of inside).
2x/(1+x²) ≠ 1/(1+x²) — the answer fails the check, so it's wrong.
The error: applying the ln pattern with no du (no x) on top. The integrand 1/(1+x²) is exactly the arctan fingerprint.
Correct: ∫ 1/(1+x²) dx = arctan x + C.
Error: ln pattern needs du = 2x dx present. Correct answer: arctan x + C
18.definite · a = 3
Compute ∫₀³ 1/(9+x²) dx exactly.

Worked solution

Background: a² + x² with a = 3, so the antiderivative is (1/3) arctan(x/3) — don't forget the 1/3 out front, it's the chain rule's partner. Then run the Fundamental Theorem as usual.
∫₀³ 1/(9+x²) dx = [(1/3) arctan(x/3)]₀³.
Top: (1/3) arctan(3/3) = (1/3) arctan 1 = (1/3)(π/4) = π/12.
Bottom: (1/3) arctan 0 = 0.
Answer: π/12 − 0 = π/12.
π/12
19.mixed definite
Compute ∫₀¹ (1/(1+x²) + eˣ) dx exactly.

Worked solution

Background: a definite integral of a sum splits into two definite integrals. One produces an angle (π/4), the other produces e − 1 — and the final answer simply adds these very different-looking exact numbers. AP answers often look like this: leave π and e in, don't round.
∫₀¹ 1/(1+x²) dx = arctan 1 − arctan 0 = π/4.
∫₀¹ eˣ dx = e¹ − e⁰ = e − 1.
Total: π/4 + e − 1 (≈ 0.785 + 1.718 = 2.503).
π/4 + e − 1
20.challenge · compute π!
(a) Show that ∫₀¹ 4/(1+x²) dx = π exactly. (b) Explain why this gives a genuine recipe for computing the digits of π using nothing but areas — no circles required. (Hint for (b): Lesson 23's trapezoidal rule can estimate any area...)

Worked solution

Background: mathematicians and computers really do use integrals like this one to calculate π. The two ingredients: an integral whose EXACT value involves π (today's arctan fact provides it), and a numerical method that approximates the same area to as many decimals as you like (Lesson 23's trapezoids, or fancier cousins).
(a) Pull out the constant: ∫₀¹ 4/(1+x²) dx = 4 ∫₀¹ 1/(1+x²) dx = 4 [arctan x]₀¹ = 4(arctan 1 − arctan 0) = 4(π/4 − 0) = π ✓.
(b) The left side is just an area under the concrete curve y = 4/(1+x²) between 0 and 1 — something we can approximate numerically with trapezoids, no π knowledge needed. Chop [0,1] into many slices, add up trapezoid areas, and the total creeps toward π. More slices → more correct digits: 3.14, then 3.1415…
So an area under a plain fraction IS π — and adding up enough skinny trapezoids under that fraction manufactures π's digits from scratch.
(a) 4 · π/4 = π ✓   (b) approximate the same area with trapezoids → digits of π
