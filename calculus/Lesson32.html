Lesson 32 — Partial Fractions

Splitting Fractions to Conquer Them · Intuitive Calculus for a Curious Student · Lesson 32 of 40

← Lesson 31📚 All lessonsNext: Lesson 33 →
🎯 Goal of this lesson: learn to integrate fractions like 5/((x−2)(x+3)) by splitting them into simple pieces — a technique called partial fractions. Each simple piece integrates to a logarithm. Along the way you'll pick up log rules, a factoring refresher, and a sharp decision habit: always check for ∫ f′/f first.

1 The problem — a fraction none of our tools can eat

  • Try to integrate ∫ 5/((x−2)(x+3)) dx with what we know:
  • Is it f′/f? The bottom is (x−2)(x+3) = x² + x − 6, whose derivative is 2x + 1. The top is 5 — not a match. ✗
  • Is it an arctan shape? Arctan wants x² + a² on the bottom (no real factors). Our bottom factors nicely, so no. ✗
  • Parts? u-sub? No useful product, no fingerprint. ✗
  • We need a genuinely new idea — and it comes from ordinary fraction arithmetic, the kind you've done since elementary school.

2 The idea — run fraction addition BACKWARD

  • Remember how fractions add: find a common denominator, then combine the tops. Watch it with algebra:
    1/(x−2) + 1/(x+3)  → common denominator (x−2)(x+3):
    = (x+3)/((x−2)(x+3)) + (x−2)/((x−2)(x+3)) = ((x+3) + (x−2))/((x−2)(x+3)) = (2x+1)/((x−2)(x+3))
  • So two SIMPLE fractions added up to one COMPLICATED one. Here's the flip: partial fractions runs this backward — given the complicated fraction, we recover the simple pieces it was built from.
  • Why bother? Because each simple piece is trivially integrable: ∫ 1/(x−2) dx = ln|x−2| + C (it's f′/f with f = x−2, since the top 1 is exactly the derivative of the bottom). Every piece gives a ln!

3 The method — distinct linear factors, step by step

  • Step 1 — set up the template. Guess that the fraction splits into one piece per bottom factor, with unknown numbers A and B on top:
    5/((x−2)(x+3)) = A/(x−2) + B/(x+3)
  • Step 2 — clear the denominators. Multiply both sides by (x−2)(x+3):
    5 = A(x+3) + B(x−2)   (must hold for EVERY x)
  • Step 3 — plug in the magic values. Since the equation holds for every x, choose x-values that make a factor vanish:
    • x = 2 kills the B term: 5 = A(2+3) + B·0 = 5A → A = 1.
    • x = −3 kills the A term: 5 = A·0 + B(−3−2) = −5B → B = −1.
  • Step 4 — verify by re-adding (always!): 1/(x−2) − 1/(x+3) = ((x+3) − (x−2))/((x−2)(x+3)) = 5/((x−2)(x+3)) ✓.
  • The cover-up shortcut — the same thing, faster: to find A, cover up the (x−2) in the original fraction with your finger, and plug x = 2 into what's left: 5/(x+3) at x = 2 gives 5/5 = 1 = A. For B: cover (x+3), plug x = −3: 5/(−3−2) = −1 = B. It works because it's exactly Step 3 in disguise.

4 Now integrate — and a log rule bonus

  • With the split done, the integral falls apart into easy logs:
    ∫ 5/((x−2)(x+3)) dx = ∫ 1/(x−2) dx − ∫ 1/(x+3) dx = ln|x−2| − ln|x+3| + C
  • Log rules, from scratch. Logarithms turn multiplication into addition. The three rules:
    • ln a + ln b = ln(ab) — logs add when the insides multiply.
    • ln a − ln b = ln(a/b) — logs subtract when the insides divide. (Sanity check with numbers: ln 8 − ln 2 = ln(8/2) = ln 4. Calculator: 2.079 − 0.693 = 1.386 = ln 4 ✓.)
    • k·ln a = ln(ak) — a coefficient becomes an exponent inside. (Check: 2 ln 3 = ln 9, since 1.099 × 2 = 2.197 = ln 9 ✓.)
  • So our answer has a tidy bonus form: ln|x−2| − ln|x+3| + C = ln|(x−2)/(x+3)| + C. Both forms are correct; the combined one is often shorter.

5 Factoring warm-up (you'll need it)

  • Often the bottom arrives UNfactored, like x² − x − 2. Partial fractions needs factors, so factor first.
  • The recipe for x² + bx + c: find two numbers that multiply to c and add to b. For x² − x − 2: multiply to −2, add to −1 → the numbers are −2 and +1. So x² − x − 2 = (x−2)(x+1). (Check by expanding: x² + x − 2x − 2 = x² − x − 2 ✓.)
  • Difference of squares: x² − 9 = (x−3)(x+3) — anything of the form x² − a² splits as (x−a)(x+a). (Check: x² + 3x − 3x − 9 ✓.)
  • Habit: when the bottom isn't factored yet, factor first — then set up the A/B template.

6 When NOT to use partial fractions

  • If the top happens to be the derivative of the bottom, you already own a one-step tool from Lesson 25: ∫ f′/f dx = ln|f| + C. Partial fractions would get the same answer with triple the work.
  • Example: ∫ (2x−1)/(x²−x−2) dx. Derivative of the bottom: 2x − 1 — exactly the top! So the answer is instantly ln|x² − x − 2| + C. No splitting needed.
  • The decision habit: always check f′/f FIRST. Differentiate the bottom in your head; if it matches the top (up to a constant factor), take the shortcut.

7 A definite example, start to finish

  • Compute ∫34 5/((x−2)(x+3)) dx. (Limits 3 and 4 stay safely away from x = 2 and x = −3, where the fraction blows up.)
  • From Sections 3–4, the antiderivative is ln|x−2| − ln|x+3|. Now FTC:
    [ln|x−2| − ln|x+3|]34 = (ln 2 − ln 7) − (ln 1 − ln 6)
    Since ln 1 = 0: = ln 2 − ln 7 + ln 6. Combine with the log rules: = ln(2·6/7) = ln(12/7) ≈ 0.539.
  • An exact answer like ln(12/7) is the finished product — just like leaving π in a circle answer. The decimal is only a sanity check.

1.warm-up · forward direction
Add the fractions: 1/(x−1) + 1/(x+2). (This is the FORWARD direction — combining simple pieces into one fraction.)

Worked solution

Background: to add fractions with different denominators, rewrite each over the common denominator — here (x−1)(x+2) — by multiplying top and bottom of each fraction by the factor it's missing. Then add the tops. Partial fractions will be exactly this process in reverse.
1/(x−1) = (x+2)/((x−1)(x+2))   and   1/(x+2) = (x−1)/((x−1)(x+2)).
Sum = ((x+2) + (x−1))/((x−1)(x+2)) = (2x+1)/((x−1)(x+2)).
(2x+1)/((x−1)(x+2))
2.warm-up · forward direction
Add the fractions: 2/(x+1) + 3/(x−4).

Worked solution

Background: same common-denominator routine, now with numbers on top. The coefficients 2 and 3 ride along: each top gets multiplied by the other fraction's factor, then everything combines. Expanding carefully and combining like terms is the whole game.
Common denominator (x+1)(x−4): sum = [2(x−4) + 3(x+1)] / ((x+1)(x−4)).
Top: 2x − 8 + 3x + 3 = 5x − 5.
(5x−5)/((x+1)(x−4))
3.warm-up · log rules
Use the log rules to: (a) write ln|x−1| − ln|x+2| as a single log; (b) simplify ln 8 − ln 2 to the log of one number; (c) write 2 ln 5 as the log of one number.

Worked solution

Background: logarithms convert multiplication into addition, so: ln a − ln b = ln(a/b) (subtraction ↔ division) and k ln a = ln(a^k) (coefficient ↔ exponent). These rules are how partial-fraction answers get compressed into one tidy log.
(a) ln|x−1| − ln|x+2| = ln|(x−1)/(x+2)|.
(b) ln 8 − ln 2 = ln(8/2) = ln 4.
(c) 2 ln 5 = ln(5²) = ln 25.
(a) ln|(x−1)/(x+2)|   (b) ln 4   (c) ln 25
4.warm-up · factoring
Factor each: (a) x² − x − 6   (b) x² − 25   (c) x² + 5x + 6.

Worked solution

Background: for x² + bx + c, hunt for two numbers that MULTIPLY to c and ADD to b; then the factors are (x + first)(x + second). For x² − a² (no middle term, minus a perfect square), it's always (x−a)(x+a). Always check by expanding back.
(a) multiply to −6, add to −1 → −3 and +2. So (x−3)(x+2). Check: x² + 2x − 3x − 6 = x² − x − 6 ✓.
(b) difference of squares: x² − 25 = (x−5)(x+5).
(c) multiply to 6, add to 5 → 2 and 3. So (x+2)(x+3).
(a) (x−3)(x+2)   (b) (x−5)(x+5)   (c) (x+2)(x+3)
5.decompose only
Find A and B: 1/((x−1)(x+2)) = A/(x−1) + B/(x+2). (Don't integrate yet — just split.)

Worked solution

Background: after multiplying through by the denominator, the equation 1 = A(x+2) + B(x−1) must hold for EVERY x — that's what lets us plug in "magic values" chosen to make one unknown's factor vanish, isolating the other.
Multiply through: 1 = A(x+2) + B(x−1).
x = 1 (kills B): 1 = A(3) → A = 1/3.
x = −2 (kills A): 1 = B(−3) → B = −1/3.
Verify by re-adding: (1/3)(x+2) − (1/3)(x−1) = (1/3)(x + 2 − x + 1) = (1/3)(3) = 1 ✓.
A = 1/3, B = −1/3  →  1/(3(x−1)) − 1/(3(x+2))
6.decompose only
Find A and B: (x+7)/((x−1)(x+3)) = A/(x−1) + B/(x+3), and verify your answer by re-adding the two pieces.

Worked solution

Background: the top can be a full expression like x+7, not just a number — the method doesn't change. When you plug in a magic value, evaluate the top at that value too. The re-adding check catches nearly every slip, so make it a reflex.
Multiply through: x + 7 = A(x+3) + B(x−1).
x = 1: 1 + 7 = 8 = A(4) → A = 2.
x = −3: −3 + 7 = 4 = B(−4) → B = −1.
Verify: 2(x+3) − 1(x−1) = 2x + 6 − x + 1 = x + 7 ✓.
A = 2, B = −1  →  2/(x−1) − 1/(x+3)
7.decompose & integrate
Find ∫ 3/(x(x−3)) dx.

Worked solution

Background: a plain x counts as a linear factor too — its piece is A/x, and its magic value is x = 0. After splitting, each piece integrates to a log: ∫ 1/x dx = ln|x| + C and ∫ 1/(x−3) dx = ln|x−3| + C.
Template: 3/(x(x−3)) = A/x + B/(x−3). Multiply through: 3 = A(x−3) + Bx.
x = 0: 3 = A(−3) → A = −1.   x = 3: 3 = 3B → B = 1.
Verify: −1(x−3) + 1·x = −x + 3 + x = 3 ✓.
∫ = ∫ (−1/x) dx + ∫ 1/(x−3) dx = −ln|x| + ln|x−3| + C = ln|(x−3)/x| + C.
ln|x−3| − ln|x| + C  (= ln|(x−3)/x| + C)
8.decompose & integrate
Find ∫ 1/(x² − 1) dx. (Factor the bottom first!)

Worked solution

Background: x² − 1 is a difference of squares: (x−1)(x+1). Note this is NOT the arctan shape — arctan needs x² PLUS a constant (which never factors); x² MINUS a constant factors, so it's partial-fractions territory.
1/((x−1)(x+1)) = A/(x−1) + B/(x+1) → 1 = A(x+1) + B(x−1).
x = 1: 1 = 2A → A = 1/2.   x = −1: 1 = −2B → B = −1/2.
Verify: (1/2)(x+1) − (1/2)(x−1) = (1/2)(2) = 1 ✓.
∫ = (1/2) ln|x−1| − (1/2) ln|x+1| + C = (1/2) ln|(x−1)/(x+1)| + C.
(1/2) ln|(x−1)/(x+1)| + C
9.decompose & integrate
Find ∫ (2x+3)/((x+1)(x+2)) dx — then discover something neat about this particular problem.

Worked solution

Background: sometimes two different tools both work — and MUST give the same answer (up to log rules). Here partial fractions works, but so does f′/f: the bottom expands to x² + 3x + 2, whose derivative is exactly the top, 2x + 3. Agreement between methods is a powerful self-check.
Partial fractions: 2x + 3 = A(x+2) + B(x+1). x = −1: 2(−1)+3 = 1 = A(1) → A = 1. x = −2: 2(−2)+3 = −1 = B(−1) → B = 1.
Verify: 1(x+2) + 1(x+1) = 2x + 3 ✓. So ∫ = ln|x+1| + ln|x+2| + C.
The neat part: d/dx[x² + 3x + 2] = 2x + 3 = the top! So f′/f gives ∫ = ln|x² + 3x + 2| + C instantly.
Same answer? ln|x+1| + ln|x+2| = ln|(x+1)(x+2)| = ln|x² + 3x + 2| ✓ — the log addition rule says yes.
ln|x+1| + ln|x+2| + C  (= ln|x² + 3x + 2| + C)
10.classify · the decision habit
For each integral, name the right tool (f′/f, partial fractions, or arctan), and solve (a) and (c): (a) ∫ (2x+1)/(x²+x−6) dx   (b) ∫ 5/(x²+x−6) dx   (c) ∫ 1/(x²+4) dx

Worked solution

Background: three fraction integrals, three tools — the ONLY difference is the top and whether the bottom factors. Check in this order: (1) is the top the bottom's derivative? → ln|f|. (2) Does the bottom factor? → partial fractions. (3) Is it x² + a²? → arctan, using ∫ 1/(x²+a²) dx = (1/a) arctan(x/a) + C.
(a) d/dx[x²+x−6] = 2x+1 = the top → f′/f. Answer: ln|x²+x−6| + C.
(b) top is 5, not the derivative; bottom factors as (x+3)(x−2) → partial fractions. (Set-up: 5/((x+3)(x−2)) = A/(x+3) + B/(x−2).)
(c) x² + 4 never factors → arctan with a = 2. Answer: (1/2) arctan(x/2) + C. (Check: derivative = (1/2)·(1/(1+(x/2)²))·(1/2) = (1/4)/(1+x²/4) = 1/(4+x²) ✓.)
(a) f′/f: ln|x²+x−6| + C   (b) partial fractions   (c) arctan: (1/2) arctan(x/2) + C
11.factor first
Find ∫ 1/(x² − x − 6) dx.

Worked solution

Background: the bottom arrives unfactored, so the very first move is the factoring recipe: two numbers that multiply to −6 and add to −1 are −3 and +2. Only then can the A/B template be set up. (Quick f′/f check first: derivative of the bottom is 2x−1 ≠ 1, so no shortcut.)
Factor: x² − x − 6 = (x−3)(x+2).
1 = A(x+2) + B(x−3). x = 3: 1 = 5A → A = 1/5. x = −2: 1 = −5B → B = −1/5.
Verify: (1/5)(x+2) − (1/5)(x−3) = (1/5)(5) = 1 ✓.
∫ = (1/5) ln|x−3| − (1/5) ln|x+2| + C = (1/5) ln|(x−3)/(x+2)| + C.
(1/5) ln|(x−3)/(x+2)| + C
12.decompose & integrate
Find ∫ 1/(x² − 4) dx.

Worked solution

Background: another difference of squares: x² − 4 = (x−2)(x+2). Compare with ∫ 1/(x²+4) dx from exercise 10 — one sign flips the whole method from partial fractions (two logs) to arctan. The sign of the constant is the switch.
1 = A(x+2) + B(x−2). x = 2: 1 = 4A → A = 1/4. x = −2: 1 = −4B → B = −1/4.
Verify: (1/4)(x+2) − (1/4)(x−2) = (1/4)(4) = 1 ✓.
∫ = (1/4) ln|x−2| − (1/4) ln|x+2| + C = (1/4) ln|(x−2)/(x+2)| + C.
(1/4) ln|(x−2)/(x+2)| + C
13.check task
Verify by differentiating that ln|x−2| − ln|x+3| really is an antiderivative of 5/((x−2)(x+3)).

Worked solution

Background: the derivative of ln|x−a| is 1/(x−a) (chain rule with inside x−a, whose derivative is 1). Checking a partial-fractions answer means differentiating each log, then RE-COMBINING the two simple fractions over a common denominator — the forward direction from exercise 1.
d/dx[ln|x−2| − ln|x+3|] = 1/(x−2) − 1/(x+3).
Combine: ((x+3) − (x−2))/((x−2)(x+3)) = (x + 3 − x + 2)/((x−2)(x+3)) = 5/((x−2)(x+3)).
Exactly the original integrand ✓.
Verified: derivative = 5/((x−2)(x+3)) ✓
14.definite
Compute ∫01 1/((x+1)(x+2)) dx exactly, simplifying to a single log.

Worked solution

Background: the full pipeline: decompose → integrate to logs → FTC with the limits → compress using log rules. Useful facts: ln 1 = 0, and 2 ln 2 = ln 4. On [0, 1] the factors x+1 and x+2 are positive, so the absolute values can be dropped.
Decompose: 1 = A(x+2) + B(x+1). x = −1: 1 = A(1) → A = 1. x = −2: 1 = B(−1) → B = −1. Verify: (x+2) − (x+1) = 1 ✓.
Antiderivative: ln(x+1) − ln(x+2).
At 1: ln 2 − ln 3.   At 0: ln 1 − ln 2 = −ln 2.
Integral = (ln 2 − ln 3) − (−ln 2) = 2 ln 2 − ln 3 = ln 4 − ln 3 = ln(4/3) ≈ 0.288.
ln(4/3)
15.spot the error
A student splits 4/((x+1)(x−3)) like this: "4 = A(x−3) + B(x+1). To find A, plug in x = 1 so the (x+1) part disappears: 4 = A(1−3) = −2A, so A = −2." Find the error, then finish the problem correctly.

Worked solution

Background: the magic value must make a FACTOR equal zero. The factor x+1 is zero when x = −1, not x = +1 — flipping this sign is the most common partial-fractions error. Quick guard: after choosing your magic value, actually substitute it into the factor and confirm you get 0.
The error: x = 1 does NOT make x+1 zero (1+1 = 2 ≠ 0). The correct magic value is x = −1. Also note: A is found by killing the B term — which happens at x = −1, since B multiplies (x+1).
Correctly: x = −1: 4 = A(−1−3) = −4A → A = −1.   x = 3: 4 = B(3+1) = 4B → B = 1.
Verify: −1(x−3) + 1(x+1) = −x + 3 + x + 1 = 4 ✓.
So 4/((x+1)(x−3)) = −1/(x+1) + 1/(x−3), and ∫ = ln|x−3| − ln|x+1| + C.
Magic value sign error; correct split: 1/(x−3) − 1/(x+1); integral = ln|(x−3)/(x+1)| + C
16.definite
Compute ∫23 1/(x(x+1)) dx exactly, as a single log.

Worked solution

Background: the split of 1/(x(x+1)) into 1/x − 1/(x+1) is one of the most famous in mathematics (it powers "telescoping sums"). The definite evaluation collects four logs; the log rules crush them into one fraction inside a single ln.
Decompose: 1 = A(x+1) + Bx. x = 0: A = 1. x = −1: 1 = −B → B = −1. Verify: (x+1) − x = 1 ✓.
Antiderivative: ln x − ln(x+1) (positive factors on [2,3], no bars needed).
At 3: ln 3 − ln 4.   At 2: ln 2 − ln 3.
Integral = (ln 3 − ln 4) − (ln 2 − ln 3) = 2 ln 3 − ln 4 − ln 2 = ln 9 − ln 8 = ln(9/8) ≈ 0.118.
ln(9/8)
17.factor first · bigger top
Find ∫ (x+5)/(x² − 1) dx.

Worked solution

Background: f′/f check first: derivative of x²−1 is 2x, not x+5 — no shortcut. So: factor (difference of squares), split with an x+5 top, integrate to logs. Different A and B values mean the two logs get different coefficients.
Factor: x² − 1 = (x−1)(x+1). Template: (x+5)/((x−1)(x+1)) = A/(x−1) + B/(x+1).
x + 5 = A(x+1) + B(x−1). x = 1: 6 = 2A → A = 3. x = −1: 4 = −2B → B = −2.
Verify: 3(x+1) − 2(x−1) = 3x + 3 − 2x + 2 = x + 5 ✓.
∫ = 3 ln|x−1| − 2 ln|x+1| + C. (Log-rules form: ln( |x−1|³/(x+1)² ) + C.)
3 ln|x−1| − 2 ln|x+1| + C
18.factor first · bigger top
Find ∫ (x+2)/(x² − 5x + 6) dx.

Worked solution

Background: full pipeline on a fresh quadratic. Factoring recipe: multiply to +6, add to −5 → −2 and −3, so the bottom is (x−2)(x−3). Watch the signs when plugging magic values into the top: at x = 2 the top is 2+2 = 4, at x = 3 it's 5.
f′/f check: derivative of bottom is 2x−5 ≠ x+2. Proceed with partial fractions.
x + 2 = A(x−3) + B(x−2). x = 2: 4 = A(−1) → A = −4. x = 3: 5 = B(1) → B = 5.
Verify: −4(x−3) + 5(x−2) = −4x + 12 + 5x − 10 = x + 2 ✓.
∫ = −4 ln|x−2| + 5 ln|x−3| + C.
5 ln|x−3| − 4 ln|x−2| + C

20.challenge · full pipeline
Let f(x) = (x+11)/((x−1)(x+2)). (a) Decompose f into partial fractions. (b) Find ∫ f(x) dx. (c) Compute ∫23 f(x) dx exactly. (d) Use the log rules to squeeze your answer into a single log.

Worked solution

Background: the whole lesson in one problem: decompose → integrate → FTC → log-compress. In part (d) you'll need the power rule twice: 4 ln 2 = ln 2⁴ = ln 16, and 3 ln 4 = ln 64, 3 ln 5 = ln 125. Then adds and subtracts become one fraction inside ln.
(a) x + 11 = A(x+2) + B(x−1). x = 1: 12 = 3A → A = 4. x = −2: 9 = B(−3) → B = −3. Verify: 4(x+2) − 3(x−1) = 4x + 8 − 3x + 3 = x + 11 ✓. So f = 4/(x−1) − 3/(x+2).
(b) ∫ f dx = 4 ln|x−1| − 3 ln|x+2| + C.
(c) At 3: 4 ln 2 − 3 ln 5. At 2: 4 ln 1 − 3 ln 4 = −3 ln 4. Integral = 4 ln 2 − 3 ln 5 + 3 ln 4.
(d) = ln 16 − ln 125 + ln 64 = ln(16 · 64 / 125) = ln(1024/125) ≈ 2.10. (Sanity: f is positive on [2,3] and roughly 3–4 tall, so an answer a bit above 2 over a width-1 interval is plausible ✓.)
