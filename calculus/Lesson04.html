Lesson 4 — The Antiderivative

Undoing the Derivative · Intuitive Calculus for a Curious Student · Lesson 4 of 40

📚 All lessons← Prev: Lesson 3Next: Lesson 5 →
🎯 Goal of this lesson: learn to run the derivative machine backwards. Given a derivative, you'll find the function it came from — that's called an antiderivative — and you'll meet the famous + C that tags along with every answer. This skill becomes the great shortcut for finding areas and totals.

1 Quick recap — the derivatives you already know

  • A derivative tells you the slope of a function — how steeply its graph is climbing at each point. You've computed a few of these before. Here are the ones we'll lean on all lesson:
  • The derivative of x2 is 2x. (Why: the curve x2 gets steeper as x grows — at x = 3 its slope is 6, at x = 5 it's 10. The slope is always exactly twice the x-value.)
  • The derivative of x3 is 3x2. (Why: this curve steepens even faster — its slope at any x is 3 times x squared.)
  • The derivative of 5x is 5. (Why: the graph of 5x is a straight line, and a straight line has the same slope everywhere — here, 5.)
  • The derivative of any constant (like 7, or −2, or 100) is 0. (Why: the graph of a constant is a flat horizontal line — it never climbs or falls, so its slope is 0 everywhere.)
  • The general pattern (the power rule): to differentiate xn, the power hops down front as a multiplier and the exponent drops by one: xn → n·xn−1.

2 The reverse game — "what function was I thinking of?"

  • Here's a riddle: "I'm thinking of a function whose derivative is 2x. What was my function?"
  • You just saw the answer in the recap: the derivative of x2 is 2x. So x2 works!
  • A function that answers this kind of riddle has a name: x2 is called an antiderivative of 2x. "Anti" means it undoes the derivative — differentiate the antiderivative and you land right back where you started.
  • So finding an antiderivative is playing the derivative game backwards: instead of "here's a function, find its slope," it's "here's the slope, find the function."
Try the riddle yourself: whose derivative is 3x2? From the recap: the derivative of x3 is 3x2. So x3 is an antiderivative of 3x2.

3 The +C twist — there's a whole family of answers

  • Back to the riddle "whose derivative is 2x?" We said x2. But watch this: what's the derivative of x2 + 7? The derivative of x2 is 2x, and the derivative of the constant 7 is 0 — so the derivative of x2 + 7 is 2x + 0 = 2x. It ALSO solves the riddle!
  • Same for x2 − 3, x2 + 100, x2 + 0.5… every one of them has derivative 2x, because tacked-on constants vanish when you differentiate.
  • So the riddle has a whole family of correct answers, and any two family members differ only by a constant. We write the entire family in one line: x2 + C, where C stands for "any constant you like."
  • The picture: all these functions are the same-shaped curve stacked at different heights. Sliding a curve straight up or down doesn't change how steep it is anywhere — so all the copies have identical slopes at every x.

  • From now on: every antiderivative answer ends in + C. Leaving it off means you've reported only one family member and hidden all the rest.

4 How to CHECK an antiderivative (never skip this!)

  • Antiderivatives come with a built-in answer checker: differentiate your answer and see if you get the original back.
  • Claim: an antiderivative of 2x is x2 + C. Check: derivative of x2 is 2x, derivative of C is 0 → total 2x ✓. Matches the original — correct.
  • This check is free (differentiating is the easy direction you already know) and it catches every mistake. Make it a reflex: answer, then check, every single time.
A check that catches a mistake: a student claims an antiderivative of 3x2 is x2 + C. Check: derivative of x2 + C is 2x — but the original was 3x2. No match → wrong. (The right answer is x3 + C, since the derivative of x3 is 3x2 ✓.)

5 Worked examples

Example 1 — antiderivative of 3x2: ask "whose derivative is 3x2?" From the recap: x3. Answer: x3 + C. Check: derivative of x3 + C = 3x2 + 0 = 3x2 ✓.
Example 2 — antiderivative of 5 (just a constant): whose derivative is the steady number 5? A straight line with slope 5: 5x. Answer: 5x + C. Check: derivative of 5x + C = 5 + 0 = 5 ✓.
Example 3 — antiderivative of 2x + 3 (a sum): handle each piece separately. Whose derivative is 2x? → x2. Whose derivative is 3? → 3x. Answer: x2 + 3x + C (one single + C covers the whole answer). Check: derivative = 2x + 3 ✓.

6 Why we care — the shortcut is coming

  • In Lessons 1–3 you found totals by adding up little rectangles under a rate graph — honest but slow.
  • Here's the spoiler for Lesson 7: antiderivatives are the shortcut to those areas and totals. Instead of adding a thousand skinny rectangles, you'll find one antiderivative and plug in two numbers. That's why this "backwards game" is worth practicing until it's automatic.
  • Next lesson (Lesson 5) turns today's guess-and-check into an official rule — the power rule for antiderivatives — so you can handle any power of x without guessing.

Worked solution

So x2 + 5 is a perfectly valid antiderivative — it's the family member with C = 5.
The only nitpick: if the question asks for ALL antiderivatives, write x2 + C to show the whole family. But calling x2 + 5 "wrong" is itself wrong.

8.sum
Find the antiderivative of 4x + 1.

Worked solution

Background: undo a sum piece by piece. For the 4x piece, remember that the derivative of x2 is 2x — so to get 4x (twice as big) you need twice the function: 2x2. For a lone constant, the antiderivative is that constant times x.
Whose derivative is 4x? Derivative of 2x2 = 2 · 2x = 4x ✓.

11.concept · why + C
In your own words: why does every antiderivative answer end in "+ C"? What would be lost if you left it off?

Worked solution

Background: the derivative of any constant is 0, because a constant's graph is a flat line with no steepness. So differentiating destroys any added constant — and when we reverse the process, we can't tell what constant (if any) was there.
If f(x) has derivative 2x, then f(x) + 1, f(x) + 7, f(x) − 40 ALL have derivative 2x too — the added constants vanish when differentiating.
Going backwards, the derivative alone can't reveal which constant the original function had. The + C honestly records that unknown.
Leaving off + C would claim there's exactly one answer, when really there's an infinite family — same-shaped curves stacked at every possible height.
Constants differentiate to 0, so infinitely many functions (differing by a constant) share the same derivative; + C records that whole family
12.sum
Find the antiderivative of 3x2 + 4x.

Worked solution

Background: take the sum one term at a time. Fingerprints to recognize: 3x2 is the derivative of x3, and 4x is the derivative of 2x2 (since 2x2 → 2·2x = 4x).
Term 1: antiderivative of 3x2 is x3.
Term 2: antiderivative of 4x is 2x2.
Combine with one + C: x3 + 2x2 + C. Check: derivative = 3x2 + 4x ✓.
x3 + 2x2 + C

Worked solution

Background: any two antiderivatives of the same function differ by a constant — they're two members of one family, two copies of the same curve stacked at different heights. Both are correct as long as each passes the differentiation check.
Check Maya: derivative of x2 + 1 = 2x ✓.
Check Leo: derivative of x2 − 3 = 2x ✓.
Both are right. Their answers differ by (x2 + 1) − (x2 − 3) = 4, a constant — exactly the family behavior the + C describes.
Both are right; the two answers differ by the constant 4 (two members of the family x2 + C)

16.find the specific function
A function f has derivative f′(x) = 2x, and you also know f(1) = 5. Find the exact function f(x) — no C left in the answer!

Worked solution

Background: the derivative alone only narrows f down to a family (here x2 + C). But ONE known point — one (input, output) pair — tells you exactly which stacked copy of the curve you're on, pinning down C. This is why the extra fact f(1) = 5 is given.
Antiderivative of 2x: f(x) = x2 + C.
Use the point: f(1) = 12 + C = 1 + C, and this must equal 5. So C = 4.
Therefore f(x) = x2 + 4. Check both facts: derivative = 2x ✓, and f(1) = 1 + 4 = 5 ✓.
f(x) = x2 + 4
17.find the specific function
Find f(x) given f′(x) = 3x2 and f(2) = 10.

Worked solution

Background: same two-step recipe every time: (1) find the antiderivative family with + C, (2) plug the known point into it and solve for C. "f(2) = 10" means: when the input is 2, the output is 10.
Step 1: antiderivative of 3x2 is f(x) = x3 + C.
Step 2: f(2) = 23 + C = 8 + C = 10, so C = 2.
f(x) = x3 + 2. Check: derivative = 3x2 ✓; f(2) = 8 + 2 = 10 ✓.
f(x) = x3 + 2
18.find the specific function
Find f(x) given f′(x) = 4x + 1 and f(0) = 3.

Worked solution

Background: a point with input 0 is the friendliest kind: plugging in x = 0 kills every x-term, leaving just C. (Note 02 = 0 and 4·0 = 0.) So f(0) directly tells you the constant.
Antiderivative of 4x + 1: the 4x piece comes from 2x2, the 1 comes from x. So f(x) = 2x2 + x + C.
f(0) = 2·0 + 0 + C = C, and this must equal 3 → C = 3.
f(x) = 2x2 + x + 3. Check: derivative = 4x + 1 ✓; f(0) = 3 ✓.
f(x) = 2x2 + x + 3
19.concept · graphs
Two different antiderivatives of the same function are graphed on the same axes. Describe how the two graphs are related — their shape, their steepness at each x, and how you'd get one from the other.

Worked solution

Background: "antiderivative of the same function" means both graphs have the SAME derivative — the same slope at every single x-value. Slope is the only thing a derivative measures; height above the x-axis is invisible to it.
Same slope at every x means the two curves steepen and flatten in perfect sync — they are identical in shape.
Since they're not the same function, they sit at different heights: one is the other slid straight up or down by a fixed amount (their difference is a constant).
Picture parallel curves stacked like pancakes: at any x, both tangent lines are parallel.
Identical shape and identical slope at every x; one graph is the other shifted vertically by a constant
