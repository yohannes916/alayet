Lesson 37 — Differential Equations I: Separation & Slope Fields

Equations About Rates, and How to Solve Them · Intuitive Calculus for a Curious Student · Lesson 37 of 40

🎯 Goal of this lesson: meet differential equations — equations whose unknown is a whole FUNCTION, described by its rate of change. You'll learn to verify a proposed solution, to solve by the star method (separation of variables), and to see solutions with slope fields. This is the heart of the AP free-response section — and you already own every tool it needs.

1 What a differential equation IS (from scratch)

  • Every equation you've ever solved asked for a number: "x + 3 = 7, find x." A differential equation (DE for short) asks for something bigger: it describes a function by its rate of change, and asks you to find the function itself.
  • Example: dy/dx = x. Read it out loud: "whatever the function y is, its slope at each x equals x." At x = 2 the graph climbs with slope 2; at x = −1 it slides down with slope −1; at x = 0 it's momentarily flat.
  • The solution is a FUNCTION, not a number. Here: y = x²/2 + C — check: its derivative is x. ✓
  • Notice the +C: a DE about the slope can't pin down the height, so the answer is a whole family of solutions, one curve for each C, all parallel copies sliding up and down.
  • Surprise: you've been solving DEs since Lesson 4. "Here's f′, find f" IS a differential equation. What's new today is DEs where the rate depends on y itself — like dy/dx = 2y — and those need a new move.

2 Verifying a proposed solution — free points, no solving

  • To check whether a function solves a DE, you don't solve anything. Just plug it into both sides and see if they match — like checking x = 4 in x + 3 = 7.
  • Recipe: (1) take the derivative of the proposed y; (2) substitute y into the right side; (3) compare. Equal for ALL x → it's a solution.
Worked check 1: is y = x² + 3 a solution of dy/dx = 2x?
Left side: derivative of x² + 3 is 2x. Right side: 2x. Match for every x → yes, it's a solution. (So is x² + 100 — any member of the family works.)
Worked check 2: is y = e^(2x) a solution of dy/dx = 2y?
Left side: derivative of e^(2x) is 2e^(2x) (chain rule, Lesson 12 vibes). Right side: 2y = 2·e^(2x). Both sides are 2e^(2x) → yes. ✓
Notice the right side contains y — you substitute the whole function in for y. That's the only new wrinkle.
  • AP tip: verification questions are free points — no cleverness required, just careful differentiating and comparing. Always write "left side = ..., right side = ..., equal → solution."

3 Separation of variables — "sort the letters"

  • The star method. It works whenever you can sort the letters: all the y's (with dy) on one side, all the x's (with dx) on the other. Then integrate BOTH sides, and add one C.
  • Steps: ① separate ② integrate both sides ③ + C (just one!) ④ solve for y if you can.
Flagship example: solve dy/dx = x/y.
① Sort: multiply both sides by y and by dx → y dy = x dx. All y's left, all x's right.
② Integrate both sides: ∫y dy = ∫x dx → y²/2 = x²/2 + C.
③ Tidy: multiply everything by 2 → y² = x² + 2C. But 2C is just... some constant. Rename it C: y² = x² + C.
C eats constants. Twice a constant, a constant plus 5, e to a constant — all still "some constant," so we keep calling it C. This renaming is legal and standard.
Now add an initial condition: same DE, with y(0) = 3 (the curve passes through (0, 3)).
Plug in x = 0, y = 3: 9 = 0 + C → C = 9 → y² = x² + 9.
Solve for y: y = ±√(x² + 9). Which sign? The initial condition decides: y(0) = 3 is positive, so take the + root: y = √(x² + 9).
Verify: dy/dx = x/√(x² + 9) = x/y ✓ and y(0) = √9 = 3 ✓. Always do this check — it takes ten seconds.
  • Why "one C, not two"? Integrating each side does produce a constant on each side — but move one across the equals sign and they merge into a single constant. Two letters would be pretending to know more than we do. (Exercise 16 makes you catch this error.)

4 The most important DE on Earth: dy/dx = ky

  • dy/dx = ky says: "the thing grows at a rate proportional to its own size." More bacteria → faster growth. More money → more interest. This one equation runs biology, finance, and radioactivity.
  • Solve it by separation — slowly, every step:
Step by step:
① Sort: dy/y = k dx (divide by y, multiply by dx).
② Integrate: ∫dy/y = ∫k dx → ln|y| = kx + C (the ∫f′/f = ln|f| move from Lesson 27!).
③ Undo the ln by making both sides an exponent of e: e^(ln|y|) = e^(kx + C).
④ Left side: e and ln cancel → |y|. Right side: e^(kx + C) = e^(kx)·e^C (exponent rule: adding exponents = multiplying).
⑤ e^C is just... a positive constant. And dropping the absolute value lets the constant carry the ± sign. C shape-shifts again: call the whole thing C. Result: y = Ce^(kx).
Verify: derivative of Ce^(kx) is kCe^(kx) = k·y ✓.
  • Memorize the sentence: "rate proportional to size" ⟹ exponential, y = Ce^(kx). Lesson 38 lives entirely on this fact — populations, half-life, cooling coffee.

5 Slope fields — a flow map for solutions

  • Most DEs can't be solved with algebra. But EVERY DE can be drawn. At each grid point (x, y), compute dy/dx there and draw a tiny segment with that slope. The result is a slope field — a flow map. Solution curves surf the field, following the little arrows.
  • Example: dy/dx = x. The slope depends only on x, so every column of the field is identical. At x = 0 all segments are flat; to the right they tilt up, steeper and steeper; to the left they tilt down — a mirror image:
slope field for dy/dx = x (\ = downhill, — = flat, / = uphill) y 3 | \ \ — / / 2 | \ \ — / / 1 | \ \ — / / 0 | \ \ — / / −1 | \ \ — / / +---------------------------→ x −2 −1 0 1 2 every COLUMN identical → slope depends on x only solutions: the parabola family y = x²/2 + C (valley bottom at x = 0)
  • Compare: the field for dy/dx = y. Now slope depends only on y, so every ROW is identical: nearly flat segments near y = 0, steep uphill high above the axis, steep downhill far below. Solutions are the y = Ce^x family — hugging the x-axis, then blasting away.
  • Matching a field to its DE — the detective checklist:
    • Where are the slopes zero? Set dy/dx = 0 and see which points satisfy it.
    • Where positive? negative? Check a test point or two.
    • Columns identical? → dy/dx depends on x only. Rows identical? → y only. Neither? → both letters appear (like dy/dx = xy).

6 Sketching a particular solution onto a field

  • AP task: "sketch the solution through the point (0, 1)." Recipe: put your pencil on the point, then follow the arrows — go rightward always turning to match the local segments, then come back to the point and follow them leftward too. Never cross segments at a different angle; your curve must be tangent to every segment it touches.
  • On the dy/dx = x field above, starting at (0, 1): flat at first, curving up to the right, and (going left) curving up to the left — the parabola y = x²/2 + 1. The field knew the answer before the algebra did.
  • One field, many starting points, many curves — that's the +C family drawn as a picture.
✏️ Exercises — 20 problems (write your answer on paper, then reveal)
1.verify
Is y = x² + 5 a solution of dy/dx = 2x? Verify by checking both sides.

Worked solution

Background: verifying means substituting, never solving. Compute the derivative of the proposed function (left side), compute the right side, and compare. If they agree for every x, the function is a solution.
Left side: derivative of x² + 5 is 2x + 0 = 2x.
Right side: 2x.
2x = 2x for all x → the sides match everywhere.
Yes — y = x² + 5 is a solution (the +5 vanishes when differentiating)
2.verify · y on the right
Is y = e^(4x) a solution of dy/dx = 4y? Verify.

Worked solution

Background: when the DE's right side contains y, substitute the entire proposed function in for y. Remember e^x is its own derivative, and the chain rule multiplies by the inner derivative: (e^(4x))′ = 4e^(4x).
Left side: derivative of e^(4x) = 4e^(4x).
Right side: 4y = 4·e^(4x) = 4e^(4x).
Both sides equal 4e^(4x) → match for all x.
Yes — y = e^(4x) solves dy/dx = 4y
3.verify · a FAIL
A classmate claims y = x³ is a solution of dy/dx = 3y. Check both sides and show the claim is false.

Worked solution

Background: a proposed solution FAILS if the two sides disagree at even one x. Showing one clean counterexample point (after computing both sides) is a complete disproof.
Left side: derivative of x³ is 3x².
Right side: 3y = 3x³.
Is 3x² = 3x³ for all x? Test x = 2: left = 12, right = 24. Not equal.
(They happen to agree at x = 0 and x = 1 — but a solution must work at EVERY x.)
No — 3x² ≠ 3x³ in general, so y = x³ is not a solution
4.separate & solve
Solve dy/dx = y by separation of variables. (Give the general solution.)

Worked solution

Background: this is dy/dx = ky with k = 1 — "grows at a rate equal to its size." Separation: sort letters, integrate both sides, one C, then undo the ln with e-both-sides.
Sort: dy/y = dx.
Integrate: ln|y| = x + C.
e both sides: |y| = e^(x+C) = e^C·e^x. Let the constant e^C (with the ± from the absolute value folded in) be C.
Verify: (Ce^x)′ = Ce^x = y ✓.
y = Ce^x
5.separate & solve
Solve dy/dx = x/y. (General solution — leave it in the form y² = ...)

Worked solution

Background: the flagship. Multiply both sides by y and dx so each letter lives with its own d-letter, integrate, then let C absorb any constant multiples.
Sort: y dy = x dx.
Integrate: y²/2 = x²/2 + C.
Multiply by 2: y² = x² + 2C → rename 2C as C.
Verify (implicitly): differentiate y² = x² + C → 2y·dy/dx = 2x → dy/dx = x/y ✓.
y² = x² + C
6.separate & solve
Solve dy/dx = (x + 1)/y. (General solution in the form y² = ...)

Worked solution

Background: same sort-the-letters move — the right side's x-part can be any expression in x; you just integrate it term by term (power rule, Lesson 21 style).
Sort: y dy = (x + 1) dx.
Integrate: y²/2 = x²/2 + x + C.
Multiply by 2: y² = x² + 2x + C (the 2C got renamed).
Verify: 2y·dy/dx = 2x + 2 → dy/dx = (x + 1)/y ✓.
y² = x² + 2x + C
7.separate & solve
Solve dy/dx = x²/y. (Give the answer in the form y² = ...)

Worked solution

Background: the x-side integral is ∫x² dx = x³/3. When you clear the fraction on the y-side, the C absorbs the multiplication — fractions inside C are fine because C is "some constant," whatever its shape.
Sort: y dy = x² dx.
Integrate: y²/2 = x³/3 + C.
Multiply by 2: y² = 2x³/3 + C.
Verify: 2y·dy/dx = 2x² → dy/dx = x²/y ✓.
y² = 2x³/3 + C
8.separate & solve · u-sub echo
Solve dy/dx = 2xy. (General solution, solved for y.)

Worked solution

Background: the right side is a PRODUCT of an x-part and a y-part — that's exactly when separation works. After integrating you'll need e-both-sides, and notice the answer echoes the u-sub fact that (e^(x²))′ = 2x·e^(x²).
Sort: dy/y = 2x dx.
Integrate: ln|y| = x² + C.
e both sides: y = e^(x² + C) = e^C·e^(x²) → y = Ce^(x²).
Verify: (Ce^(x²))′ = Ce^(x²)·2x = 2x·y ✓.
y = Ce^(x²)
9.separate & solve · neat
Solve dy/dx = y/x, and simplify the answer as far as you can. (It comes out surprisingly clean.)

Worked solution

Background: both sides become logarithms. Then use the log rule ln A + ln B = ln(AB): a "+ constant" attached to a ln can be rewritten as multiplying INSIDE the ln — which is how the constant ends up as a plain multiplier.
Sort: dy/y = dx/x.
Integrate: ln|y| = ln|x| + C.
e both sides: |y| = e^C·|x| → y = Cx (constant absorbs the sign).
Verify: left side (Cx)′ = C; right side y/x = Cx/x = C ✓. Straight lines through the origin!
y = Cx — the solution family is all lines through the origin
10.separate & solve · circles
Solve dy/dx = −x/y. What familiar shapes are the solution curves?

Worked solution

Background: not every solution family is a stack of function graphs. Here the answer is an implicit equation — and x² + y² = C is the equation of a circle centered at the origin with radius √C.
Sort: y dy = −x dx.
Integrate: y²/2 = −x²/2 + C.
Multiply by 2 and move x over: x² + y² = C.
Verify: differentiate x² + y² = C → 2x + 2y·dy/dx = 0 → dy/dx = −x/y ✓.
x² + y² = C — the solutions are circles centered at the origin
11.initial condition · choose the root
Solve dy/dx = x/y with the initial condition y(0) = −2. Give y as an explicit function of x, and explain which square root you chose and why.

Worked solution

Background: after finding y² = (stuff), solving for y forces a ± choice. The initial condition breaks the tie: pick the sign that matches the given point. Here y(0) = −2 is NEGATIVE, so the minus root is the right one.
General solution (exercise 5): y² = x² + C.
Plug in (0, −2): (−2)² = 0 + C → C = 4 → y² = x² + 4.
y = ±√(x² + 4). Since y(0) = −2 < 0, choose the minus root.
Verify: y = −√(x² + 4) → dy/dx = −x/√(x² + 4) = x/(−√(x² + 4)) = x/y ✓, and y(0) = −√4 = −2 ✓. Defined for all x (x² + 4 is never negative).
y = −√(x² + 4), the negative root because y(0) = −2 < 0; defined for all x
12.initial condition
Solve dy/dx = 2xy with y(0) = 5.

Worked solution

Background: once you have the general solution with its C out front, an initial condition at x = 0 is especially friendly: e^0 = 1, so C is simply the starting value.
General solution (exercise 8): y = Ce^(x²).
Plug in (0, 5): 5 = C·e^0 = C·1 → C = 5.
Verify: y = 5e^(x²) → dy/dx = 5e^(x²)·2x = 2x·y ✓, and y(0) = 5·1 = 5 ✓.
y = 5e^(x²)
13.slope field · read the rows
In a certain slope field, all the segments in any single ROW are identical — slopes never change as you slide left or right. What does that tell you about the differential equation? Give one example DE that would make such a field.

Worked solution

Background: a row of a slope field holds y fixed and lets x vary. If nothing changes along a row, then x has no influence on the slope — the formula for dy/dx cannot contain x.
Identical rows → the slope depends only on y (moving in the x-direction changes nothing).
So the DE has the form dy/dx = (an expression in y alone).
Example: dy/dx = y (flat along y = 0, steeper as |y| grows). Any y-only DE like dy/dx = y − 3 or dy/dx = y² also qualifies.
dy/dx depends on y only — e.g. dy/dx = y
14.where are slopes zero?
For the differential equation dy/dx = x(y − 2), describe ALL the points in the plane where the slope field shows flat (zero-slope) segments. What is special about the horizontal line y = 2?

Worked solution

Background: flat segments live where dy/dx = 0. A product is zero when either factor is zero — so set each factor to 0 separately. A whole line of zero slopes that a solution can LIVE on is called an equilibrium solution.
x(y − 2) = 0 when x = 0 (the entire y-axis) or y = 2 (the entire horizontal line).
So flat segments appear along the y-axis and along the line y = 2 — a big "+" of flatness.
Special: the constant function y = 2 is itself a solution! Check: left side (2)′ = 0; right side x(2 − 2) = 0 ✓. A solution that starts on that line stays on it forever.
Slopes are zero along x = 0 and y = 2; y = 2 is an equilibrium solution of the DE
15.reproduce the classic
From scratch, with every step shown, solve dy/dx = ky (k a constant) and explain where the formula y = Ce^(kx) comes from — including what happened to the absolute value and to e^C.

Worked solution

Background: this derivation is worth owning cold — it is THE bridge between "rate proportional to size" and "exponential function," and Lesson 38 uses it constantly. The key integral is ∫dy/y = ln|y|.
Sort the letters: dy/y = k dx.
Integrate both sides: ln|y| = kx + C₁ (one constant).
Make both sides an exponent of e: |y| = e^(kx + C₁) = e^(C₁)·e^(kx).
e^(C₁) is a positive constant; removing the absolute value multiplies by ±1. Bundle "±e^(C₁)" into a single new constant C (this is C shape-shifting — it eats exponentials and signs alike).
Result: y = Ce^(kx). Verify: (Ce^(kx))′ = kCe^(kx) = k·y ✓. Bonus: setting x = 0 gives y(0) = C — the constant is the starting value.
y = Ce^(kx), where C = ±e^(C₁) is the (renamed) constant — and C = y(0)
16.spot the error
A student solves dy/dx = x/y like this: "y dy = x dx → y²/2 + C₁ = x²/2 + C₂, and since there are two constants I can't simplify further — the answer must keep both C₁ and C₂." Explain the error and fix it.

Worked solution

Background: each side of an integration honestly does produce its own constant — the student's algebra isn't false. The error is stopping there: two unknown constants sitting on opposite sides of "=" always collapse into ONE.
Subtract C₁ from both sides: y²/2 = x²/2 + (C₂ − C₁).
C₂ − C₁ is one unknown constant — a single number we don't know. Rename it C.
So y²/2 = x²/2 + C, i.e. y² = x² + C — exactly the one-constant answer. Keeping two letters pretends the equation carries two independent unknowns when it only carries one.
The two constants merge: C = C₂ − C₁ — always write just one C
17.spot the error · non-separable!
Another student tries to solve dy/dx = x + y by separation: "dy/y = (x/y + 1) dx... hmm, or maybe dy = (x + y) dx..." Explain why NO amount of algebra will separate this DE, and state the test for recognizing a separable equation.

Worked solution

Background: separation requires writing dy/dx = (x-stuff) × (y-stuff) — a pure PRODUCT. A sum x + y is welded together: dividing by y drags a y into the x-territory (x/y), dividing by x drags an x into the y-territory. Recognizing non-separable equations is itself an AP skill.
Try it: dividing both sides by y gives (1/y)dy/dx = x/y + 1 — the right side still mixes x and y. Every other division fails the same way.
Test: can you factor the right side as f(x)·g(y)? For x + y: no factoring of a sum into an x-only times a y-only piece exists (if x + y = f(x)g(y), setting x = 0 forces g(y) = y/f(0) and setting y = 0 forces f(x) = x/g(0), and (x/g(0))·(y/f(0)) = xy·constant ≠ x + y).
Compare: dy/dx = xy separates (f = x, g = y); dy/dx = x + y does not. (It CAN be solved — just with different tools, beyond this course.)
Not separable: x + y cannot be factored into (x-only)·(y-only); separation needs a product
18.sketch through a point
Using the slope field for dy/dx = x (section 5), a solution curve is drawn through the point (0, 1). Describe the curve's shape in words: what does it do at x = 0, to the right, and to the left? Then find its equation and check your description.

Worked solution

Background: sketching on a field = starting at the point and staying tangent to every little segment you pass. The field for dy/dx = x is flat on the y-axis, uphill to the right, downhill-shaped (mirror image) to the left.
In words: at (0, 1) the curve is momentarily FLAT (slope 0 there). Moving right it bends upward, climbing ever more steeply. Moving left it also rises (going leftward means the downhill segments lift the curve up as you look backward). It's a valley — symmetric about the y-axis, bottom at (0, 1).
Equation: dy/dx = x → y = x²/2 + C; through (0, 1): 1 = 0 + C → C = 1.
Verify: y = x²/2 + 1 has derivative x ✓, passes through (0, 1) ✓, minimum at x = 0, symmetric — matches the description.
An upward parabola with its lowest point at (0, 1): y = x²/2 + 1
19.match field to DE
Three slope fields are described. Match each to one of these DEs — dy/dx = x, dy/dx = y, dy/dx = xy — and justify each match. (a) Flat segments along BOTH axes; slopes positive in the top-right and bottom-left regions, negative in the other two. (b) Every column identical; flat segments only along the y-axis (the vertical line x = 0). (c) Every row identical; flat segments only along the x-axis (the horizontal line y = 0).

Worked solution

Background: run the detective checklist: where are slopes zero, what's the sign in each region, and do columns/rows repeat? xy = 0 on both axes and follows the sign rules of multiplication (+·+ = +, +·− = −).
(a) Zero on both axes and sign = sign of the product → dy/dx = xy (top-right: x>0, y>0 → positive; top-left: x<0, y>0 → negative ✓).
(b) Columns identical → depends on x only; zero exactly at x = 0 → dy/dx = x.
(c) Rows identical → depends on y only; zero exactly at y = 0 → dy/dx = y.
(a) dy/dx = xy   (b) dy/dx = x   (c) dy/dx = y
20.challenge · AP-style multi-part
Consider dy/dx = −x/y. (a) Describe the slope field: where are segments flat? where are slopes undefined? what are the slopes' signs in the four quadrants? (b) Find the particular solution with y(0) = 5, solved explicitly for y. (c) State the x-values for which your solution is defined, and explain the limitation in one sentence.

Worked solution

Background: a full AP-style trio — field analysis, solve with an initial condition (choose the root!), and domain. From exercise 10 the family is the circles x² + y² = C, and a function can only be the TOP or BOTTOM half of a circle, never both.
(a) Flat where −x/y = 0 → x = 0 (the y-axis, except the origin region). Undefined where y = 0 (the x-axis — vertical tangents there). Signs: quadrant I (x>0, y>0) → negative; II (x<0, y>0) → positive; III → negative; IV → positive. The segments swirl around the origin.
(b) y dy = −x dx → y²/2 = −x²/2 + C → x² + y² = C. Through (0, 5): 0 + 25 = C → x² + y² = 25. Solve: y = ±√(25 − x²); y(0) = 5 > 0 picks the + root: y = √(25 − x²).
Verify: dy/dx = −2x/(2√(25 − x²)) = −x/√(25 − x²) = −x/y ✓ and y(0) = √25 = 5 ✓.
(c) Need 25 − x² > 0 (strictly, so y ≠ 0 keeps dy/dx defined): −5 < x < 5. The solution is only the TOP half of the circle of radius 5 — at x = ±5 the circle turns vertical and y would hit 0, where the DE breaks down.
(a) flat on x = 0, undefined on y = 0, signs −, +, −, + in quadrants I–IV   (b) y = √(25 − x²)   (c) −5 < x < 5
